## 생성할 채널 4종

### 1. trust_action (분리심문/비공개보호 반응)
법정 지배력 행동 시 당사자 반응.

**키 형식**: ref 파일의 trust_action 채널 키 형식 그대로 따름
**상황별 대사**:
- **분리심문(separation)**: 상대가 배제될 때의 반응. 배제되는 쪽은 "왜 저를 빼시는 겁니까?", 남는 쪽은 솔직해질 기회.
- **비공개보호(confidential_protection)**: 민감 정보 비공개 결정에 대한 반응. "감사합니다, 그 부분은 차마..."

**family-01 맥락**:
- A(태성) 분리 시: 형으로서 체면 → "동생 없이 더 솔직할 수 있다" 또는 "왜 제 동생만 빼시는 겁니까"
- B(정후) 분리 시: 20년 비밀 지원을 형 없이 말할 수 있음 → 담담하지만 안도
- 비공개보호: 출생 비밀(h-d3/h-d4), 공장 부도 이력 등 민감 정보 관련

**커버리지**: ref 파일의 spouse-01 trust_action 구조와 동일한 규모로 생성

### 2. judge_question (사건 맞춤형 재판관 질문)
범용 질문 엔진 대신 사건 특화 재판관 질문.

**키 형식**: ref 파일의 judge_question 채널 키 형식 그대로 따름
**구조**: 쟁점별 × 질문유형별(fact_pursuit/motive_search/empathy_approach) × depth별

**family-01 맥락**:
- d-1 관련: "어머니의 인지 상태가 유서 작성 시점에 어떠했는지 구체적으로 기억하십니까?"
- d-2 관련: "90대10 유서를 60대40으로 바꾸신 건, 본인 몫을 줄인 거라고 하셨는데요..."
- d-3 관련: "20년간 매달 보내신 생활비가 어머니 돈이었는지, 본인 돈이었는지..."

**작성 규칙**:
- 기계적 관찰문 금지: "진술 태도에 변화가 감지됩니다" ❌
- 긴 발언 직접 인용 금지 → 간접 인용: "아까는 ~쪽으로 말씀하셨는데"
- 톤 단계: soft(정리 요청) / mid(추궁) / hard(단호)
- 합니다체 필수

**키 형식**: ref 파일의 judge_contradiction 채널 키 형식 그대로 따름

**family-01 모순 포인트**:

### 4. system_message_v2 (상태 전이/연출 시스템 메시지)

**키 형식**: ref 파일의 system_message_v2 채널 키 형식 그대로 따름

**상황별 메시지**:
- 진술 변화: "태성의 목소리에서 확신이 조금씩 빠지기 시작한다."

- 감정 폭발: "정후의 눌러왔던 감정이 마침내 표면으로 올라온다."
- 숨겨진 쟁점 발견: "유서 뒤에 숨겨진 또 다른 문제가 보이기 시작한다."
- 증거 해금: "새로운 증거가 사건의 그림을 바꿔놓는다."
