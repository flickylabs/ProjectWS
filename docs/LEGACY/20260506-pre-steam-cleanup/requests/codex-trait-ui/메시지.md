## 생성할 컴포넌트

### 1) `src/components/pc/profile/PCTraitEnhancePanel.tsx`

**성향 강화 화면** — 내 정보 탭에서 사용.

- 6성향 카드를 2열 3행 그리드로 배치
  - 논리 / 직관
  - 엄격 / 관용
  - 원칙 / 화해
- 각 카드 내용:
  - 성향 이름 + 아이콘 (SVG inline, 아래 디자인 참조)
  - 현재 레벨 (Lv0~3) — 별 또는 게이지로 표시
  - 다음 레벨 요구 재료: "추론의 조각 ×6 / 탐구의 조각 ×10"
  - 보유량 표시 + 진행률 바 (부족 시 빨간색, 충족 시 금색)
  - [강화] 버튼 — `canEnhanceTrait()` true일 때만 활성화
  - 클릭 시 `enhanceTrait()` 호출 → 레벨업 애니메이션 (숫자 올라가며 빛남)
  - Lv3(MAX)일 때 "MAX" 뱃지 + 해금된 Major 퍼크 이름 표시
- 하단: 조각 변환 영역
  - 축 선택 (탐구/심판/해결)
  - "중립 조각 ×3 → [방향] 조각 ×1" 변환 버튼
  - `convertFragments()` 호출

**데이터 흐름:**
```tsx
const state = loadProgressionState()
// state.inventory: FragmentInventory (9종 조각 수량)
// state.traits: TraitLevels (6성향 레벨)
// 강화 후: saveProgressionState(updatedState)
```

### 2) `src/components/pc/profile/PCPerkEquipPanel.tsx`

**퍼크 장착 화면** — 강화 패널 하단 또는 별도 탭.

- Major 슬롯 (1개) + Minor 슬롯 (1개) 가로 배치
- `getAllUnlockedPerks(state.traits, 'major')` → 해금된 major 목록
- `getAllUnlockedPerks(state.traits, 'minor')` → 해금된 minor 목록
- 각 퍼크 카드: 이름, 설명, 해금 조건(어떤 성향 Lv몇)
- 미해금 퍼크: 어두운 실루엣 + 잠금 아이콘 + "논리 Lv3 필요"
- 장착/해제: 클릭 토글 → `saveProgressionState()` 호출
- 현재 장착 중인 퍼크는 금색 테두리

### 3) `src/components/pc/result/PCFragmentRewardOverlay.tsx`

**조각 획득 연출** — 결과 화면에서 표시.

- Props: `rewards: FragmentReward[]` (computeCaseRewards 결과)
- 각 조각이 화면 중앙에서 인벤토리 방향으로 날아오는 애니메이션
- 조각 종류별 아이콘 + "+N" 표시
- 보너스 조각은 금색 효과로 구분
- "성향 강화 가능!" 배너 (canEnhanceTrait가 true인 항목이 있을 때)
- 닫기 버튼 또는 자동 소멸 (3초)
