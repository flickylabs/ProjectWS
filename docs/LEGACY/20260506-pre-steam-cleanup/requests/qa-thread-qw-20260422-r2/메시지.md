## 2차 집중 이슈 (사용자 제기)

**이슈 1. 화자 톤 오염**
- 일부 상황에서 **시스템 메시지 / 재판관 가이드(judgeHint)**가 마치 **당사자 대사**처럼 읽히거나, 역으로 **당사자 대사**가 시스템 서술체로 읽히는 케이스
- NPC 말풍선 안에 "~가 감지된다/확인된다" 같은 관찰문이 섞이는 케이스
- 재판관 합니다체와 당사자 반말이 혼재되는 케이스
- "플레이어는/진행자는" 같은 4번째 벽 깨는 표현

**이슈 2. 맥락·단계별 자연스러움**
- 질문 유형(사실추궁/동기탐색/공감접근)에 맞지 않는 응답 톤
- LieState 점진적 공개가 부자연스러움 (갑자기 실명 노출, 금액 구체화 등 — Truth Throttle 위반)
- investigationStages 단계별 정보 공개가 "애매 → 의심 → 반전" 흐름으로 자연스러운지
- 쟁점 emerge 직후 NPC 반응이 "방금 들킨" 감정으로 자연스러운지
- 증인 다층 증언(vague/partial/full)이 실제로 정보 계단을 이루는지

## 검증 라운드 (12라운드 + 확장 가능)

### Phase A: 화자 톤 오염 전수 (R1~R4)

**R1. 시스템 서술체 침투 — NPC 대사 스캔**
- 3건 ScriptedText + Phase1/2 + v2-atoms + game-events 모든 NPC 대사에서:
  - 서술체 어미 (`~이다 | ~된다 | ~있다 | ~한다` 단독형) 스캔
  - 관찰문 패턴 (`~가 감지된다 | ~이 확인된다 | ~흐름이 나타난다 | ~변화가 보인다`)
  - 4번째 벽: `플레이어 | 진행자 | 시청자 | 관찰자`
- NPC는 1인칭·구어체 (반말 또는 합니다체) 필수
- 발견 건수 + 위치 + 원문 + 수정안

**R2. 재판관 가이드(judgeHint) 톤 전수**
- 3건 × 5 dc-\* = 15개 judgeHint
- 재판관 합니다체 일관 (`~합니다 | ~습니다 | ~시지요`)
- "제안합니다/확인해보시지요" 류 조언형 톤
- 당사자 1인칭 섞임 금지 (`제가 | 저희 | 우리`)
- 시스템 서술체 금지 (`~된다 | ~가 풀린다`)

**R3. 조합 재판관 코멘트(combinationComments.ts) 톤 전수**
- 18개 코멘트 전수
- 재판관 톤 일관 (합니다체, 직접 인용 금지, 간접 화법만)
- 특히 spouse-01 combine-3/4/5 (금액 재배치 반영)

**R4. 시스템 메시지 서술체 전수**
- `speaker: 'system'` 메시지 전수:
  - 조합 성공 (`🧑‍⚖️ 새 증인 'OOO' 소환 가능해졌습니다`)
  - 증거 조사 완료
  - 쟁점 emerge (`🆕 새 쟁점 ...이 드러났습니다`)
  - 감정 폭발 fallback 설명
  - timeline_lock (`📌 진술 시점 고정`)
- 이모지 프리픽스 일관, 합니다체, 간결한 서술

### Phase B: 맥락·단계별 자연스러움 (R5~R9)

**R5. 심문 유형별 응답 톤 정합 (3건 × 3유형)**
- `fact_pursuit` 질문 → 모순/반박/추가 정보 요구하는 답변 atom

- S3+: 실명 / 구체 금액 / 정식명칭
- S5: 전부 공개
- 3건 × 각 쟁점 × S0~S5 = 샘플 30+ 케이스 검증
- 위반 사례 (S0에서 실명 나오는 등) 리스트

**R7. investigationStages 단계별 정보 공개 곡선**
