# GPT Pro 요청: Phase 6 중재 스크립트 3사건

## 배경

Phase 6에서 플레이어가 중재 유형(즉시판결/조건부/보류/사실먼저)을 선택하면,
양측 당사자(A, B)가 이에 반응하는 대사가 표시됩니다.
현재 이 대사는 LLM 폴백에 의존하고 있어, 스크립트 보충이 필요합니다.

## 기존 구조

scriptedText 번들의 `mediation` 채널이 있다면:
```json
{
  "channels": {
    "mediation": {
      "paths": {
        "immediate": {
          "judge": "쟁점은 충분히 드러났습니다...",
          "dialogues": [
            { "speaker": "a", "text": "A의 반응 대사", "relatedDisputes": ["d-1"], "behaviorHint": "긴장" },
            { "speaker": "b", "text": "B의 반응 대사", "relatedDisputes": ["d-1"], "behaviorHint": "불안" }
          ]
        },
        "conditional": { ... },
        "postpone": { ... },
        "fact_first": { ... }
      }
    }
  }
}
```

## 요청

3사건 × 4유형 × 당사자 2명 반응 = **24개 대사** 작성.

### 사건 정보

**spouse-01** (민준-서연)
- A: 민준 (avoidant) — 재판관에게: 합니다체, 상대 언급: "제 아내가~"
- B: 서연 (confrontational) — 재판관에게: 합니다체, 상대 언급: "제 남편이~"
- 쟁점: 공동통장/베팅/외도의심/휴대폰접근

**family-01** (지훈-수진)
- A: 지훈 — 재판관에게: 합니다체, 상대 언급: "제 동생이~"/"수진이가~"
- B: 수진 — 재판관에게: 합니다체, 상대 언급: "형이~"/"지훈이가~"
- 쟁점: 부모재산/간병분담/생활비/가업승계

**friend-01** (현우-동민)
- A: 현우 — 재판관에게: 합니다체, 상대 언급: "동민이가~"
- B: 동민 — 재판관에게: 합니다체, 상대 언급: "현우가~"
- 쟁점: 공동투자/수익배분/계약해석/신뢰파괴

### 중재 유형별 톤 가이드

| 유형 | 재판관 톤 | 당사자 예상 반응 |
|------|----------|----------------|
| immediate | 단호한 결단 | A/B 모두 긴장, 압박감 |
| conditional | 조건 제시 | 탐색적, 조건 따지기 |
| postpone | 여유 부여 | 안도 + 불확실함 |
| fact_first | 사실 먼저 | 방어적 또는 수용적 |

### 대사 구조

각 유형에서:
- A 대사 1개 (2~3문장)
- B 대사 1개 (2~3문장)
- 같은 유형이라도 A와 B의 톤이 달라야 함 (archetype 반영)
- `behaviorHint`: 1~2단어 (예: "긴장", "방어적", "수용")
- `relatedDisputes`: 해당 사건의 주요 쟁점 1~2개

## 한국어 품질 규칙
- 합니다체 필수 (재판관 대상)
- 번역체 금지
- "사전 상의/협의" 금지
- 호칭 규칙 준수 (위 사건 정보 참조)
