# 조합 재판관 코멘트 생성 — spouse-01

## 목표
플레이어가 증거/발언을 조합해 새로운 단서를 발견했을 때, **재판관이 법정에서 하는 코멘트 1줄**을 생성합니다.

## 산출물
`spouse-01-combination-comments.json` — 6개 코멘트

```json
[
  {
    "recipeId": "combine-1",
    "comment": "재판관 코멘트 텍스트"
  },
  ...
]
```

## 사건 개요
- **사건**: 이준호(A, 남편) vs 박지연(B, 아내) — 부부 분쟁
- 남편이 비자금을 빼서 형에게 보냈고, 아내가 투자 사기에 걸려 적금을 깼음
- 외도 의심 → 실은 형네 돌봄이었음

## 조합 데이터
동봉된 `combination-data.json` 참조.

## 작성 규칙

### 톤
- **재판관 말투**: 합니다체, 단호하지만 중립적
- 관찰자로서 사실을 짚는 톤 (판단은 플레이어가 함)
- 1~2문장, 40자 이내 권장

### 내용 규칙
- **직접적 결론 금지**: "이것은 외도가 아닙니다" ← 이런 거 안 됨
- **방향만 제시**: "두 증거의 시간대가 겹치는 부분이 있군요"
- DossierCard(dc-*) 조합은 약간 더 강한 톤 가능: "이 부분은 반드시 짚고 넘어가야겠습니다"
- Lead(L-*) 조합은 가벼운 관찰 톤: "흥미로운 접점이 보입니다"

### 금지 패턴
- 번역체: "~된 것으로 판단됩니다", "~한 측면이 있습니다"
- 기계적 관찰: "내용이 확인됩니다", "태도에 변화가 감지됩니다"
- 긴 직접 인용: NPC 발언을 따옴표로 그대로 넣지 않음

### 예시
- Lead: "영수증 구매 장소와 GPS 경로가 겹칩니다. 한번 따져볼 만합니다."
- DossierCard: "이 금액의 출처와 사용처를 분명히 해야겠습니다."
