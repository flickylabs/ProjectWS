## V4 사건 사실 변경 (V3 대비 — 내용 검증 시 필수 숙지)

| 항목 | V3 | V4 |
|------|----|----|
| B의 3,000만원 | 공동적금 | **개인 비자금 → 형에게 현금 전달** |
| A의 2,000만원 | 적금 해지 | **위임장 조작으로 공동 적금 해지 (범죄)** |
| 각방 사유 | 불명확 | **시부모 재산 형 탕진 → B 숨김 → A 분노** |
| 오피스텔 | 외도 의심 | **형네 오피스텔, 조카(중2) 돌봄** |
| 새벽 전화 | 불명확 | **각방이라 복도에서 문틈으로 들음** |
| 증인 | 형, 조카 등 | **경비, 은행직원, 박미라** |
| 증거 | 카드명세서, 출입기록 | **영수증 5장 묶음, 블랙박스 GPS/네비** |

### 정보 비대칭 (절대 규칙)

**A만 아는 것** (B의 대사에 나오면 FAIL):
- 위임장 조작
- 투자 사기 피해
- 수년간 계좌 감시

**B만 아는 것** (A의 대사에 나오면 FAIL):
- 형의 개인회생
- 조카의 존재/돌봄
- 현금 전달 경위
- 시부모 재산 탕진의 상세 (B가 이미 알고 숨겼다는 사실)

## 추가 주의사항

1. **V3 데이터와 혼동 금지**: V4는 서사 자체가 바뀜. V3 기준으로 사실관계를 판단하면 오판함.
2. **behaviorHint도 검증**: 코드 태그("a S0 fact_pursuit ?? 1") 형식이면 FAIL. 캐릭터 분위기 묘사여야 함.
3. **검증 깊이**: 기계적 체크리스트가 아님. 의미/내용/맥락을 꼼꼼히 읽고 판단.
4. **채널별 검증 완료 시 즉시 CT 보고** — Thread R에 FAIL 피드백을 빠르게 전달해야 함.
