## 변경 영역 요약

### 1. 핫바 재설계 (P0)

**기존**: F1(심문)/F2(증거)/F3(특수) 3페이지 × 6슬롯 = 17액션
**V4**: 6슬롯 단일 바

```
[사실추궁] [동기탐색] [공감접근] [증거 제시▼] [증인 소환] [메뉴▼]
  1키        2키        3키        4키          5키       6키
```

변경 사항:
- `pcHotbarConfig.ts`의 3페이지 구조 → 단일 페이지
- F1/F2/F3 키보드 바인딩 제거
- 슬롯 4: 클릭 시 증거 목록 드롭다운
- 슬롯 5: 조건부 활성/비활성 (증인 소환 가능 시 활성+글로우)
- 슬롯 6: 메뉴 드롭다운 (분리심문, 비공개보호, 즉답요구, 기록정리, 단계진행)

**영향 파일**: `PCBottomDock.tsx`, `pcHotbarConfig.ts`, `PCActionsPanel.tsx`

### 2. 끼어들기 UI (P1)

**기존**: 핫바 변경 방식
**V4**: 팝업 선택지 (현재도 이 방식이면 유지)

```
┌─────────────────────────────────────┐
│  B(이준호)가 끼어듭니다              │
│  "그쪽도 적금 건드린 거 아니냐!"     │
│  [허용]        [제지]               │
└─────────────────────────────────────┘
```

- 허용 시: 대화 영역에 **반격 질문 버튼** 일시 표시 (1턴, 펄스 글로우)
- 제지 시: "상대가 입을 다물지만, 불만이 쌓입니다" 텍스트

### 3. 조합 스킬 (P1)

**기존**: CombinationLab 3슬롯 + 별도 패널
**V4**: 우패널 하단 2슬롯 인라인

```
[슬롯A: 비어있음] + [슬롯B: 비어있음]
         → [조합 실행]
```

- 드래그앤드롭 또는 Shift+클릭으로 슬롯에 추가
- 유효한 쌍: [조합 실행] 활성 + 글로우
- 불가능한 쌍: "새로운 것을 발견할 수 없습니다"
- 성공 시: 두 카드 합쳐지는 애니 → 결과 팝업

**영향 파일**: `CombinationLabPanel.tsx` → 대폭 축소 or 신규 컴포넌트

### 4. 기록 정리 (요약 스킬) (P2)

**기존**: 판결 전용 요약
**V4**: 진행 중 사용 가능, 턴 소비 없음. 메뉴▼에서 접근.

```
┌─ 기록 정리 ─────────────────────────┐
│ ■ 확인된 사실                        │
│   ✓ B가 오피스텔에 다니고 있다        │
│   ? A가 목돈 출금을 알고 있다 (경위?) │
│ ■ 미해결 의문                        │
│   • 오피스텔에 누가 사는가?           │
│ ■ 모순 발견                          │
│   ⚡ B: "야근" → "아는 사람"          │
└─────────────────────────────────────┘
```

**신규 컴포넌트** 필요. 데이터 소스: LieState 전이 기록 + contradictionMeta + 증거 조사 상태

### 5. 증거 수첩 (좌패널 상단) (P1)

**기존**: 증거 카드 나열
**V4**: 증거별 발견 메모 + 관련 발언 연결 + 조합 힌트

```
┌─ e-1: 영수증 묶음 ──────────┐
│ [획득] B의 차에서 A가 발견    │
│ ■ 발견한 내용:               │
│   • 편의점: 컵라면, 삼각김밥  │
│   • 올리브영: 머리끈, 틴트    │
│   • (미확인 항목 3개)        │
│ ■ 관련 발언:                 │
│   B S1: "그건 제가 산 겁니다" │
│ ★ 조합 힌트                  │
└──────────────────────────────┘
```

**영향 파일**: 좌패널 증거 섹션 전체 재작성

### 6. 발언 노트 (좌패널 하단) (P1)

**기존**: 시간순 18개 + 핀
**V4**: 쟁점별 탭 + 양측 대조 뷰 + 모순 하이라이트

- 기본 뷰: 축소 (1줄씩)
- 쟁점 탭 클릭: 확장 → A/B 좌우 대조
- 모순 자동 하이라이트
- Shift+클릭 → 조합 슬롯에 추가

**영향 파일**: `PCImportantNotesSection.tsx` 대폭 재작성

### 7. 타임라인 (좌패널 확장) (P2)

**기존**: (미구현 or 전체 노출)
**V4**: 발견 기반 점진적 채워짐 + "기록 추가" 연출

### 8. 판결 UI (P2)

**기존**: 단순 슬라이더 + 해결안
**V4**: 4단계 (쟁점판단 → 안건책임 → 해결안 → 판결문)

상세는 `v4-gameplay-design-confirmed.md` Section 4 참조.
