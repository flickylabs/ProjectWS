# Session 3: 쟁점 d-3 심문 ScriptedText 생성

> **쟁점**: A 아버지는 예비신랑에게 돈을 뜯어내려 접근하고 있었는가
> **채널**: interrogation
> **출력 대상**: A(송다은) + B(최수민), S0~S5, 3 질문유형, 각 5 variant
> **총 entry 수**: 36개 (2 party x 6 state x 3 questionType)
> **총 variant 수**: 180개

---

## 작업 지시

session-0-context의 규칙을 준수하며, 아래 NEW FACT 매핑을 기반으로 d-3 쟁점의 심문 대사를 생성해주세요.

### 쟁점 성격

d-1에서 B가 "경고하려 했다"고 말한 뒤, "무엇을 경고하려 했는가"에서 파생되는 쟁점.
B가 예비신랑에게 연락한 **진짜 이유** = A 아버지가 예비신랑에게 과거와 같은 방식으로 돈 접근을 하고 있었다는 것.
이 쟁점은 d-4(과거 사기)와 직접 연결됨.

### 트리거

- 핵심 잠금: 인사 차원의 연락은 S1, 돈 얘기와 급한 부탁은 S2, 반복된 접근 패턴은 S4에서 열림.
- 트리거 증거: `hard_evidence` `e-5`, `e-7`

### 출력 형식

```json
{
  "session": "session-3-d3-interrogation",
  "channel": "interrogation",
  "disputeId": "d-3",
  "entries": [ ... 36개 entry ... ]
}
```

## A(송다은) d-3 NEW FACT 매핑

A는 아버지를 방어하는 입장. "아버지가 그럴 사람이 아니다"에서 시작해 점진적으로 균열.
핵심 긴장: 아버지의 진실을 받아들이는 것이 A에게는 세계관 붕괴에 가까움.

**A의 정보 비대칭**: A는 아버지가 과거 B에게 사기를 친 사실, 현재 예비신랑에게 돈 접근 중인 사실을 **모른다** (e-5, e-6가 열리기 전). A의 대사는 "아버지를 아는 딸"의 관점에서 나옴.

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | "아버지가 그럴 분이 아니다" (완전 방어) | deny | none |
| S1 | **"인사 차원에서 연락할 수는 있다" — 최소 인정** | hedge | hint |
| S2 | **"경제적으로 어려운 건 맞다" — 아버지 상황 일부 인정** | hedge | hint |
| S3 | **"돈 얘기를 꺼냈을 수는 있다" — 돈 접근 가능성 인정** | partial | partial |
| S4 | **"예전에도 이런 적이 있었다" — 아버지의 패턴 인지 시작** | emotional | partial |
| S5 | **"아버지가 수민이한테 했던 것과 같은 일인지도 모르겠습니다"** — 과거와 현재 연결 | confess | full |

### A d-3 질문유형별 레퍼런스

| State | 사실추궁 | 동기탐색 | 공감접근 |
|-------|---------|---------|---------|
| S0 | "아버지가 예비신랑한테 돈을 뜯으려 했다고요? 있을 수 없는 일입니다" | "아버지가 그럴 분이 아닙니다. 수민이가 아버지까지 끌어들이는 겁니다" | "아버지까지 건드리면 안 됩니다. 이건 선 넘는 겁니다" |
| S1 | "사위 될 사람한테 인사 차원에서 연락할 수는 있습니다" | "결혼 전이니까 만나보고 싶었을 수 있습니다. 자연스러운 겁니다" | "아버지가 예비 사위한테 관심 갖는 게 잘못입니까" |

| S4 | "예전에도 이런 적이 있었습니다. 주변에 돈을 빌려 다닌 적이요" | "그때는 다 갚았다고 생각했는데, 아직도 이러고 계신 건지 모르겠습니다" | "아버지가 이러시는 게 창피하다는 생각이 먼저 듭니다. 딸로서 어떻게 해야 할지 모르겠습니다" |
| S5 | "아버지가 수민이한테 했던 것과 같은 일인지도 모르겠습니다" | "수민이가 경고하려 한 게 이거였다면, 저는 아버지 편만 들면서 수민이를 밀어낸 겁니다" | "아버지를 의심하는 것도 무섭고, 수민이가 맞는 것도 무섭습니다" |

## B(최수민) d-3 NEW FACT 매핑

B는 A 아버지의 현재 행위를 점진적으로 드러냄.
핵심 긴장: "다은이 아버지 얘기를 꺼내면 다은이가 무너진다" — 보호 동기.
Archetype: affect_flattening — 아버지 사기라는 무거운 주제를 건조하게 말함.

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | "다은이 아버지 얘기는 꺼낼 수 없다" (거부) | deny | none |
| S1 | **"좀 이상한 낌새를 본 건 맞다" — 모호한 인정** | hedge | hint |
| S2 | **"예비신랑에게 돈 얘기를 꺼내고 있었다"** | partial | partial |
| S3 | **"예전에 제게 했던 방식과 너무 똑같았다" — 패턴 일치** | partial | partial |
| S4 | **"그래서 또 당하게 두면 안 되겠다는 생각에 예비신랑을 직접 붙잡았다" — 연락 동기 확정** | emotional | partial |
| S5 | **"다은이에게 말하면 아버지 얘기까지 다 무너질까 봐, 또 제가 나쁜 사람 되는 쪽을 택했다"** | confess | full |

### B d-3 질문유형별 레퍼런스

| State | 사실추궁 | 동기탐색 | 공감접근 |
|-------|---------|---------|---------|
| S0 | "다은이 아버지 얘기는 꺼낼 수 없습니다" | "그건 다은이한테 너무 큰 일이 됩니다" | "그 얘기를 제 입으로 하면 안 됩니다" |
| S1 | "좀 이상한 낌새를 본 건 맞습니다" | "우연히 알게 됐습니다. 일부러 캔 게 아닙니다" | "알고 싶지 않은 걸 알게 됐습니다" |
| S2 | "예비신랑에게 돈 얘기를 꺼내고 있었습니다" | "'결혼 전에 잠깐만 도와주면 금방 돌려준다' 같은 말이었습니다" | "그 문자를 보는 순간 예전 일이 떠올랐습니다" |
| S3 | "예전에 제게 했던 방식과 너무 똑같았습니다" | "'사위 될 사람이면 이 정도는 믿어야지' — 그때도 비슷한 말을 들었습니다" | "같은 문구, 같은 방식입니다. 사람이 바뀐 게 아닙니다" |
| S4 | "그래서 또 당하게 두면 안 되겠다는 생각에 예비신랑을 직접 붙잡았습니다" | "다은이한테 말하면 '왜 우리 아버지를 욕하느냐'가 됩니다. 그래서 예비신랑한테 직접 갔습니다" | "예전에는 말하지 못해서 제가 당했습니다. 이번에는 다른 사람까지 당하게 두고 싶지 않았습니다" |
| S5 | "다은이에게 말하면 아버지 얘기까지 다 무너질까 봐, 또 제가 나쁜 사람 되는 쪽을 택했습니다" | "다은이 아버지를 고발하는 게 아닙니다. 다은이가 상처받지 않게 막으려 한 겁니다" | "결국 또 제가 나쁜 사람이 됐습니다. 알면서도 다른 방법을 모르겠었습니다" |

**B의 S0 톤 주의**: "꺼낼 수 없다"는 화가 아니라 **단호한 선긋기**. 다은이를 보호하려는 의지.

**B의 S3 핵심**: "예전에 제게 했던 방식과 너무 똑같았다" → d-4(과거 사기)로의 직접 브릿지.

**B의 Truth Throttle 주의**:
- S0~S1: "아버지", "돈", "사기" 등 구체어 불가. "이상한 낌새" 수준.
- S2: "돈 얘기를 꺼내고 있었다" — 행위 인정. 구체 문구는 S3.
- S3+: "사위 될 사람이면 이 정도는" 등 직접 인용 가능. "예전에 제게 했던 방식" 언급 가능.
