# Session 1: 쟁점 d-1 심문 ScriptedText 생성

> **쟁점**: B의 연락은 예비신랑 집착인가, 위험 경고인가 (초기 공개 쟁점)
> **채널**: interrogation
> **출력 대상**: A(송다은) + B(최수민), S0~S5, 3 질문유형, 각 5 variant
> **총 entry 수**: 36개 (2 party x 6 state x 3 questionType)
> **총 variant 수**: 180개

---

## 작업 지시

session-0-context 폴더의 세 파일(PROJECT-CONTEXT, QUALITY-RULES, OUTPUT-FORMAT)을 숙지한 상태에서, 아래 NEW FACT 매핑 테이블을 기반으로 d-1 쟁점의 interrogation 채널 ScriptedText를 생성해주세요.

### 출력 형식

```json
{
  "session": "session-1-d1-interrogation",
  "channel": "interrogation",
  "disputeId": "d-1",
  "entries": [
    {
      "key": "a|d-1|S0|fact_pursuit",
      "party": "a",
      "disputeId": "d-1",
      "lieState": "S0",
      "questionType": "fact_pursuit",
      "stanceHint": "deny",
      "truthLevel": "none",
      "variants": [
        { "id": "v1", "text": "...", "behaviorHint": "..." },
        { "id": "v2", "text": "...", "behaviorHint": "..." },
        { "id": "v3", "text": "...", "behaviorHint": "..." },
        { "id": "v4", "text": "...", "behaviorHint": "..." },
        { "id": "v5", "text": "...", "behaviorHint": "..." }
      ]
    },
    ... (36개 entry)
  ]
}
```

### 생성 순서

1. A(송다은) — S0 -> S5 순서로, 각 state에서 fact_pursuit -> motive_search -> empathy_approach
2. B(최수민) — S0 -> S5 순서로, 각 state에서 fact_pursuit -> motive_search -> empathy_approach

---

## A(송다은) d-1 NEW FACT 매핑

A는 "B가 예비신랑에게 집착한다"고 확신하는 입장. 과거 손절 경험을 근거로 삼음.
A의 핵심 감정: B가 "또" 자기 주변 남자에게 접근했다는 분노와 배신감.
Archetype: premature_summary (성급한 단정, 기존 서사로 프레이밍, 자기 가설에 확신)

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | B가 예비신랑에게 연락한다는 사실 인지 — "또 시작이다" | deny | none |
| S1 | **연락 기록 확인 — 전화 6번, 문자 11번** | hedge | hint |
| S2 | **단톡방에 올린 사실 인정 + "예전에도 이랬다" 근거 제시** | hedge | hint |
| S3 | **과거 손절 경위 구체화 — "돈 문제 때 수민이가 변했다"** | partial | partial |
| S4 | **자기 행동 돌아봄 — "확인 없이 퍼뜨린 건 맞다"** | emotional | partial |
| S5 | **"예전에도, 이번에도 내가 모르는 사정이 있었을 수 있다" + "먼저 못 박아버린 건 내 잘못"** | confess | full |

### A d-1 질문유형별 레퍼런스

| State | 사실추궁 (fact_pursuit) | 동기탐색 (motive_search) | 공감접근 (empathy_approach) |
|-------|----------------------|------------------------|--------------------------|
| S0 | "손절한 사람이 제 예비신랑한테 전화를 하고 문자를 보냅니다. 9일 동안이요" | "예전에도 이랬습니다. 수민이는 남자 문제가 생기면 선을 모릅니다" | "결혼 3주 전입니다. 그런데 이런 일이 터지니 미칠 것 같습니다" |
| S1 | "연락 기록을 봤습니다. 전화 6번, 문자 11번. 대부분 답도 없는데 계속 보냈습니다" | "답이 없는데도 이렇게 집요하게 연락하는 게 정상적인 겁니까" | "그 기록을 본 순간 손이 떨렸습니다. 예전 생각이 바로 났습니다" |
| S2 | "친구들 단톡방에 올렸습니다. 수민이가 또 내 남자한테 연락한다고" | "예전에 손절한 이유가 있습니다. 그때도 돈이 엮이니까 사람이 달라졌습니다" | "사람이 한 번 보여준 모습은 쉽게 안 바뀝니다. 그래서 확신했습니다" |
| S3 | "예전에 돈 문제가 있었습니다. 수민이가 돈만 엮이면 변했습니다. 그때 저는 손절했고 후회 안 했습니다" | "같은 패턴입니다. 그때도 남한테 접근하더니, 이번에도 제 남자한테 연락합니다" | "10년 넘게 알고 지낸 친구였습니다. 그 손절이 저한테도 쉬웠겠습니까" |
| S4 | "확인을 안 하고 올린 건 맞습니다. 수민이한테 직접 묻지 않았습니다" | "화가 나니까 먼저 말이 나간 겁니다. 맞는지 틀리는지 따질 여유가 없었습니다" | "수민이한테 직접 물을 수가 없었습니다. 물으면 또 말을 돌릴 것 같았으니까" |
| S5 | "예전에도, 이번에도 제가 모르는 사정이 있었을 수 있다는 생각이 듭니다" + "내가 먼저 수민이를 나쁜 사람으로 못 박아버렸습니다" | "아버지 진실을 몰랐다고 해도, 수민이를 두 번이나 같은 방식으로 버린 건 제 잘못입니다" | "수민이가 나한테 말 못 한 이유가 있었다면, 그걸 묻지 않은 것도 제 잘못입니다" |

**S5 주의**: "모르는 사정"(S5a)과 "먼저 못 박은 건 내 잘못"(S5b)을 5개 variant에 분산 배치. v1~v3은 자기 행동 인정 중심, v4~v5는 과거까지 포함한 반성.

**A의 정보 비대칭 주의**:
- A는 S0~S4에서 예비신랑이 먼저 B에게 접근한 사실을 **모른다**
- A는 S0~S4에서 아버지가 B에게 사기를 친 사실, 아버지가 예비신랑에게 돈 접근 중인 사실을 **모른다**
- S5에서 "모르는 사정이 있었을 수 있다"는 가능성의 인정이지, 구체적 내용을 아는 것이 아님

## B(최수민) d-1 NEW FACT 매핑

B는 연락 사실을 숨기다가 점진적으로 진짜 이유를 드러냄.
B의 핵심 감정: "또 내가 나쁜 사람이 되는구나" — 반복적 희생양의 피로.
Archetype: affect_flattening (감정 무뎌짐, 짧고 담담한 문장, 건조한 톤)

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | 완전 부정 — "집착이라니요" | deny | none |
| S1 | **연락한 사실 인정 + "그런 뜻은 아니었다"** | hedge | hint |
| S2 | **"꼭 전해야 할 말이 있었다" — 용건 존재 인정** | hedge | hint |
| S3 | **"꼬시려는 게 아니라 경고하려고 연락했다"** (경고 내용은 아직 모호) | partial | partial |
| S4 | **"다은이한테는 말할 길이 없었고, 공통 친구를 통하면 바로 소문이 난다"** — 우회 연락 이유 | emotional | partial |
| S5 | **"또 당하게 두고 싶지 않았다. 예전에도 똑같은 걸 봤으니까"** — 보호 동기 + 과거 연결 | confess | full |

### B d-1 질문유형별 레퍼런스

| State | 사실추궁 (fact_pursuit) | 동기탐색 (motive_search) | 공감접근 (empathy_approach) |
|-------|----------------------|------------------------|--------------------------|
| S0 | "제가 왜 걔 남자한테 집착합니까" / "연락 기록이요? 네, 했습니다. 근데 집착은 아닙니다" | "그런 뜻으로 한 게 아닙니다" / "의심받을 이유가 없습니다" | "이런 자리에서 이런 말을 듣게 될 줄 몰랐습니다" / "또 이러는구나, 하는 생각이 들었습니다" |
| S1 | "연락한 건 맞습니다. 그런 뜻은 아니었습니다" | "말하면 더 복잡해질 것 같아서 안 했습니다" | "설명할 기회가 없었습니다. 다은이가 먼저 단정 지었으니까" |
| S2 | "그 사람한테 꼭 전해야 할 말이 있었습니다" | "답이 없으니까 계속 보낸 겁니다. 급한 일이었습니다" | "이렇게까지 해야 하나 싶었지만 멈출 수가 없었습니다" |
| S3 | "꼬시려는 게 아니라 경고하려고 연락했습니다" | "그 사람이 알아야 할 일이 있었습니다. 다은이 대신 제가 전한 겁니다" | "다은이한테 직접 말하면 믿지 않았을 겁니다. 그래서 그 사람한테 갔습니다" |
| S4 | "다은이한테는 말할 길이 없었습니다. 손절당한 사이에서 갑자기 연락하면 더 의심받습니다" | "공통 친구를 통하면 바로 소문이 납니다. 다은이 귀에 이상하게 들어갈 게 뻔했습니다" | "다은이가 저를 어떻게 생각하는지 압니다. 그래서 직접 갈 수가 없었습니다" |
| S5 | "또 당하게 두고 싶지 않았습니다. 예전에도 똑같은 걸 봤으니까요" | "예전에도 같은 일을 봤고, 그때도 말하지 못했습니다. 이번에는 막으려고 했습니다" | "또 제가 나쁜 사람이 됐습니다. 알면서도 그 길밖에 없었습니다" |

**B의 S0 톤 주의**: affect_flattening이므로 감정 폭발이 아닌 **건조한 부정**. "집착이라니요"를 화나서가 아니라 피로감 속에서 말함.
- v1~v2: 담담한 부정 ("그럴 이유가 없습니다")
- v3~v5: 피로감 섞인 반응 ("또 이러는구나 싶었습니다")

**B의 S5 핵심**: "예전에도 똑같은 걸 봤다" → 이것이 d-3(아버지의 돈 접근), d-4(과거 사기)로의 연결 브릿지.

**B의 Truth Throttle 주의**:
- S0~S1: "경고", "아버지", "돈" 등 구체어 절대 불가. "그런 뜻이 아니었다" 수준만.
- S2: "전해야 할 말" — 내용은 아직 비공개. "급한 일"까지만.
- S3: "경고"라는 단어 등장 가능. 단, 경고 내용(아버지 돈 접근)은 아직 비공개.
- S4~S5: 우회 이유, 보호 동기까지 열림. 단, "아버지"의 구체적 행위는 d-3에서 열림.

## d-1 LieState 전이 원문 (참조)

- S0: "제가 왜 걔 남자한테 집착합니까."
- S1: "연락한 건 맞지만 그런 뜻은 아니었습니다."
- S2: "그 사람한테 꼭 전해야 할 말이 있었습니다."
- S3: "꼬시려는 게 아니라 경고하려고 연락했습니다."
- S4: "다은이한테는 말할 길이 없었고, 공통 친구를 통하면 바로 소문이 납니다."
- S5: "또 당하게 두고 싶지 않았습니다. 예전에도 똑같은 걸 봤으니까요."

### 트리거

- 핵심 잠금: "연락한 건 맞다"는 S1, 만나자 한 이유가 경고였다는 건 S3, 왜 A 대신 예비신랑에게 갔는지는 S5에서 열림.
- 트리거 증거: `hard_evidence` `e-4`, `e-5`

## 체크리스트 (생성 후 자체 검증)

- [ ] 각 State에서 이전 State에 없던 NEW FACT가 있는가
- [ ] fact_pursuit / motive_search / empathy_approach가 각각 다른 정보 조각을 주는가
- [ ] 5개 variant가 패러프레이즈가 아니라 다른 측면(기본/디테일A/디테일B/감정/연결)인가
- [ ] Truth Throttle 준수 — B의 S0~S1에서 "경고", "아버지", "돈", "사기" 등 구체 명사 0건
- [ ] 호칭 규칙 — A는 "제 전 친구"/"그 사람", B는 "다은이"/"제 친구", 합니다체
- [ ] 기획 용어 / 쟁점명 원문 / Party코드(A,B) 0건
- [ ] behaviorHint가 코드 태그가 아닌 캐릭터 분위기 묘사인가
- [ ] A 대사에 A가 모르는 사실(예비신랑 선넘기, 아버지 사기, 아버지 돈 접근)이 없는가
- [ ] B의 affect_flattening이 반영됐는가 — 건조하고 짧은 문장, 감정 폭발 아닌 피로감
- [ ] A의 premature_summary가 반영됐는가 — 성급한 단정, "예전에도 이랬다" 프레이밍
- [ ] B의 S5 "예전에도 똑같은 걸 봤다"가 d-3, d-4 연결 브릿지로 작동하는가
