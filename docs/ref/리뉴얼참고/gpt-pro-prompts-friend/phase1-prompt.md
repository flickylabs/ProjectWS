# GPT Pro 요청: friend-01 Phase 1 스크립트

## 목적
재판 시작 시 양측 초기 진술을 자동 재생하는 Phase 1 대화 스크립트 생성.
플레이어는 재판관 역할이며, 중간에 3번의 선택지(재판관 발언)를 고릅니다.

## 사건 정보

**사건**: 손절한 절친
**A**: 송다은(31, 온라인 쇼핑몰 CS 직원) — premature_summary. B와 크게 틀어진 뒤 이미 관계가 끝났다고 단정. B가 예비신랑에게 연락한 사실을 공통 친구들에게 퍼뜨렸다.
**B**: 최수민(31, 필라테스 강사) — affect_flattening. 예비신랑을 꼬시려 한 게 아니라 경고하려 했고, A 아버지에게 당한 일을 말하지 못한 채 스스로 악역이 되었다.

**호칭 규칙**:
- 재판관 → 당사자: "송다은 씨", "최수민 씨"
- A → B 직접: "수민아" (평시) / "최수민!" (격앙)
- B → A 직접: "다은아" (평시) / "송다은!" (격앙)
- A → 재판관에게 B 언급: "제 전 친구"
- B → 재판관에게 A 언급: "다은이" / "제 친구"

**초기 공개 쟁점**: d-1 "B의 연락은 예비신랑 집착인가, 위험 경고인가"
**초기 공개 증거**: e-1(B→예비신랑 연락 기록 9일간), e-2(공통 친구 단톡방 캡처), e-3(과거 손절 직전 카톡)

**핵심 초기 긴장**:
결혼 3주 전, 손절한 전 친구가 예비신랑에게 9일간 전화 6번 문자 11번을 보냈다. A는 "또 내 남자한테 달라붙었다"며 분노. B는 "그런 뜻이 아니었다"고만 할 뿐 이유를 말하지 않는다 — 그래서 더 수상해 보인다. 공통 친구들은 이미 B를 비난하는 중.

## 구조 규칙

1. **총 30~36대사** (system 2개 + 당사자 대사 + 선택지 3세트 + 분기 대사)
2. **system 대사 2개**: 첫 대사(상황 요약), 마지막 대사(Phase 종료 안내)
3. **선택지 3세트** (choiceId: c1, c2, c3):
   - 각 선택지에 **3개 옵션** (재판관이 하는 말)
   - 각 옵션 뒤에 **2~3개 분기 대사** (branchCondition으로 연결)
4. **흐름**:
   - 도입: A가 분노하며 상황 설명 — "손절한 친구가 내 예비신랑에게 9일 동안..."
   - c1: A의 주장을 어떻게 받을지 (B에게 직접 묻기 / A에게 증거 확인 / 양측 진정)
   - 중반: B가 담담하게 "그런 뜻이 아니었다" — 하지만 이유를 말하지 않음
   - c2: B의 침묵을 어떻게 다룰지 (추궁 / 시간 주기 / A에게 과거 경위 묻기)
   - 후반: A가 과거 손절까지 끌어와 B를 공격 — "예전에도 이래서 손절했다"
   - c3: 과거와 현재를 어떻게 다룰지 (과거 먼저 정리 / 현재 연락에 집중 / 양측 입장 분리)
5. **톤 규칙**:
   - A(premature_summary): 단정적, 성급한 결론, 과거와 현재를 한 줄로 묶음. "예전에도 이래서", "또 그런 거잖아"
   - B(affect_flattening): 감정 억제, 말끝이 흐려짐, 이유를 숨김. "... 그런 뜻은 아니었습니다.", "... 말하기가 어렵습니다."
   - 재판관 대상: 합니다체 필수
   - 당사자 간: 반말
6. **금지**: 번역체, "부득이하게", d-2~d-5 내용 직접 언급 (예비신랑이 먼저 찝적댄 것, A 아버지 사기 등은 아직 미발견)
7. **중요**: B는 이유를 모르는 게 아니라 **말할 수 없는 것**. 힌트는 줄 수 있지만 직접 밝히면 안 됨. "사정이 있었다"까지만.
8. **behaviorHint**: 각 대사에 1문장 연출 힌트
