# 솔로몬 법정 — friend-01 ScriptedText 생성 프로젝트

> 이 문서는 GPT Pro가 NPC 대사(ScriptedText)를 생성하기 위한 프로젝트 컨텍스트입니다.
> 모든 세션에서 이 컨텍스트를 참조합니다.

---

## 게임 개요

AI 둘(NPC)의 분쟁을 플레이어(재판관)가 심문하여 진실을 밝혀내는 추리 게임.
플레이어는 질문을 선택하고, NPC는 거짓말 상태(S0~S5)에 따라 점진적으로 진실을 드러냄.

**핵심 원칙: "진실은 플레이어가 직접 밝혀낸다"** — 어떤 채널도 플레이어보다 먼저 답을 말하면 안 됨.

---

## 사건: friend-01

손절한 절친 분쟁. A(송다은)는 B가 자기 예비신랑에게 집착한다고 확신하고, B(최수민)는 경고하려 했을 뿐이라고 주장.
실제로는 B가 A를 보호하려다 매번 악역이 되는 반복 구조.
과거 손절(A 아버지 사기) → 현재 B가 예비신랑에게 연락 → A가 단톡방에 퍼뜨림.

**훅**: 손절한 전 절친이 내 예비신랑에게 계속 연락한다. 결혼 3주 전, 그 장면만 보면 누구라도 친구가 선을 넘었다고 생각한다.

---

## 캐릭터

### A — 송다은 (31, 온라인 쇼핑몰 CS 직원)

- **Archetype**: premature_summary (성급한 단정, 기존 서사로 상대를 프레이밍, 자기 가설에 확신, 자기 전제를 의심하지 않음)
- **숨기는 것 / 결함**:
  1. 확인도 하지 않고 단톡방에서 B를 "또 남자한테 붙었다"고 매도
  2. 과거 손절도 아버지 사기 때문이었다는 진실을 모름 — B가 변한 거라고 단정
  3. 아버지가 지금 예비신랑에게도 같은 방식으로 돈 접근 중이라는 사실을 모름
- **핵심 감정**: B가 "또" 자기 주변 남자에게 접근했다는 분노와 배신감. 과거에도 이랬다는 확신.
- **호칭**:
  - B에게 직접(평소): "수민아"
  - B에게 직접(격앙 시): "최수민!"
  - 재판관에게 상대 언급: "제 전 친구" / "그 사람"

### B — 최수민 (31, 필라테스 강사)

- **Archetype**: affect_flattening (감정적으로 무뎌진 상태. 짧고 담담한 문장. 고통스러운 얘기도 건조하게 함. 이것이 차갑거나 유죄처럼 보이지만 실제로는 반복적으로 희생양이 된 피로감)
- **숨기는 것 / 보호하는 것**:
  1. 예비신랑에게 연락한 진짜 이유 = A 아버지의 돈 접근 경고
  2. 예비신랑이 먼저 B에게 찝적댄 사실 (A 몰래 보자, 이상형 언급 등)
  3. 과거 손절의 진짜 원인 = A 아버지가 B의 돈을 사기로 가져감
  4. 매번 A에게 말하면 아버지 진실이 무너지니까 차마 못 말하고 자기가 악역이 됨
- **핵심 감정**: 두 번 다 A를 지키려다 두 번 다 버림받은 피로와 체념. "또 내가 나쁜 사람이 되는구나."
- **호칭**:
  - A에게 직접(평소): "다은아"
  - A에게 직접(격앙 시): "송다은!"
  - 재판관에게 상대 언급: "다은이" / "제 친구"

## 중반 뒤집기 구조

초반 (`e-1`, `e-2`, `e-3`): B가 손절한 친구의 예비신랑에게 계속 들이대는 사람처럼 보임. A의 분노가 이해됨.

**1차 뒤집기** (`e-4`): 먼저 선을 넘은 건 예비신랑. B의 연락은 집착이 아니라 경계/대응.

**2차 뒤집기** (`e-5`): B가 예비신랑에게 연락한 진짜 이유 = A 아버지의 돈 접근.

**3차 뒤집기** (`e-6`): 과거 손절도 B의 변심이 아니라 A 아버지의 사기.

**최종 확정** (`e-7`): 과거와 현재가 같은 패턴. B가 두 번 다 A를 지키려다 두 번 다 악역이 됨.

## 판결 딜레마

B는 매번 A를 지키려다 말하지 못했고, 결국 매번 A에게 버림받았다. 그렇다고 해서 A의 예비신랑에게 직접 연락한 방식이 완전히 옳았던 것도 아니다.
A는 친구를 잔인하게 몰아붙였지만, 아버지의 진실을 모른 채 반응한 사람이기도 하다. 예비신랑은 B에게 찝적댄 잘못이 있고, 동시에 A 아버지에게 당할 뻔한 피해자이기도 하다.

**재판관 성향 분화**:
- 논리형: A가 더 나쁘다. 직접 확인도 없이 단톡방에서 B를 먼저 매도했고, 과거 오해까지 반복해 사회적 낙인을 찍었다.
- 직관형: B가 더 나쁘다. 마음은 이해돼도 이번에도 말을 비틀고 우회해 결국 더 큰 오해를 만든 건 B 자신의 선택이었다.
