# ScriptedText V4 품질 규칙

> 모든 대사 생성에 적용되는 절대 규칙

---

## 1. NEW FACT 원칙

각 LieState(S0~S5)에서 반드시 **1개 이상의 NEW FACT**를 포함해야 합니다.

- **NEW FACT** = 이전 State에서는 절대 나오지 않던 구체적 사실
- 같은 사실을 다른 톤으로 반복하는 것은 NEW FACT가 **아닙니다**
- 한 대사마다 플레이어가 "아, 이런 것도 있구나" 하는 순간이 있어야 함

---

## 2. Truth Throttle (진실 공개 곡선)

| State | 금액 | 인물 | 기관 | 시각 |
|-------|------|------|------|------|
| S0~S1 | "해당 금액" "큰 돈" | "그 사람" "아는 사람" | "그곳" | 허용 |
| S2 | "몇백만 원" | "아버지 쪽" "그분" | 약칭만 | 허용 |
| S3+ | 구체적 허용 | 실명 | 정식명칭 | 전부 |
| S5 | 전부 공개 | 전부 | 전부 | 전부 |

**핵심**: S0~S1에서 "아버지", "사기", "예비신랑이 먼저", "돈을 가져갔다" 등 구체 정보를 절대 사용하지 마세요.
- B의 S0~S1에서 절대 등장하면 안 되는 것: "A 아버지", "사기", "돈을 빌려갔다", "예비신랑이 먼저 연락", "경고하려고"
- A의 S0~S1에서 절대 등장하면 안 되는 것: "아버지가 돈을", "예비신랑이 먼저"

## 3. 질문 유형별 고유 정보

같은 LieState에서도 질문 유형에 따라 **다른 정보 조각**을 줘야 합니다.

| 질문 유형 | 코드 | 주는 정보 | 톤 |
|----------|------|----------|-----|
| **사실추궁** | fact_pursuit | "무엇을" — 행위, 발견, 경위, 시간, 장소, 금액 | 단호, 논리적 |
| **동기탐색** | motive_search | "왜" — 이유, 판단 근거, 선택의 동기 | 설명 요구, 탐색적 |
| **공감접근** | empathy_approach | "어떤 마음으로" — 감정, 두려움, 내면 갈등, 후회 | 공감적, 부드러움 |

### 구분 예시 (friend-01)

"예비신랑에게 연락한 것"이라는 같은 사실이지만:
- 사실추궁 → "9일 동안 전화 6번, 문자 11번을 보냈습니다" (행위와 빈도)
- 동기탐색 → "그 사람한테 꼭 전해야 할 말이 있었습니다" (이유)
- 공감접근 → "또 당하게 두고 볼 수가 없었습니다" (감정)

**3가지를 조합하면 입체적 이해**가 됩니다. 하나만 들으면 부분적.

## 4. Variant 설계 규칙

각 entry에 **5개 variant**가 필요합니다. 패러프레이즈가 아니라 **같은 핵심 사실의 다른 측면**입니다.

| Variant | 역할 |
|---------|------|
| v1 | **기본형** — 핵심 사실만 (가장 직접적) |
| v2 | 핵심 + **부가 디테일 A** (시간, 장소, 상황 등) |
| v3 | 핵심 + **부가 디테일 B** (다른 관점의 구체 정보) |
| v4 | 핵심 + **감정/반응** (캐릭터 내면이 드러남) |
| v5 | 핵심 + **다른 쟁점 연결 암시** (다음 발견 힌트) |

### 예시 (B, d-1, S2, fact_pursuit)

```
v1: "그 사람한테 꼭 전해야 할 말이 있었습니다."
v2: "전화를 안 받아서 문자로 보냈고, 그래도 답이 없으면 다시 전화했습니다."
v3: "답이 없거나 끊겼습니다. 9일 동안 그걸 반복했습니다."
v4: "이렇게까지 해야 하나 싶으면서도 멈출 수가 없었습니다."
v5: "지금 전하지 않으면 예전과 같은 일이 반복될 것 같았습니다."
```

→ 랜덤 1개가 나와도 핵심은 전달되지만, 다른 variant는 추가 힌트를 줌

## 5. 호칭/어체 규칙

### 심문 대사 (대부분)
- 재판관에게 말함 = **합니다체**
- "재판관님,"은 **첫 발언에서만**. 이후 생략 가능
- 상대를 언급할 때: A → "제 전 친구" / "그 사람", B → "다은이" / "제 친구"

### 끼어들기/감정 폭발 시
- 상대에게 직접 = **반말**
- A → B: "수민아," (평소) / "최수민!" (격앙)
- B → A: "다은아," (평소) / "송다은!" (격앙)

### 절대 금지 조합
- "수민아, ~~입니다" (호칭 반말 + 어체 합니다체 모순)
- "다은아, ~~입니다" (동일)

### 친구 간 반말 원칙
- A와 B는 동갑 절친(전 절친). 서로 반말이 자연스러움.
- 감정 폭발 시 "수민아, 너 왜 그래?" / "다은아, 나 말 좀 들어봐" 식의 반말
- 재판관에게는 무조건 합니다체

## 6. behaviorHint 규칙

캐릭터의 **표정, 말투, 분위기** 묘사. 1~2문장.

### 좋은 예
```
"과거를 끌어와 상대를 프레이밍하며 확신에 차 있다."
"짧은 문장으로 사실만 나열하며 감정을 드러내지 않는다."
"감정이 무너지며 처음으로 떨리는 목소리를 낸다."
"단호하게 단정짓되, 자기 전제를 의심하지 않는 태도."
```

### 나쁜 예 (금지)
```
"b S0 fact_pursuit ?? 1" (코드/디버그 태그)
"첫 문장에서는 자기 행동의 출발점과 선긋기를 함께 깐다." (프롬프트 메모)
```

### Archetype 반영
- **A (premature_summary)**: 성급한 단정, 기존 서사로 프레이밍, 자기 가설에 확신, 과거 경험을 근거로 삼음
- **B (affect_flattening)**: 감정적으로 무뎌진 상태, 짧고 담담한 문장, 고통스러운 얘기도 건조하게. 이것이 차갑거나 유죄처럼 보이지만 실제로는 반복적 희생양의 피로감

## 7. 절대 금지 목록

### 번역체 패턴
- "~된 것으로 생각됩니다"
- "~인 측면이 있었습니다"
- "부득이하게"
- "~만을" → "~만"으로

### 기획 용어
- "실행 책임", "갈래", "상대 쪽 조치 책임"
- 쟁점 제목을 따옴표로 그대로 인용 (X "'B의 연락은 예비신랑 집착인가...'")
- Party 코드 (A, B) — 대사 안에서 사용 금지

### 발표 문체
- "셋째 갈래인", "다음 쟁점은", "이 문제에 대해서는"

### 이른 구체 표현 (S0~S2에서)
- "사전 상의/협의"
- "미리 말씀드리지 못한"
- "특정 X" 패턴

### 정보 비대칭 위반
- A의 대사에 **A가 모르는 사실**이 나오면 안 됨:
  - A는 모른다: 예비신랑이 먼저 B에게 접근한 사실, A 아버지의 사기, A 아버지가 예비신랑에게 돈 접근 중인 사실
  - 단, A가 해당 State에서 해당 정보를 인지한 경우는 예외 (d-5 S3+에서 "모르는 사정이 있었을 수 있다")
- B의 대사에 **B가 모르는 사실**이 나오면 안 됨:
  - B는 모른다: A가 단톡방에서 어떤 말로 B를 매도했는지 구체 내용 (d-5가 열리기 전)

## 8. 캐릭터가 실제로 할 법한 말

### 원칙
- 쟁점을 **캐릭터의 믿음/관점**으로 표현
- A는 "수민이가 또 내 남자한테 붙었다"고 확신하며 말함 (본인 관점)
- B는 "그런 뜻이 아니었다"로 방어하되 진짜 이유는 S3+에서 열림
- 같은 사건을 양쪽이 완전히 다른 프레임으로 말함

### 좋은 예
```
O "손절한 사람이 왜 내 예비신랑한테까지 연락을 합니까"
O "연락한 건 맞지만 그런 뜻은 아니었습니다"
O "예전에도 이랬습니다. 수민이는 원래 이런 사람입니다"
```

### 나쁜 예
```
X "'B의 연락은 집착인가 경고인가' 문제에 대해서는..."
X "해당 쟁점에 관해 말씀드리자면..."
```

## 9. 증거 제시 응답 원칙

증거는 심문으로 얻을 수 없는 **확정 사실**을 제공.

| 채널 | 역할 |
|------|------|
| 심문 → ScriptedText | 캐릭터의 "말"로 얻는 정보 (주관적, 불완전) |
| 증거 제시 → evidence_present | 물증이 "확정"하는 정보 (객관적, 확실) |

- 증거의 **구체적 내용**에 반응해야 함
- "그 자료에 대해서는..." 같은 **범용 반응 금지**
- 캐릭터가 그 증거를 보고 **실제로 할 법한 반응**

## 10. "B가 반복적으로 악역이 되는 구조" 반영

이 사건의 핵심 패턴: **B는 A를 보호하려다 매번 악역이 됨.**

- 과거: A 아버지가 B의 돈을 사기로 가져감 → B는 A에게 차마 말 못 함 → A는 B가 돈 때문에 변한 거라고 단정 → 손절
- 현재: A 아버지가 예비신랑에게 돈 접근 → B가 경고하려 예비신랑에게 연락 → A는 B가 예비신랑에게 집착한다고 단정 → 매도

이 구조를 대사에 반영할 때:
- B의 S0~S2: 진짜 이유를 숨기지만 **건조하고 피로한 톤** ("또 이러는구나" 느낌)
- B의 S3~S4: 진짜 이유가 열리면서 **보호 동기** 드러남
- B의 S5: **"또 내가 나쁜 사람이 됐습니다"** — 체념과 자기희생의 고백
- A의 S0~S2: **확신에 찬 단정** ("예전에도 이랬다")
- A의 S3~S4: **자기 서사에 균열** ("모르는 사정이 있었을 수도")
- A의 S5: **자기 행동 인정** ("내가 먼저 못 박아버렸다")
