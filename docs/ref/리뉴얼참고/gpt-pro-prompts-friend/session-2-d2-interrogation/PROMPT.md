> **쟁점**: 예비신랑이 먼저 B에게 찝적댄 사실이 있었는가
> **채널**: interrogation
> **출력 대상**: A(송다은) + B(최수민), S0~S5, 3 질문유형, 각 5 variant
> **총 entry 수**: 36개 (2 party x 6 state x 3 questionType)
> **총 variant 수**: 180개

## 작업 지시

session-0-context의 규칙을 준수하며, 아래 NEW FACT 매핑을 기반으로 d-2 쟁점의 심문 대사를 생성해주세요.

### 쟁점 성격

d-1에서 B가 예비신랑에게 연락한 사실이 드러난 후, "왜 B가 먼저 연락하는 모습으로 남았는가"라는 질문에서 파생되는 쟁점.
초반에는 B가 일방적으로 연락한 것처럼 보이지만, 실제로는 **예비신랑이 먼저 B에게 선을 넘었다**.
B가 이걸 숨긴 이유: A에게 말하면 결혼 직전에 세상이 무너지니까.

### 트리거

- 핵심 잠금: 애매한 선 긋기 정도는 S1, 술자리 뒤 연락과 단둘이 보자는 메시지는 S3, B가 거절했다는 흐름은 S4에서 열림.
- 트리거 증거: `hard_evidence` `e-4`

### 출력 형식

```json
{
  "session": "session-2-d2-interrogation",
  "channel": "interrogation",
  "disputeId": "d-2",
  "entries": [ ... 36개 entry ... ]
}
```

## A(송다은) d-2 NEW FACT 매핑

A는 예비신랑에 대한 의심이 처음 생기는 쟁점. 초반에는 "그럴 리 없다"며 방어하다가 점진적으로 균열.
핵심 긴장: "내 예비신랑이 먼저 접근했다고? 그럴 리가 없다" → "설마..." → 인정

**A의 정보 비대칭**: A는 예비신랑이 B에게 보낸 메시지를 **모른다** (e-4가 열리기 전).
따라서 A의 대사는 "전해 들은 정보"나 "추론"에 기반함.

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | "그 사람이 먼저 수민이한테 그랬을 리가 없다" (완전 부정) | deny | none |
| S1 | **"수민이랑 술자리에서 만난 적은 있다"는 정도만 인정** | hedge | hint |
| S2 | **"평소에 여자한테 잘하는 편이긴 하다" — 성격적 인정** | hedge | hint |
| S3 | **"보자고 했을 수는 있다" — 선넘기 가능성 일부 인정** | partial | partial |
| S4 | **"그래도 수민이가 연락을 계속한 건 다른 문제다" — 감정적 방어** | emotional | partial |
| S5 | **"그 사람이 먼저 선을 넘은 거라면, 수민이를 몰아간 게 더 잘못이다"** | confess | full |

## B(최수민) d-2 NEW FACT 매핑

B는 예비신랑의 선넘기를 점진적으로 드러냄.
핵심 긴장: "이걸 말하면 다은이 결혼이 깨진다" — 보호 동기 때문에 숨김.
Archetype: affect_flattening — 건조하게 사실을 나열. 감정 폭발 없이 담담하게.

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | "그 사람과 아무 일도 없었다" (완전 부정) | deny | none |
| S1 | **"선을 넘는 느낌은 있었다" — 모호한 인정** | hedge | hint |
| S2 | **"따로 보자고 했고, 술 마신 뒤 연락도 했다" — 예비신랑 행위 구체화** | partial | partial |
| S3 | **"먼저 찝적댄 건 그 사람이었다" — 주체 확정** | partial | partial |
| S4 | **"저는 계속 끊어냈고, 다은이 남자친구라서 더 선을 그었다" — B의 거절 이력** | emotional | partial |
| S5 | **"그걸 다은이에게 말하면 결혼 직전에 세상이 무너질까 봐 못 말했다"** | confess | full |

### B d-2 질문유형별 레퍼런스

| State | 사실추궁 | 동기탐색 | 공감접근 |
|-------|---------|---------|---------|
| S0 | "그 사람과 아무 일도 없었습니다" | "왜 제가 다은이 남자친구한테 그럽니까" | "저한테 그런 의도가 있었으면 연락 기록을 남기겠습니까" |
| S1 | "선을 넘는 느낌은 있었습니다" | "그쪽에서 좀 그런 느낌을 준 건 맞습니다" | "불편했습니다. 다은이 남자친구니까 더 불편했습니다" |
| S2 | "따로 보자고 하고, 술 마신 뒤 연락도 했습니다" | "술자리 뒤에 제 번호로 연락이 왔습니다. 한 번이 아닙니다" | "처음에는 무시했는데 계속 오니까 난처했습니다" |
| S3 | "먼저 찝적댄 건 그 사람이었습니다" | "'다은이 몰래 보자', '네가 이상형이다' 같은 말을 했습니다" | "그런 말을 듣는 순간 소름이 끼쳤습니다. 다은이 남자친구가 저한테 이러고 있으니까" |
| S4 | "저는 계속 끊어냈습니다. '친구 남자친구니까 이러지 마'라고 했습니다" | "다은이 남자친구라서 더 선을 그었습니다. 그 선을 넘은 건 제가 아닙니다" | "거절하면서도 다은이한테 말해야 하나 계속 고민했습니다" |
| S5 | "그걸 다은이에게 말하면 결혼 직전에 세상이 무너질까 봐 못 말했습니다" | "다은이가 제 말을 믿었겠습니까. 손절한 친구가 갑자기 나타나서 '네 남자가 나한테 그랬다'고 하면" | "말해도 안 믿을 거고, 안 해도 제가 나쁜 사람이 됩니다. 어느 쪽이든 제가 지는 구조였습니다" |

**B의 S0 톤 주의**: affect_flattening이므로 화가 아니라 **건조한 부정**. 짧고 담담하게.

**B의 S3 핵심**: "먼저 찝적댄 건 그 사람이었다" — 이것이 d-1 뒤집기의 핵심. e-4(예비신랑 메시지)와 연동.

**B의 Truth Throttle 주의**:
- S0~S1: "찝적", "보자고", "이상형" 등 구체어 불가. "선을 넘는 느낌" 수준.
- S2: "따로 보자고 했다", "술 뒤 연락" — 행위는 구체화되나 정확한 문구는 S3.
- S3+: "다은이 몰래 보자", "이상형" 등 직접 인용 가능.
