# ScriptedText V4 품질 규칙

> 모든 대사 생성에 적용되는 절대 규칙

---

## 1. NEW FACT 원칙

각 LieState(S0~S5)에서 반드시 **1개 이상의 NEW FACT**를 포함해야 합니다.

- **NEW FACT** = 이전 State에서는 절대 나오지 않던 구체적 사실
- 같은 사실을 다른 톤으로 반복하는 것은 NEW FACT가 **아닙니다**
- 한 대사마다 플레이어가 "아, 이런 것도 있구나" 하는 순간이 있어야 함

---

## 2. Truth Throttle (진실 공개 곡선)

| State | 금액 | 인물 | 기관 | 시각 |
|-------|------|------|------|------|
| S0~S1 | "해당 금액" "큰 돈" | "그 사람" "아는 사람" | "그곳" | 허용 |
| S2 | "200만원대" "몇천만 원" | "김 씨" "가족 쪽" | 약칭만 | 허용 |
| S3+ | 구체적 허용 ("3,000만원") | 실명 ("형", "조카") | 정식명칭 | 전부 |
| S5 | 전부 공개 | 전부 | 전부 | 전부 |

**핵심**: S0~S1에서 "형", "조카", "3,000만원", "위임장" 등 구체 명사를 절대 사용하지 마세요.

---

## 3. 질문 유형별 고유 정보

같은 LieState에서도 질문 유형에 따라 **다른 정보 조각**을 줘야 합니다.

| 질문 유형 | 코드 | 주는 정보 | 톤 |
|----------|------|----------|-----|
| **사실추궁** | fact_pursuit | "무엇을" — 행위, 발견, 경위, 시간, 장소, 금액 | 단호, 논리적 |
| **동기탐색** | motive_search | "왜" — 이유, 판단 근거, 선택의 동기 | 설명 요구, 탐색적 |
| **공감접근** | empathy_approach | "어떤 마음으로" — 감정, 두려움, 내면 갈등, 후회 | 공감적, 부드러움 |

### 구분 예시

"블랙박스를 봤다"는 같은 사실이지만:
- 사실추궁 → "봤더니 매일 같은 좌표가 찍혀 있었습니다" (결과)
- 동기탐색 → "새벽 통화를 듣고 혹시나 해서 봤습니다" (원인)
- 공감접근 → "그걸 보는 순간 손이 떨렸습니다" (감정)

**3가지를 조합하면 입체적 이해**가 됩니다. 하나만 들으면 부분적.

## 4. Variant 설계 규칙

각 entry에 **5개 variant**가 필요합니다. 패러프레이즈가 아니라 **같은 핵심 사실의 다른 측면**입니다.

| Variant | 역할 |
|---------|------|
| v1 | **기본형** — 핵심 사실만 (가장 직접적) |
| v2 | 핵심 + **부가 디테일 A** (시간, 장소, 상황 등) |
| v3 | 핵심 + **부가 디테일 B** (다른 관점의 구체 정보) |
| v4 | 핵심 + **감정/반응** (캐릭터 내면이 드러남) |
| v5 | 핵심 + **다른 쟁점 연결 암시** (다음 발견 힌트) |

### 예시 (A, d-1, S1, fact_pursuit)

```
v1: "차에서 영수증 묶음을 봤습니다. 머리끈, 틴트, 헤어롤이 찍혀 있었습니다."
v2: "영수증에 머리끈, 틴트에 컵라면까지 있었습니다. 누군가 그 집에서 생활하고 있다는 뜻입니다."
v3: "같은 편의점에서 반복 결제였습니다. 오피스텔 근처 편의점이에요."
v4: "그 영수증을 보는 순간 손이 떨렸습니다. 틴트요. 제가 안 쓰는 틴트."
v5: "영수증 날짜를 보니 통장에서 돈이 빠지기 시작한 시점과 겹칩니다."
```

→ 랜덤 1개가 나와도 핵심은 전달되지만, 다른 variant는 추가 힌트를 줌

## 5. 호칭/어체 규칙

### 심문 대사 (대부분)
- 재판관에게 말함 = **합니다체**
- "재판관님,"은 **첫 발언에서만**. 이후 생략 가능
- 상대를 언급할 때: A → "제 남편", B → "제 아내"

### 끼어들기/감정 폭발 시
- 상대에게 직접 = **반말**
- "자기야," (구어체)
- "이준호!" / "박지연!" (격앙 시)

### 절대 금지 조합
- "자기, ~~입니다" (호칭 반말 + 어체 합니다체 모순)

## 6. behaviorHint 규칙

캐릭터의 **표정, 말투, 분위기** 묘사. 1~2문장.

### 좋은 예
```
"억울함을 앞세우며 자기 행동의 선긋기를 시도한다."
"남편에게 직접 반말로 몰아붙이며 감정이 터진다."
"시선을 내리며 최소한의 단어로만 답한다."
"처음으로 눈물을 보이며 목소리가 작아진다."
```

### 나쁜 예 (금지)
```
"a S0 fact_pursuit ?? 1" (코드/디버그 태그)
"첫 문장에서는 자기 행동의 출발점과 선긋기를 함께 깐다." (프롬프트 메모)
```

### Archetype 반영
- **A (victim_cosplay)**: 피해자 포지셔닝, 억울함 과장, 감정 호소, 때로 공격적
- **B (avoidant)**: 최소 발화, 시선 회피, 말끝 흐림, 침묵 후 한마디

## 7. 절대 금지 목록

### 번역체 패턴
- "~된 것으로 생각됩니다"
- "~인 측면이 있었습니다"
- "부득이하게"
- "~만을" → "~만"으로

### 기획 용어
- "실행 책임", "갈래", "상대 쪽 조치 책임"
- 쟁점 제목을 따옴표로 그대로 인용 (✗ "'오피스텔 출입과 새벽 통화는...'")
- Party 코드 (A, B) — 대사 안에서 사용 금지

### 발표 문체
- "셋째 갈래인", "다음 쟁점은", "이 문제에 대해서는"

### 이른 구체 표현 (S0~S2에서)
- "사전 상의/협의"
- "미리 말씀드리지 못한"
- "특정 X" 패턴

### 정보 비대칭 위반
- A의 대사에 **B만 아는 사실**이 나오면 안 됨 (예: A가 "조카"를 언급)
- B의 대사에 **A만 아는 사실**이 나오면 안 됨 (예: B가 "위임장"을 언급)

## 8. 캐릭터가 실제로 할 법한 말

### 원칙
- 쟁점을 **캐릭터의 믿음/관점**으로 표현
- A는 "딴살림"이라고 확신하며 말함 (본인 관점)
- B는 "그건 아니다"로 부정하되 구체적 설명은 안 함 (회피 관점)
- 같은 사건을 양쪽이 완전히 다른 프레임으로 말함

### 좋은 예
```
✓ "'남편의 딴집 살림'을 그냥 넘길 수는 없습니다"
✓ "그런 일 아닙니다"
```

### 나쁜 예
```
✗ "'오피스텔 출입과 새벽 통화는 딴살림 흔적인가' 문제에 대해서는..."
✗ "해당 쟁점에 관해 말씀드리자면..."
```

## 9. 증거 제시 응답 원칙

증거는 심문으로 얻을 수 없는 **확정 사실**을 제공.

| 채널 | 역할 |
|------|------|
| 심문 → ScriptedText | 캐릭터의 "말"로 얻는 정보 (주관적, 불완전) |
| 증거 제시 → evidence_present | 물증이 "확정"하는 정보 (객관적, 확실) |

- 증거의 **구체적 내용**에 반응해야 함
- "그 자료에 대해서는..." 같은 **범용 반응 금지**
- 캐릭터가 그 증거를 보고 **실제로 할 법한 반응**
