# 솔로몬 법정 — spouse-v4-01 ScriptedText 생성 프로젝트

> 이 문서는 GPT Pro가 NPC 대사(ScriptedText)를 생성하기 위한 프로젝트 컨텍스트입니다.
> 모든 세션에서 이 컨텍스트를 참조합니다.

---

## 게임 개요

AI 둘(NPC)의 분쟁을 플레이어(재판관)가 심문하여 진실을 밝혀내는 추리 게임.
플레이어는 질문을 선택하고, NPC는 거짓말 상태(S0~S5)에 따라 점진적으로 진실을 드러냄.

**핵심 원칙: "진실은 플레이어가 직접 밝혀낸다"** — 어떤 채널도 플레이어보다 먼저 답을 말하면 안 됨.

---

## 사건: spouse-v4-01

부부 분쟁. A(박지연, 아내)는 남편의 "딴살림"을 확신하고, B(이준호, 남편)는 사실을 숨기며 방어함.
실제로는 양쪽 모두 상대에게 숨기는 것이 있고, 심문을 통해 점진적으로 드러남.

---

## 캐릭터

### A — 박지연 (아내)

- **Archetype**: victim_cosplay (피해자 포지셔닝, 억울함 앞세움, 과장 경향)
- **숨기는 것**:
  1. 신혼 초부터 B 계좌를 몰래 확인해옴 (사생활 침해)
  2. 위임장을 조작해서 공동 적금 2,000만원 해지 (**범죄**)
  3. 해지한 돈을 투자방에 넣었다가 사기 당함 (전액 손실)
- **핵심 감정**: 남편이 "또" 숨기고 있다는 실망과 분노. 시댁 문제를 숨긴 전과가 있음.
- **호칭**:
  - 재판관에게 상대 언급: "제 남편"
  - 상대에게 직접(감정 폭발 시): "자기야" / "이준호!"

### B — 이준호 (남편)

- **Archetype**: avoidant (최소 발화, 회피, 눈 마주침 회피)
- **숨기는 것**:
  1. 개인 비자금 운용 (아내 몰래)
  2. 비자금에서 3,000만원을 형에게 현금 전달 (아내 동의 없이)
  3. 오피스텔 방문 = 조카 돌봄 (아내에게 설명 안 함)
  4. 시부모 재산 탕진 사실을 이미 알고 있었음 (아내에게 숨김)
- **핵심 감정**: 아내가 돈 문제로 가족(형)을 외면하는 것에 대한 실망. 말하면 이혼까지 갈 것이라는 공포.
- **호칭**:
  - 재판관에게 상대 언급: "제 아내"
  - 상대에게 직접(감정 폭발 시): "자기야" / "박지연!"

## 각방 사유

시부모 사후, 재산(집+토지)을 **형(이성호)이 혼자 상속받아 전부 탕진**한 사실 발각.
- B는 이미 알고 있었지만 A에게 숨김 → A "왜 나한테 말 안 했어?" → 대폭발 → 각방
- 이것이 B가 형 얘기를 못 꺼내는 구조적 이유

## 핵심 드라마 포인트

1. **A가 계좌를 훔쳐봤다는 사실이 터지는 순간** — B: "그걸 어떻게 알아?" → 양쪽 침묵 → 재판관 추궁
2. **위임장 조작이 밝혀지는 순간** — B도 충격, A는 벌받을 각오
3. **경비 증언 "여자 혼자 사는 집이 없다"** — 외도 서사에 첫 균열
4. **참고서 영수증 부각** — "중학생이 왜?" → 조카 연결
5. **형의 개인회생** — B가 현금으로 전달할 수밖에 없었던 이유
