# Session 1: 쟁점 d-1 심문 ScriptedText 생성

> **쟁점**: 오피스텔 방문과 새벽 전화 (초기 공개 쟁점)
> **채널**: interrogation
> **출력 대상**: A(박지연) + B(이준호), S0~S5, 3 질문유형, 각 5 variant
> **총 entry 수**: 36개 (2 party × 6 state × 3 questionType)
> **총 variant 수**: 180개

---

## 작업 지시

session-0-context 폴더의 세 파일(PROJECT-CONTEXT, QUALITY-RULES, OUTPUT-FORMAT)을 숙지한 상태에서, 아래 NEW FACT 매핑 테이블을 기반으로 d-1 쟁점의 interrogation 채널 ScriptedText를 생성해주세요.

```json

      "truthLevel": "none",

        { "id": "v1", "text": "...", "behaviorHint": "..." },
        { "id": "v2", "text": "...", "behaviorHint": "..." },
        { "id": "v3", "text": "...", "behaviorHint": "..." },
        { "id": "v4", "text": "...", "behaviorHint": "..." },
        { "id": "v5", "text": "...", "behaviorHint": "..." }
      ]
    },
    ... (36개 entry)
  ]
}
```

### 생성 순서

1. A(박지연) — S0 → S5 순서로, 각 state에서 fact_pursuit → motive_search → empathy_approach
2. B(이준호) — S0 → S5 순서로, 각 state에서 fact_pursuit → motive_search → empathy_approach

## A(박지연) d-1 NEW FACT 매핑

A는 "딴살림"을 확신하는 입장. 자기가 목격/발견한 것을 토대로 말함.
A의 핵심 감정: 남편이 "또" 숨기고 있다는 실망과 분노. 시댁 문제를 숨긴 전과가 있음.
Archetype: victim_cosplay (피해자 포지셔닝, 억울함, 과장)

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | 오피스텔 존재 인지 | deny | none |
| S1 | **영수증 발견 — 여성/청소년 물품** | hedge | hint |
| S2 | **B의 회피 패턴 구체화 + 각방 사유** | hedge | hint |
| S3 | **B 계좌에서 목돈 출금 발견** (→ d-2 트리거) | partial | partial |
| S4 | **A 자신의 비밀 — 적금 해지 자백** | emotional | partial |
| S5 | **위임장 조작 인정 + 투자 사기 전액 손실** | confess | full |

### A d-1 질문유형별 레퍼런스

| State | 사실추궁 (fact_pursuit) | 동기탐색 (motive_search) | 공감접근 (empathy_approach) |
|-------|----------------------|------------------------|--------------------------|
| S0 | "블랙박스를 보니 매일 같은 주소에 정차해 있었습니다" | "처음엔 야근인가 했는데, 새벽 벨소리를 듣고 혹시나 싶어 블랙박스를 봤습니다" | "육감이라는 게 있나봅니다. 화장실 가려는데 문틈으로 벨소리와 통화 소리가 들렸습니다" |
| S1 | "차에서 영수증 묶음을 봤습니다. 머리끈, 틴트, 헤어롤이 찍혀 있었습니다" | "블랙박스를 본 다음부터 차 안도 확인하게 됐습니다. 한 번 의심이 시작되니 멈출 수가 없었습니다" | "그 영수증을 본 순간 손이 떨렸습니다. 틴트요. 제가 안 쓰는 틴트" |
| S2 | "물어보면 화를 내거나 방문을 잠급니다. 한 번도 제대로 답한 적이 없습니다" | "각방을 쓴 지 8개월이 다 됐습니다. 남편이 숨기는 버릇 때문이에요. 부모님 재산을 형이 다 써버린 것도 숨기고 있었거든요" | "8개월째 같은 집에서 남이처럼 삽니다. 거기에 이 상황까지 겹치니 미칠 것 같았습니다" |
| S3 | "남편 통장에서 큰 돈이 빠진 것도 알고 있습니다" | "오피스텔, 통화, 거기에 돈까지. 세 개가 동시에 겹치니 확신이 된 겁니다" | "차마 말 못 했습니다. 이걸 말하면 제가 통장을 봤다는 것도 들키니까" |
| S4 | "저도 돈을 움직였습니다. 공동 적금을 깼습니다" | "버림받기 전에 제 몫이라도 지키려고 한 겁니다" | "두려웠습니다. 이혼당하면 아무것도 없을 것 같아서" |
| S5 | "위임장에 남편 서명을 제가 썼습니다. 범죄 행위인 것 알고 있습니다" + "그 돈을 투자에 넣었다가 사기를 당해 전부 잃었습니다" | "범죄인 건 압니다. 그 순간에는 살아남는 게 먼저였습니다" + "빨리 불리려다 사기를 당했습니다" | "매일 밤 적금 해지한 날을 후회했습니다" + "남편한테 미안합니다. 되돌리고 싶지만 돈은 사라졌습니다" |

**S5 주의**: 위임장 조작(S5a)과 투자 사기(S5b)를 5개 variant에 분산 배치. v1~v3은 위임장 중심, v4~v5는 투자 사기까지 포함.

**핵심 드라마**: S3에서 "목돈 출금을 알고 있다" 발언 → B "그걸 어떻게 알아?" → 계좌 감시 폭로

## B(이준호) d-1 NEW FACT 매핑

B는 숨기는 입장. 최대한 늦게, 최소한만 말하려 함.
B의 핵심 감정: 아내가 돈 문제로 가족(형)을 외면하는 것에 대한 실망. 말하면 이혼까지 갈 것이라는 공포.
Archetype: avoidant (최소 발화, 회피, 눈 마주침 회피)

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | 완전 부정 (오피스텔 + 새벽전화) | deny | none |
| S1 | **방문 인정 + "아는 사람"** | hedge | hint |
| S2 | **"가족" 범위 + 통화 인정** | hedge | hint |
| S3 | **��형 + 조카 진실** (핵심 반전) | partial | partial |
| S4 | **시댁 갈등 = 침묵 동기** | emotional | partial |
| S5 | **비자금 3,000만원 현금 전달** | confess | full |

### B d-1 질문유형별 레퍼런스

| State | 사실추궁 | 동기탐색 | 공감접근 |
|-------|---------|---------|---------|
| S0 | "그런 일 아닙니다" / "새벽에 전화를 했다고요? 저를 그런 사람으로 보는 겁니까" | "의심받을 이유가 없습니다" / "아내가 왜 이렇게까지 됐는지 저도 모르겠습니다" | "이런 자리에서 이런 말을 들을 줄 몰랐습니다" / "10년을 함께 산 사람한테 이런 의심을 받다니 기가 막힙니다" |
| S1 | "그곳에 간 건 맞습니다. 아는 사람 때문입니다" | "말하면 더 복잡해질 것 같아서 안 했습니다" | "집에 오면 아내 얼굴 보기가 힘들었습니다" |
| S2 | "가족 문제입니다. 전화도 그것과 관련된 전화였습니다" | "집에서 꺼내기 어려운 사정이 있었습니다. 각방까지 간 이유가 있으니까요" | "말하면 더 크게 터질 것 같아서 참았습니다. 이미 8개월째 남남처럼 사는데" |
| S3 | "형네 오피스텔입니다. 조카가 혼자 남는 날이 많아서 밥을 챙기러 갔습니다" | "형은 새벽부터 밤까지 일을 해서 제가 조카를 챙겨야 했습니다" | "조카가 혼자 라면 끓여 먹는 걸 보면 그냥 올 수가 없었습니다" |
| S4 | "형 얘기가 나오면 이혼까지 갈 것 같았습니다" | "부모님 재산 문제로 아내가 저희 집과 사이가 벌어졌습니다. 형 얘기가 또 나오면 끝이라고 생각했습니다" | "아내한테 미안한 거 압니다. 근데 형도 버릴 수 없었습니다" |
| S5 | "제 비자금에서 3,000만원을 빼서 형에게 직접 전달했습니다. 형은 개인회생 중이라 계좌로는 안 됩니다" | "아내 몰래 비자금을 만든 것도, 거기서 큰 돈을 뺀 것도 제 잘못입니다" | "아내가 비자금까지 알고 있었다면, 배신감이 두 배였을 겁니다. 그래도 형을 못 본 척할 수는 없었습니다" |

**S0 주의**: B의 S0는 두 가지 톤이 있음.
- 오피스텔에 대한 담담한 부정 ("그런 일 아닙니다")
- 새벽 전화에 대한 화난 부정 ("저를 그런 사람으로 보는 겁니까")
→ 5개 variant에 두 톤을 분산 배치 (v1~v2 담담, v3~v5 화남 등)

## 체크리스트 (생성 후 자체 검증)

- [ ] 각 State에서 이전 State에 없던 NEW FACT가 있는가
- [ ] fact_pursuit / motive_search / empathy_approach가 각각 다른 정보 조각을 주는가
- [ ] 5개 variant가 패러프레이즈가 아니라 다른 측면(기본/디테일A/디테일B/감정/연결)인가
- [ ] Truth Throttle 준수 — S0~S1에서 "형", "조카", "3,000만원", "위임장" 등 구체 명사 0건
- [ ] 호칭 규칙 — A는 "제 남편", B는 "제 아내", 합니다체
- [ ] 기획 용어 / 쟁점명 원문 / Party코드(A,B) 0건
- [ ] behaviorHint가 코드 태그가 아닌 캐릭터 분위기 묘사인가
- [ ] A 대사에 B만 아는 사실(형, 조카, 개인회생)이 없는가
- [ ] B 대사에 A만 아는 사실(위임장, 투자 사기, 계좌 감시)이 없는가
- [ ] S3의 A "목돈 출금" 언급이 d-2 트리거로서 자연스러운가
