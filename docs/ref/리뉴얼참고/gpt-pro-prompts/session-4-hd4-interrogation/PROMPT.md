# Session 4: 쟁점 h-d4 심문 ScriptedText 생성

> **쟁점**: 누가 먼저 숨기고 움직였는가 (최종 쟁점)
> **채널**: interrogation
> **출력 대상**: A(박지연) + B(이준호), S0~S5, 3 질문유형, 각 5 variant
> **총 entry 수**: 36개
> **총 variant 수**: 180개

---

## 작업 지시

session-0-context의 규칙을 준수하며, 아래 NEW FACT 매핑을 기반으로 h-d4 쟁점의 심문 대사를 생성해주세요.

### 쟁점 성격

d-2(비자금) + h-d3(적금 해지) 모두 공개된 후 자동 발현하는 **메타 쟁점**.
구체적 사실보다 **"누가 먼저 숨겼는가, 누가 더 잘못했는가"**에 대한 양쪽의 관점을 다룸.
감정의 깊이가 가장 깊고, 양쪽 모두 자기 잘못을 인정해가는 과정.

### 출력 형식

```json
{
  "session": "session-4-hd4-interrogation",
  "channel": "interrogation",
  "disputeId": "h-d4",
  "entries": [ ... 36개 entry ... ]
}
```

---

## 선후관계 팩트 (h-d4의 객관적 기준)

| 항목 | 먼저 한 쪽 |
|------|-----------|
| 숨김 시작 | B (비자금 + 형 상황 은폐) |
| 계좌 감시 | A (신혼 초부터) |
| 돈 실행 | 동시기 — B 4개월 전 출금, A 6주 전 적금 해지 |
| 범죄 행위 | A (위임장 조작) |

**핵심**: 순서를 따지면 명확한 "먼저"가 없음. 양쪽 모두 상대가 먼저라고 생각.

---

## A(박지연) h-d4 NEW FACT 매핑

A는 "먼저 배신당한 쪽"이라고 주장하다가, 점진적으로 자기 행동도 인정.
핵심 전환: "남편이 먼저" → "하지만 내 감시도 먼저" → "위임장은 내 잘못"

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | "숨긴 건 남편이 먼저" | blame | none |
| S1 | **"하지만 계좌 감시는 내가 먼저" 인정** | hedge | hint |
| S2 | **선후 관계 복잡성 인식** | partial | partial |
| S3 | **위임장 조작이 "먼저 움직인 것"임을 인정** | partial | partial |
| S4 | **감정적 총정리** (5,000만원 사라짐) | emotional | partial |
| S5 | **완전 인정** (계좌감시 + 위임장 + 사기 = 전부 내 선택) | confess | full |

### A h-d4 질문유형별 레퍼런스

| State | 사실추궁 | 동기탐색 | 공감접근 |
|-------|---------|---------|---------|
| S0 | "비자금도, 오피스텔도, 시댁 문제도 남편은 항상 솔직하지 못했습니다" | "저는 지키기 위해 대비를 한 것뿐입니다" | "먼저 배신당한 사람이 저입니다" |
| S1 | "통장을 몰래 본 건... 신혼 때부터입니다" | "의심이 있어서가 아니라 불안해서 시작했습니다" | "사랑해서 확인한 거였는데, 언제부터 감시가 됐는지 모르겠습니다" |
| S2 | "제가 먼저 본 건 맞지만, 숨긴 건 남편이 먼저입니다" | "보는 것과 숨기는 것은 다릅니다" | "누가 먼저인지 따지기 시작하면 끝이 없습니다" |
| S3 | "위임장 조작까지 한 것은 명백한 제 잘못 맞습니다" | "남편은 숨기는 잘못을 했지만, 저는 범죄를 저질렀습니다" | "이걸 인정하는 게 제일 어렵습니다" |
| S4 | "5,000만원이 사라졌습니다. 남편 3,000만원, 저 2,000만원" | "서로 숨기다가 서로 잃은 겁니다" | "남편이 말했으면 저도 안 그랬을 거고, 제가 물어봤으면 남편도 말했을 겁니다" |
| S5 | "계좌 감시, 위임장 조작, 사기 피해. 전부 제 선택입니다" | "남편 탓을 하고 싶지만 절반은 제 탓입니다" | "이 자리에서 처음으로 전부 말했습니다. 이제 판단해 주십시오" |

## B(이준호) h-d4 NEW FACT 매핑

B는 "나쁜 의도는 아니었다"에서 시작해 상호 신뢰 부재를 인정해감.
핵심 전환: "나쁜 남편 아니다" → "감시당했다는 충격" → "둘 다 못 믿은 결혼" → "내 침묵이 출발점"

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | "숨긴 건 있지만 나쁜 의도는 아니었다" | hedge | none |
| S1 | **"아내 감시는 몰랐다" 충격** | emotional | hint |
| S2 | **각자의 숨김 비교** (비자금 vs 계좌 감시) | partial | partial |
| S3 | **시간순 정리** (숨김=내가 먼저, 감시=아내 먼저) | partial | partial |
| S4 | **아내의 범죄에 대한 태도** (고소 안 할 것 + 내 침묵이 몰았다) | emotional | partial |
| S5 | **완전 인정** (비자금/현금전달/은폐/오피스텔 = 전부 내 잘못) | confess | full |

### B h-d4 질문유형별 레퍼런스

| State | 사실추궁 | 동기탐색 | 공감접근 |
|-------|---------|---------|---------|
| S0 | "비자금도 형 돈도 나쁜 데 쓴 게 아닙니다" | "가족을 지키려고 한 겁니다" | "나쁜 남편이 아닙니다" |
| S1 | "수년째 통장을 봐왔다니... 그건 몰랐습니다" | "그걸 알았으면 처음부터 말했을 겁니다" | "감시당하고 있었다는 게 배신감입니다. 저만 숨긴 게 아니었습니다" |
| S2 | "제가 비자금을 숨겼고, 아내는 계좌를 훔쳐봤습니다. 둘 다 신뢰를 깬 겁니다" | "누가 더 나쁜지 따지는 건 의미 없습니다" | "서로 믿지 못한 결혼이었다는 게 제일 아픕니다" |
| S3 | "숨김은 제가 먼저, 감시는 아내가 먼저, 돈 실행은 동시기입니다" | "순서를 따지면 저부터이지만, 감시를 따지면 아내부터입니다" | "결국 출발점이 없습니다. 처음부터 서로를 못 믿은 겁니다" |
| S4 | "위임장 조작은 범죄입니다. 하지만 거기까지 몰아간 건 제 침묵입니다" | "아내를 고소할 생각은 없습니다" | "아내가 그 지경까지 간 건 제가 아무 말도 안 해서입니다" |
| S5 | "비자금 숨기기, 3,000만원 현금 전달, 시댁 문제 은폐, 오피스텔 숨기기. 전부 제 잘못입니다" | "형을 도운 건 후회 안 합니다. 하지만 아내한테 숨긴 건 후회합니다" | "아내도 저도 서로한테 제일 못한 겁니다. 판단해 주십시오" |

---

## h-d4 특별 주의사항

1. **이 쟁점은 d-2 + h-d3이 모두 공개된 후에만 등장** → 양쪽 모두 상대의 비밀을 이미 알고 있는 상태
2. **새로운 "물리적 사실"은 거의 없음** → 대신 **해석, 감정, 관점의 변화**가 NEW FACT
3. **양쪽 모두 S5에서 "판단해 주십시오"로 마무리** → 재판관(플레이어)에게 판단을 넘김
4. **감정 깊이가 가장 깊은 쟁점** — behaviorHint도 가장 감정적이어야 함

## 체크리스트

- [ ] h-d4의 NEW FACT가 "물리적 사실"이 아닌 "해석/감정의 변화"인가
- [ ] A가 S0에서 "남편이 먼저"로 시작해 S5에서 "절반은 내 탓"으로 변화하는가
- [ ] B가 S0에서 "나쁜 의도 아님"에서 S5에서 "전부 내 잘못"으로 변화하는가
- [ ] B의 S1에서 "계좌 감시 충격"이 자연스러운가 (d-2에서 알게 된 사실)
- [ ] 양쪽 S5가 재판관에게 판단을 넘기는 톤인가
- [ ] 5 variant = 패러프레이즈가 아닌 다른 측면
- [ ] behaviorHint가 감정 깊이를 반영하는가
