# Session 3: 쟁점 h-d3 심문 ScriptedText 생성

> **쟁점**: 공동 적금 2,000만원 해지 (숨김 → 연쇄 발견)
> **채널**: interrogation
> **출력 대상**: A(박지연) + B(이준호), S0~S5, 3 질문유형, 각 5 variant
> **총 entry 수**: 36개
> **총 variant 수**: 180개

---

## 작업 지시

session-0-context의 규칙을 준수하며, 아래 NEW FACT 매핑을 기반으로 h-d3 쟁점의 심문 대사를 생성해주세요.

### 쟁점 발견 경로

d-2 발견 후 B가 역공 → "그쪽도 적금 건드린 거 아니냐" → 새 쟁점 부상.
A가 숨기는 쪽이고, B는 피해자 측이면서 상호 책임을 인식해가는 구조.

### 출력 형식

```json
{
  "session": "session-3-hd3-interrogation",
  "channel": "interrogation",
  "disputeId": "h-d3",
  "entries": [ ... 36개 entry ... ]
}
```

## A(박지연) h-d3 NEW FACT 매핑

A는 적금 해지 사실을 숨기려 하다가 점진적으로 드러냄.
핵심 긴장: **위임장 조작 = 범죄** → 이걸 인정하는 것이 가장 어려움.

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | "적금은 건드린 적 없다" (거짓) | deny | none |
| S1 | **"이혼 대비"라는 심리 인정** | hedge | hint |
| S2 | **"돈을 따로 움직였다" 부분 인정** | partial | partial |
| S3 | **위임장 사용 + 금액** (2,000만원 해지) | partial | partial |
| S4 | **투자 사기 피해** (전액 손실) | emotional | partial |
| S5 | **위임장 조작 = 범죄 인정 + 전체 반성** | confess | full |

### A h-d3 질문유형별 레퍼런스

| State | 사실추궁 | 동기탐색 | 공감접근 |
|-------|---------|---------|---------|
| S0 | "공동 적금은 그대로입니다" | "왜 제가 적금을 건드립니까" | "그건 우리 미래를 위한 돈입니다. 손 댈 이유가 없습니다" |
| S1 | "만약을 위해 알아본 적은 있습니다" | "이혼하면 반도 못 받을까 봐 불안했습니다" | "남편이 딴살림을 차린 줄 아는데, 가만있으면 바보 아닙니까" |
| S2 | "일부를 빼두려 한 건 맞습니다" | "방어였습니다. 먼저 당하기 싫었습니다" | "겁이 났습니다. 빈손으로 쫓겨날까 봐" |
| S3 | "공동 적금 2,000만원을 해지했습니다. 위임장을 써서 혼자 했습니다" | "남편이 먼저 돈을 빼돌렸으니 저도 지킬 권리가 있다고 생각했습니다" | "지금 생각하면 미친 짓이었습니다. 그때는 정상적인 판단이 안 됐습니다" |
| S4 | "그 돈을 투자방에 넣었습니다. 빨리 불리려고. 전부 사기였습니다" | "친구가 보내준 링크를 믿었습니다. 확인도 안 하고 넣었습니다" | "2,000만원이 하루 만에 사라졌습니다. 누구한테 말할 수도 없었습니다" |
| S5 | "위임장에 남편 서명을 제가 썼습니다. 범죄 행위인 것 알고 있습니다" + "계좌 감시, 위임장 조작, 사기 피해. 전부 제 선택입니다" | "범죄인 건 압니다. 그 순간에는 살아남는 게 먼저였습니다" + "남편 탓을 하고 싶지만 절반은 제 탓입니다" | "남편한테 미안합니다. 되돌리고 싶지만 돈은 사라졌습니다" + "이 자리에서 처음으로 전부 말했습니다. 이제 판단해 주십시오" |

**S5 주의**: 위임장 조작 인정(S5a)과 전체 반성(S5b)을 5개 variant에 분산. v1~v3은 위임장 중심, v4~v5는 전체 총정리.

## B(이준호) h-d3 NEW FACT 매핑

B는 적금이 해지된 사실에 충격받고, 점진적으로 상호 책임을 인식함.
핵심 전환: 피해자에서 → "나도 잘못이 있다" 인정

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | "적금에 대해서는 모른다" | hedge | hint |
| S1 | **"뭔가 이상하다" 감지** (아내가 돈 얘기 피함) | hedge | hint |
| S2 | **적금 잔액 확인 → 충격** (해지 발견) | partial | partial |
| S3 | **위임장 문제 인지** (동의 없이 해지 불가능한데?) | partial | partial |
| S4 | **상호 책임 인식** (자기도 먼저 숨겼음) | emotional | partial |
| S5 | **자기 책임 인정** (비자금/현금전달/은폐 = 출발점) | confess | full |

### B h-d3 질문유형별 레퍼런스

| State | 사실추궁 | 동기탐색 | 공감접근 |
|-------|---------|---------|---------|
| S0 | "공동 적금은 아내가 관리하고 있습니다" | "그쪽은 아내 영역이었습니다" | "적금 통장은 아내가 관리해서 저는 따로 신경쓰지 않고 있었습니다" |
| S1 | "최근에 아내가 돈 얘기를 피하는 게 느껴졌습니다" | "원래 가계부 얘기를 자주 했는데 어느 순간 안 하기 시작했습니다" | "불안한 건 저만이 아니었나 봅니다" |
| S2 | "확인해봤더니 적금이 해지되어 있었습니다" | "제가 한 게 아닙니다. 아내가 한 겁니다" | "그걸 봤을 때 머리가 하얘졌습니다" |
| S3 | "공동 명의인데 어떻게 제 동의도 없이 해지가 가능했는지 모르겠습니다" | "제가 비자금을 숨긴 것과 아내가 적금을 깬 것은 차원이 다릅니다" | "이렇게까지 할 줄은 몰랐습니다. 어디서부터 잘못된 건지 모르겠습니다" |
| S4 | "제가 먼저 숨겼으니 아내를 탓만 할 수는 없습니다" | "제가 말했으면 아내가 이런 선택을 안 했을 겁니다" | "둘 다 무너진 겁니다. 순서가 다를 뿐" |
| S5 | "비자금을 숨긴 것, 형에게 보낸 것, 아내한테 설명 안 한 것. 이게 다 출발점입니다" | "아내의 범죄는 아내 책임이지만, 거기까지 몰아간 건 저입니다" | "위임장 조작이라니. 그만큼 절박했다는 뜻 아닙니까. 그걸 만든 게 접니다" |

## 체크리스트

- [ ] A의 S0이 "완전 부정"인가 (거짓말 — 실제로는 해지함)
- [ ] A의 S3에서 금액(2,000만원)과 위임장이 처음 등장하는가
- [ ] B의 충격 → 분노 → 상호 책임 인식 감정 흐름이 자연스러운가
- [ ] B의 S3에서 "어떻게 동의 없이?"가 위임장 조작 힌트를 자연스럽게 내는가
- [ ] Truth Throttle: A의 S0~S1에서 "2,000만원", "위임장" 미등장
- [ ] 5 variant = 패러프레이즈가 아닌 다른 측면
- [ ] 정보 비대칭 유지
