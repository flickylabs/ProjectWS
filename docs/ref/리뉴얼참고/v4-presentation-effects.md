## 확정된 연출 항목

### 1. NEW FACT 드러남

**트리거**: LieState 전이 시 새로운 사실이 나올 때
**연출**:
- 대사 표시 후 **0.3초 일시 정지**
- 화면 하단에 **"새로운 사실 발견"** 배너 슬라이드인
- 타임라인에 포인트 추가 애니메이션
- 짧은 효과음 (톤: 발견/인사이트)
**예시**: A가 S1에서 "영수증에 틴트가 찍혀 있었습니다" → 배너 + 증거 수첩 업데이트

### 2. 숨겨진 쟁점 발견

**트리거**: d-2, h-d3, h-d4 쟁점 부상 시
**연출**:
- 대화 일시 중단
- 화면 중앙에 **쟁점 카드가 슬라이드인** (좌→우)
- 쟁점 이름 + 1줄 설명 표시
- 발언 노트에 새 탭 추가 (글로우)
- 효과음 (톤: 긴장/전환)
**예시**: A가 "목돈 빠진 것도 안다" → [d-2: 비자금 3,000만원 출금] 카드 등장

### 3. 조합 성공

**트리거**: 조합 슬롯에 유효한 쌍을 넣고 실행 시
**연출**:
- 두 카드가 **중앙으로 이동하며 합쳐지는 애니메이션**
- 합쳐진 후 **결과 팝업** (새 쟁점 / 업그레이드 / 질문 해금)
- 관련 UI 요소에 **글로우 강조** (증거 수첩, 발언 노트, 핫바 등)
- 효과음 (톤: 성취/발견)
**예시**: 영수증 + 형 문자 → "중학교 참고서 + 가은이 = 중학생 조카?!" 팝업

### 4. 모순 발견

**트리거**: 같은 캐릭터의 이전 발언과 현재 발언이 모순될 때
**연출**:
- 양쪽 발언이 **나란히 화면에 표시** (좌:이전, 우:현재)
- **⚡ 표시** + 빨간 밑줄
- 발언 노트에 모순 항목 자동 추가 (글로우)
- 효과음 (톤: 경고/잡았다)
**예시**: B "야근입니다" → B "아는 사람 때문입니다" ⚡

### 5. S5 자백

**트리거**: 캐릭터가 S5(완전 자백)에 도달할 때
**연출**:
- 배경 톤 변화 (어두운 계열 → 차분한 계열)
- 캐릭터 이모지 변화 (resigned 표정)
- 대사 표시 속도 약간 느림 (타이핑 딜레이 증가)
- 배경음 전환 (긴장 → 해소)
- **"[캐릭터명]이(가) 모든 것을 인정했습니다"** 시스템 메시지
**예시**: A가 "위임장에 남편 서명을 제가 썼습니다" → 분위기 전환

### 6. 끼어들기

**트리거**: interjection 조건 충족 시
**연출**:
- 현재 대화 흐름 중단
- 상대 캐릭터가 **화면 옆에서 슬라이드인** (강조)
- 끼어들기 대사 표시 + 팝업 선택지 [허용] [제지]
- 효과음 (톤: 긴장/끼어듦)
- **허용 시**: 반격 질문 버튼이 대화 영역에 등장 (1턴 한정, 펄스 글로우)
- **제지 시**: 캐릭터가 멈추는 애니메이션 + "입을 다물지만 불만이 쌓입니다"

### 7. 판결 진입

**트리거**: Phase 3 시작 시
**연출**:
- 화면 서서히 전환 (심리 UI → 판결 UI)
- **"이제 판결을 내려야 합니다"** 타이핑 연출
- 확인된 사실 / 모순 / 미해결 목록 요약 표시
- 배경음 전환 (진행 → 결정)

### 8. 판결문 생성

**트리거**: Step 4 진입 시
**연출**:
- 판결문이 **한 줄씩 타이핑 연출**로 표시
- 점수(통찰/권위/지혜) **카운터 애니메이션** (0→최종값)
- 칭호 **등장 효과** (슬라이드업 + 글로우)
- 배경음 (톤: 마무리/여운)

## 추가 필요 항목

### 9. 증거 조사 디테일 해금

**트리거**: investigationStage 진행 시
**연출**:
- 증거 수첩에서 "(미확인 항목)" → 실제 내용으로 전환
- 전환 시 **타이핑 연출** + 글로우
- 핵심 항목(참고서 등) 해금 시 별도 강조
**예시**: e-1 영수증 3번째 조사 → "서점: 중학교 참고서" 등장 + "중학교?"

### 10. 증인 소환 해금

**트리거**: 증인 소환 조건 충족 시
**연출**:
- 핫바의 [증인 소환] 버튼이 비활성→활성 전환
- **펄스 글로우** + "새 증인을 소환할 수 있습니다" 시스템 메시지
- 증인 아이콘 등장 효과

### 11. 증인 증언 핵심 순간

**트리거**: 증인이 결정적 증언을 할 때 (depth=full)
**연출**:
- 증인 대사에 **강조 마크** (★)
- 관련 증거/발언 자동 연결 표시
- 효과음 (톤: 결정적 발견)
**예시**: 경비 "그 층에 여자 혼자 사는 집은 없는 걸로 압니다" → ★ + 외도 가설에 균열

### 12. 결정적 질문(DossierCard) 해금

**트리거**: 조합 또는 조건 충족으로 DossierCard 해금 시
**연출**:
- 화면 중앙에 **카드 등장 애니메이션** (아래→위)
- "결정적 질문을 발견했습니다" 시스템 메시지
- 핫바에 일시적 특수 버튼 추가 또는 심문 시 자동 선택지에 포함
- 효과음 (톤: 중요 발견)

### 13. 쟁점 연쇄 발견 (드라마 비트)

**트리거**: d-2 → h-d3 → h-d4 연쇄 시
**연출**:
- 각 쟁점 발견 시 이전 쟁점 카드가 **연결선으로 이어지는** 시각 효과
- "사건의 전모가 드러나고 있습니다" 시스템 메시지 (h-d4 발현 시)
- 발언 노트 탭이 순차적으로 추가되며 타임라인에 연쇄 포인트 표시

### 14. 계좌 감시 폭로 순간 (B의 충격)

**트리거**: A가 d-2에서 계좌 감시를 암시/고백, B가 "그걸 어떻게 알아?" 반응 시
**연출**:
- B 캐릭터 이모지 **갑작스런 변화** (침착→놀람)
- 화면 **약간의 흔들림** (카메라 쉐이크 0.2초)
- "양쪽 모두 침묵" 시스템 메시지
- 이 순간 끼어들기 확률 100% (보장)

### 15. 위임장 조작 폭로 순간

**트리거**: A가 h-d3 S3+에서 위임장 조작 인정, 또는 e-7 제시 시
**연출**:
- **화면 전체 톤 변화** (잠시 어두워짐 → 복원)
- "중대한 사실이 드러났습니다" 시스템 메시지
- B 캐릭터 반응 (충격 → 할 말 잃음)
- 타임라인에 "범죄" 태그와 함께 포인트 추가
