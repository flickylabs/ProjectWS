## V4에서 달라진 핵심 (V3 대비)

### 서사 변경
- B의 3,000만원: 공동적금이 아니라 **개인 비자금에서 출금 → 형에게 현금 전달**
- A의 2,000만원: **공동 적금을 위임장 조작해서 해지** (범죄)
- 각방 사유: 시부모 재산 형 탕진 → B가 숨김 → A 분노
- 증인: 형/조카 제거 → **경비(빈번 방문), 은행직원(위임장), 박미라(투자방 링크)**
- 증거: 카드명세서→**영수증 5장 묶음**, 출입기록→**블랙박스 GPS/네비**

### 3개 액션 차별화
- **사실추궁**: "무슨 일이 있었습니까?" → 행위/발견/경위
- **동기탐색**: "왜 그랬습니까?" → 이유/판단/선택의 동기
- **공감접근**: "그때 어떠셨습니까?" → 감정/심리/내면 상태
→ 같은 State에서도 3가지 질문에 **다른 정보 조각**이 나옴. 이 차별화를 리뉴얼 시 유지해야 함.

### Variant 5종 = 다른 측면 (패러프레이즈 아님)
- v1: 기본형 / v2: 부가 디테일A / v3: 부가 디테일B / v4: 감정/반응 / v5: 다른 쟁점 연결 암시
