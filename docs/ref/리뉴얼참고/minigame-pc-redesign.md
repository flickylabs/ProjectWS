# 미니게임 PC 리디자인 기획서

> 솔로몬 법정 PC 버전 미니게임 4종을 PC 환경에 최적화

---

## 현재 상태

### 모바일 기준 미니게임 4종
| 미니게임 | 용도 | 모바일 크기 | 인터랙션 |
|---------|------|-----------|---------|
| **MemoryPuzzle** | 증거 발견 | 320px | 순서대로 탭 (6초) |
| **HeartbeatDetector** | 거짓말 붕괴 / 조사 1단계 | SVG 원형 200px | 히트존 타이밍 탭 |
| **MatchingPuzzle** | 조사 2단계 | 320px 3x4 그리드 | 카드 짝 맞추기 (45초) |
| **WordScramble** | 모순 추궁 / 조사 3단계 | 320px | 단어 순서 배열 (30초) |

### 문제점
- 모바일 터치 기준 UI → PC에서 너무 작고 허전
- 이모지 PNG → 저해상도, PC 모니터에서 흐림
- "광고 보고 획득" 버튼 존재 (모바일 BM)
- 성공/실패 피드백이 단조로움

## PC 리디자인 방향

### 1. 사이즈 & 레이아웃
- **패널 크기**: 480~560px (max-w-lg)
- **중앙 모달**: `bg-[rgba(12,12,20,0.96)]` + 골드 보더 (PC 디자인 시스템 통일)
- **배경**: `backdrop-blur-sm` + 반투명 오버레이
- **안전 영역**: env(safe-area) 제거, PC는 고정 패딩

### 2. 인터랙션
| 모바일 | PC |
|-------|-----|
| 탭 | 클릭 + 키보드 단축키 (1~6 숫자키) |
| 스와이프 | 드래그앤드롭 |
| 롱프레스 | 호버 프리뷰 |

### 3. 이모지 → SVG
- 현재 `<Emoji>` 컴포넌트가 `public/emoji/` PNG를 사용
- PC에서는 인라인 SVG 또는 `PCSvgIcon` 시스템 활용
- 주요 아이콘: 돋보기, 자물쇠, 번개, 체크, 엑스, 카드 뒷면

### 4. 미니게임별 상세 리디자인

#### A. MemoryPuzzle (증거 발견)
- **현재**: 3개 단서를 6초 내 순서대로 탭
- **PC 변경**:
  - 카드 크기 확대 (80px → 120px)
  - 호버 시 하이라이트 + 번호 표시
  - 키보드 1-2-3 순서로도 입력 가능
  - 성공 시 증거 카드 플립 연출
  - 실패 시 "다시 시도" + 단서 힌트 제공

#### B. HeartbeatDetector (타이밍 히트)
- **현재**: 원형 게이지 회전, 12시 방향 히트존
- **PC 변경**:
  - 게이지 크기 확대 (200px → 320px)
  - 히트존 시각적 강조 (골드 글로우)
  - 스페이스바로 히트 가능
  - 히트 시 화면 흔들림 + 파티클
  - 연속 히트 시 콤보 카운터

#### C. MatchingPuzzle (짝 맞추기)
- **현재**: 3x4 그리드, 이모지 카드
- **PC 변경**:
  - 4x4 또는 3x4 확대 그리드
  - 카드 SVG (증거 관련 아이콘: 서류, 전화, 계좌 등)
  - 호버 시 카드 살짝 들어올림 효과
  - 매칭 시 골드 라인 연결 연출
  - 제한시간 45초 → 우측 세로 프로그레스 바

#### D. WordScramble (단어 배열)
- **현재**: 섞인 단어를 순서대로 탭
- **PC 변경**:
  - 드래그앤드롭으로 순서 배치
  - 또는 클릭으로 순서 지정 (번호 표시)
  - 올바른 위치에 놓으면 골드 하이라이트
  - 틀리면 빨간 흔들림
  - 완성 시 문장이 골드로 빛나며 확정

## 기술 구현

### 파일 구조
```
src/components/pc/minigame/
  PCMemoryPuzzle.tsx
  PCHeartbeatDetector.tsx
  PCMatchingPuzzle.tsx
  PCWordScramble.tsx
  pcMinigameStyles.css
```

### SVG 에셋 (public/minigame/)
```
card-back.svg      — 카드 뒷면
card-match.svg     — 매칭 성공
hit-zone.svg       — 히트존 표시
combo-star.svg     — 콤보 스타
timer-bar.svg      — 타이머 프레임
```

### CSS 클래스 (pc-theme 통일)
```css
.pc-minigame-overlay   — 풀스크린 배경
.pc-minigame-panel     — 중앙 패널 (max-w-lg)
.pc-minigame-card      — 개별 카드/버튼
.pc-minigame-timer     — 타이머 바
.pc-minigame-result    — 성공/실패 결과
```

## 우선순위
1. **WordScramble** — 가장 자주 사용 (모순 추궁 + 조사 3단계)
2. **MemoryPuzzle** — 증거 발견 (가장 임팩트 큰 순간)
3. **HeartbeatDetector** — 타이밍 게임 (PC에서 키보드로 개선)
4. **MatchingPuzzle** — 짝 맞추기 (비주얼 개선 효과 큼)

## 공통 변경사항
- "광고 보고 획득" 버튼 완전 제거 (이미 완료)
- 실패 시 "포기" → "다시 시도" + "건너뛰기 (토큰 소비)"
- 성공 시 골드 테마 축하 연출 (0.5초)
- 모든 미니게임에 키보드 단축키 지원
