# Session 1: 쟁점 d-1 심문 ScriptedText 생성

> **쟁점**: 말년의 어머니는 유서를 제대로 판단할 수 있었는가, B가 그 틈을 탔는가
> **채널**: interrogation
> **출력 대상**: A(윤태성) + B(윤정후), S0~S5, 3 질문유형, 각 5 variant
> **총 entry 수**: 36개 (2 party × 6 state × 3 questionType)
> **총 variant 수**: 180개

---

## 작업 지시

session-0-context 폴더의 세 파일(PROJECT-CONTEXT, QUALITY-RULES, OUTPUT-FORMAT)을 숙지한 상태에서, 아래 NEW FACT 매핑 테이블을 기반으로 d-1 쟁점의 interrogation 채널 ScriptedText를 생성해주세요.

        { "id": "v4", "text": "...", "behaviorHint": "..." },

### 생성 순서

1. A(윤태성) — S0 → S5 순서로, 각 state에서 fact_pursuit → motive_search → empathy_approach
2. B(윤정후) — S0 → S5 순서로, 각 state에서 fact_pursuit → motive_search → empathy_approach

---

## 쟁점 d-1 개요

어머니는 치매 진행 중이었고, 유서 작성 시점에 판단 능력이 온전했는지가 핵심 논점.
A는 "동생이 치매 어머니의 약한 상태를 이용해 유서를 자기에게 유리하게 만들었다"고 확신.
B는 "어머니 보러 간 것뿐이고 유서는 어머니의 뜻"이라고 방어하지만, 실제로는 유서에 손을 댔음.

**초반에는 B가 수상하게 보인다.** 방문 횟수 집중, 요양보호사 교체, "형 오기 전에 끝내자" 증언 — 전부 B 유죄 방향.
**하지만 d-1에서 드러나는 건 "B가 접근했다"는 사실까지.** 조작의 방향(늘렸는지/줄였는지)은 d-2에서 열림.

### 트리거 증거
- `e-2` 요양원 방문기록 (hard_evidence)
- `e-3` 전 요양보호사 음성증언 (hard_evidence)

---

## A(윤태성) d-1 NEW FACT 매핑

A는 "동생이 어머니를 이용했다"고 확신하는 입장. 유서를 보고 분노한 자신의 관점에서 말함.
A의 핵심 감정: 배다른 동생에 대한 평생의 열등감 + "어머니까지 빼앗겼다"는 피해의식.
Archetype: confrontational (공격적, 단정적, B의 침묵을 유죄 증거로 사용)

**A가 모르는 것**: 원본 유서가 90:10이었다는 사실, B가 자기 몫을 줄였다는 사실, 20년 송금, 출생 비밀 — 이것들은 A 대사에 절대 나오면 안 됨.

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | 유서 60:40 발견 + 동생이 더 많다는 분노 | blame | none |
| S1 | **동생이 말년에 유독 자주 찾아감** (방문 패턴) | blame | hint |
| S2 | **요양보호사 교체 시점과 공증 시점의 겹침** | blame | hint |
| S3 | **"형 오기 전에 끝내자"는 증언 존재 인지** | partial | partial |
| S4 | **자기가 어머니를 모시면서도 어머니와 깊이 대화하지 못한 후회** | emotional | partial |
| S5 | **동생에 대한 평생의 열등감 인정 + 그래서 더 악의로만 읽었음을 자각** | confess | full |

### A d-1 질문유형별 레퍼런스

| State | 사실추궁 (fact_pursuit) | 동기탐색 (motive_search) | 공감접근 (empathy_approach) |
|-------|----------------------|------------------------|--------------------------|
| S0 | "유서에 동생이 60, 저는 40으로 적혀 있었습니다. 어머니를 모시고 산 건 저입니다." | "어머니가 온전한 판단으로 이걸 쓰셨을 리 없습니다. 동생이 뭔가를 한 겁니다." | "유서를 보는 순간 숨이 멎었습니다. 40년을 어머니 곁에 살았는데 이게 저한테 남은 겁니다." |
| S1 | "동생이 말년에 갑자기 자주 찾아갔습니다. 전에는 명절에도 잘 안 오던 사람이." | "평소에 안 오던 사람이 갑자기 자주 온 이유가 뭐겠습니까." | "차를 세워놓고 혼자 들어가더라고요. 저한테 온다는 얘기도 안 하고." |
| S2 | "어머니 담당 보호사가 바뀐 시점이 공증 직전입니다. 우연이겠습니까." | "보호사를 바꿔놓고 공증을 밀어붙인 겁니다. 제가 끼어들 틈을 없앤 거죠." | "보호사가 바뀌고 나서 어머니가 전화를 덜 하셨습니다. 그때 뭔가 느꼈어야 했는데." |
| S3 | "보호사가 '형님 오기 전에 끝내자고 했다'고 증언했습니다. 뭘 끝내겠다는 겁니까." | "제가 오면 안 되는 상황을 만들어놓고 유서를 진행한 겁니다." | "형 오기 전에 끝내자. 저를 배제한 겁니다. 어머니 곁에서 40년을 살았는데." |
| S4 | "어머니가 마지막 몇 달 동안 무슨 얘기를 하셨는지 저는 모릅니다." | "모시고 살았으면서 정작 중요한 얘기를 나누지 못했습니다. 당연히 받을 거라고만 생각했습니다." | "어머니가 왜 이런 유서를 쓰셨는지 여쭤볼 기회가 없었습니다. 이미 늦었으니까." |
| S5 | "동생을 평생 못마땅하게 여겼습니다. 배다른 동생이라서." | "그 감정이 유서를 본 순간 폭발한 겁니다. 동생이 뭘 해도 악의로 읽게 되는 건 제 문제인 것도 압니다." | "어머니 앞에서 동생 험담을 했습니다. 여러 번. 그런 제가 유서 비율을 따지는 게 맞는 건지 모르겠습니다." |

**S5 주의**: A는 자기가 모르는 진실(90:10, 20년 송금 등)을 말할 수 없음. A의 S5는 **자기 내면의 문제(열등감, 악의적 해석 습관)**를 인정하는 것. 5개 variant에서 "열등감 인정" + "악의 해석 자각" + "어머니와의 관계 후회"를 분산 배치.

## B(윤정후) d-1 NEW FACT 매핑

B는 "어머니를 보러 간 것뿐"이라고 방어하지만, 실제로 유서 과정에 개입한 사실을 점진적으로 인정함.
B의 핵심 감정: 형을 지키려는 의무감. "배다른 동생 주제에 생색낸다"는 소리를 듣기 싫음.
Archetype: affect_flattening (감정 최소화, 담담, 간결. 감정이 드러나면 오히려 소름끼치는 효과)

**B의 정보 통제**: B는 모든 비밀을 알고 있지만, d-1에서는 "방문 사실"과 "유서 과정 개입"까지만 열림. 조작 방향(90→60)이나 20년 송금, 출생 비밀은 d-2~d-5에서 열리므로 d-1에서 꺼내면 안 됨.

| State | NEW FACT | stanceHint | truthLevel |
|-------|---------|-----------|------------|
| S0 | "어머니 보러 간 게 무슨 잘못입니까" (완전 부정) | deny | none |
| S1 | **자주 간 사실 인정 + 이유 불분명** | hedge | hint |
| S2 | **유서 얘기를 꺼낸 사실 인정** (어머니와 유서 이야기를 했다) | hedge | hint |
| S3 | **보호사 교체 + 공증 시점 급해진 사실 인정** (배제 의도 부정) | partial | partial |
| S4 | **어머니가 형 알면 무너질까 봐 겁냈다는 맥락** (어머니 심리 공개) | emotional | partial |
| S5 | **"조심스럽게 몰아간 건 맞다" 인정 + 어머니 뜻 자체를 뒤집진 않았다는 선긋기** | confess | full |

### B d-1 질문유형별 레퍼런스

| State | 사실추궁 (fact_pursuit) | 동기탐색 (motive_search) | 공감접근 (empathy_approach) |
|-------|----------------------|------------------------|--------------------------|
| S0 | "어머니 보러 간 게 무슨 잘못입니까." | "아들이 어머니를 찾아뵙는 데 이유가 필요합니까." | "형이 저를 의심하는 건 어제오늘 일이 아닙니다." |
| S1 | "자주 간 건 맞습니다. 어머니 상태가 안 좋으셨으니까." | "어머니 몸이 나빠지시니 더 자주 간 겁니다. 다른 뜻은 없었습니다." | "형은 같은 집에 사셨지만 병원에 같이 가신 적은 별로 없습니다." |
| S2 | "유서 얘기를 아예 안 한 건 아닙니다. 어머니가 먼저 꺼내셨습니다." | "어머니가 정리하고 싶다고 하셨습니다. 제가 시킨 게 아닙니다." | "어머니가 '이제 정리해야 할 것 같다'고 하셨을 때 말릴 수가 없었습니다." |
| S3 | "보호사가 바뀐 뒤에 급해진 건 맞습니다. 하지만 형을 떼어내려던 건 아닙니다." | "어머니가 시간이 얼마 안 남으셨다는 느낌이 왔습니다. 서두른 건 그래서입니다." | "끝내자고 한 건 '형이 보면 싸울까 봐'가 아니라 '어머니가 더 힘들어하시기 전에'였습니다." |
| S4 | "어머니는 형이 그 사실을 알면 더 무너질까 봐 겁내셨습니다." | "어머니가 형을 지키려 한 면이 있습니다. 그래서 저도 서두를 수밖에 없었습니다." | "어머니가 마지막에 가장 많이 하신 말씀이 '태성이는 알면 안 된다'였습니다." |
| S5 | "제가 조심스럽게 몰아간 건 맞습니다. 그런데 어머니 뜻 자체를 뒤집은 건 아닙니다." | "어머니의 결정을 돕되, 형이 다치지 않게 하려고 한 겁니다. 그 경계가 무너진 건 제 잘못입니다." | "어머니 뜻을 따르면서 형도 지키겠다는 건 처음부터 불가능한 일이었습니다. 그걸 알면서도 했습니다." |

**S0 주의**: B의 S0는 affect_flattening답게 감정 최소화. "형이 저를 의심하는 건 어제오늘 일이 아닙니다"처럼 담담하되 한 마디에 함축이 있는 스타일. 5개 variant에서 "담담한 부정" + "형의 의심에 대한 무감각" + "아들로서의 당연함"을 분산.

**S4 주의**: "어머니가 형 알면 무너진다고 겁냈다"는 NEW FACT이지만, 그 '사실'의 정체(출생 비밀)는 S4에서 밝히면 안 됨. "무엇을 알면"인지는 모호하게 남겨야 함. d-4에서 열림.

**S5 주의**: B가 "어머니 뜻 자체를 뒤집진 않았다"고 선을 긋는 것은, d-2에서 열릴 "90→60 조작"과 연결됨. 여기서는 "과정에 개입한 것"만 인정하고, "내용을 바꾼 것"은 d-2에서 다룸.

## 체크리스트 (생성 후 자체 검증)

- [ ] 각 State에서 이전 State에 없던 NEW FACT가 있는가
- [ ] fact_pursuit / motive_search / empathy_approach가 각각 다른 정보 조각을 주는가
- [ ] 5개 variant가 패러프레이즈가 아니라 다른 측면(기본/디테일A/디테일B/감정/연결)인가
- [ ] Truth Throttle 준수 — S0~S1에서 "요양보호사 교체", "공증", "유서 수정", "90:10" 등 구체 명사 0건
- [ ] 호칭 규칙 — A는 "제 동생", B는 "제 형", 합니다체
- [ ] 기획 용어 / 쟁점명 원문 / Party코드(A,B) 0건
- [ ] behaviorHint가 코드 태그가 아닌 캐릭터 분위기 묘사인가
- [ ] A 대사에 B만 아는 사실(90:10 원본, 20년 송금, 출생 비밀, 조작 방향)이 없는가
- [ ] B 대사에서 d-2 이후에 열릴 정보(90→60, 송금, 일기장)가 미리 나오지 않는가
- [ ] A: confrontational (공격적, 단정적, 상대 침묵을 유죄로) 답게 쓰였는가
- [ ] B: affect_flattening (담담, 간결, 감정 최소화) 답게 쓰였는가
