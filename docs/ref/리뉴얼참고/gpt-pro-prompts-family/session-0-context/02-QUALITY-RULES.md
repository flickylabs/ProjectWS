# ScriptedText V4 품질 규칙

> 모든 대사 생성에 적용되는 절대 규칙

---

## 1. NEW FACT 원칙

각 LieState(S0~S5)에서 반드시 **1개 이상의 NEW FACT**를 포함해야 합니다.

- **NEW FACT** = 이전 State에서는 절대 나오지 않던 구체적 사실
- 같은 사실을 다른 톤으로 반복하는 것은 NEW FACT가 **아닙니다**
- 한 대사마다 플레이어가 "아, 이런 것도 있구나" 하는 순간이 있어야 함

---

## 2. Truth Throttle (진실 공개 곡선)

| State | 금액 | 인물 | 기관 | 시각 |
|-------|------|------|------|------|
| S0~S1 | "해당 금액" "큰 돈" | "그 사람" "아는 사람" | "그곳" | 허용 |
| S2 | "200만원대" "몇천만 원" | "김 씨" "가족 쪽" | 약칭만 | 허용 |
| S3+ | 구체적 허용 ("90:10") | 실명 ("형", "요양보호사") | 정식명칭 ("공증사무실") | 전부 |
| S5 | 전부 공개 | 전부 | 전부 | 전부 |

**핵심**: S0~S1에서 "90:10", "60:40 원래 비율", "요양보호사 교체", "출생 비밀", "일기장", "송금 내역" 등 구체 명사를 절대 사용하지 마세요.

---

## 3. 질문 유형별 고유 정보

같은 LieState에서도 질문 유형에 따라 **다른 정보 조각**을 줘야 합니다.

| 질문 유형 | 코드 | 주는 정보 | 톤 |
|----------|------|----------|-----|
| **사실추궁** | fact_pursuit | "무엇을" — 행위, 발견, 경위, 시간, 장소, 금액 | 단호, 논리적 |
| **동기탐색** | motive_search | "왜" — 이유, 판단 근거, 선택의 동기 | 설명 요구, 탐색적 |
| **공감접근** | empathy_approach | "어떤 마음으로" — 감정, 두려움, 내면 갈등, 후회 | 공감적, 부드러움 |

### 구분 예시

"유서를 손댔다"는 같은 사실이지만:
- 사실추궁 → "같은 날 두 번 스캔이 찍혀 있고, 마지막 제출자가 제 이름입니다" (결과)
- 동기탐색 → "형이 끝까지 파고들면 더 큰 비밀이 터질까 봐 그랬습니다" (원인)
- 공감접근 → "유서를 고치는 손이 떨렸습니다. 이게 맞는 건지 아직도 모르겠습니다" (감정)

**3가지를 조합하면 입체적 이해**가 됩니다. 하나만 들으면 부분적.

## 4. Variant 설계 규칙

각 entry에 **5개 variant**가 필요합니다. 패러프레이즈가 아니라 **같은 핵심 사실의 다른 측면**입니다.

| Variant | 역할 |
|---------|------|
| v1 | **기본형** — 핵심 사실만 (가장 직접적) |
| v2 | 핵심 + **부가 디테일 A** (시간, 장소, 상황 등) |
| v3 | 핵심 + **부가 디테일 B** (다른 관점의 구체 정보) |
| v4 | 핵심 + **감정/반응** (캐릭터 내면이 드러남) |
| v5 | 핵심 + **다른 쟁점 연결 암시** (다음 발견 힌트) |

### 예시 (B, d-2, S3, fact_pursuit)

```
v1: "90을 60으로 바꿨습니다. 제가 한 겁니다."
v2: "공증사무실에서 같은 날 두 번 제출했습니다. 앞 서류가 90, 뒤 서류가 60입니다."
v3: "어머니가 쓴 원래 유서는 저에게 90을 남기는 것이었습니다. 그걸 60으로 줄였습니다."
v4: "조작이라는 말이 맞습니다. 그 이름으로 부르셔도 됩니다. 제가 한 건 맞으니까."
v5: "왜 자기 몫을 줄였냐고 물으시면, 유서 말고도 숨기고 있는 것이 있습니다."
```

→ 랜덤 1개가 나와도 핵심은 전달되지만, 다른 variant는 추가 힌트를 줌

## 5. 호칭/어체 규칙

### 심문 대사 (대부분)
- 재판관에게 말함 = **합니다체**
- "재판관님,"은 **첫 발언에서만**. 이후 생략 가능
- 상대를 언급할 때: A → "제 동생", B → "제 형"

### 끼어들기/감정 폭발 시
- 상대에게 직접 = **반말**
- A → B: "정후야," (구어체) / "윤정후!" (격앙 시)
- B → A: "형," (구어체) / "윤태성!" (격앙 시)

### 절대 금지 조합
- "정후야, ~~입니다" (호칭 반말 + 어체 합니다체 모순)
- "형, ~~입니다" (호칭 반말 + 어체 합니다체 모순)

## 6. behaviorHint 규칙

캐릭터의 **표정, 말투, 분위기** 묘사. 1~2문장.

### 좋은 예
```
"주먹을 쥐며 상대를 직접 가리킨다."
"담담하게 말하지만 손끝이 미세하게 떨린다."
"재판관을 보지 않고 바닥을 보며 한 마디씩 끊어 말한다."
"처음으로 목소리가 갈라지며 감정이 드러난다."
```

### 나쁜 예 (금지)
```
"a S0 fact_pursuit ?? 1" (코드/디버그 태그)
"첫 문장에서는 자기 행동의 출발점과 선긋기를 함께 깐다." (프롬프트 메모)
```

### Archetype 반영
- **A (confrontational)**: 공격적, 단정적, 상대를 직접 가리킴, 목소리 높임, B의 침묵을 유죄로 삼음
- **B (affect_flattening)**: 감정 최소화, 무표정, 담담한 어조, 시선 고정, 간결한 문장. 감정이 드러날 때는 소름끼치는 대비 효과

## 7. 절대 금지 목록

### 번역체 패턴
- "~된 것으로 생각됩니다"
- "~인 측면이 있었습니다"
- "부득이하게"
- "~만을" → "~만"으로

### 기획 용어
- "실행 책임", "갈래", "상대 쪽 조치 책임"
- 쟁점 제목을 따옴표로 그대로 인용 (✗ "'말년의 어머니는 유서를 제대로 판단할 수 있었는가'에 대해서는...")
- Party 코드 (A, B) — 대사 안에서 사용 금지

### 발표 문체
- "셋째 갈래인", "다음 쟁점은", "이 문제에 대해서는"

### 이른 구체 표현 (S0~S2에서)
- "사전 상의/협의"
- "미리 말씀드리지 못한"
- "특정 X" 패턴

### 정보 비대칭 위반
- A의 대사에 **B만 아는 사실**이 나오면 안 됨 (예: A가 "90:10 원본" 언급, A가 "출생 비밀" 언급, A가 "20년 송금" 언급)
- B의 대사에 **A만 아는 사실**이 나오면 안 됨 (A만 아는 건 거의 없으나, A의 내면 감정/동기를 B가 단정하면 안 됨)

**A가 모르는 것** (B만 아는 사실):
- 90:10 원본 유서의 존재
- 유서를 90에서 60으로 줄인 사실
- 20년 송금의 진짜 출처 (B 돈)
- A의 출생 비밀 (아버지의 친자 아님)
- 어머니 일기장의 내용

## 8. 캐릭터가 실제로 할 법한 말

### 원칙
- 쟁점을 **캐릭터의 믿음/관점**으로 표현
- A는 "동생이 어머니를 이용했다"고 확신하며 말함 (본인 관점)
- B는 "형은 모르는 것이 있다"고 암시만 하되 구체적 설명은 늦춤 (flat 관점)
- 같은 사건을 양쪽이 완전히 다른 프레임으로 말함

### 좋은 예
```
✓ "어머니가 돌아가신 뒤에 나온 유서에 동생이 60을 가져간다고 돼 있었습니다"
✓ "제가 손댄 건 맞습니다"
```

### 나쁜 예
```
✗ "'말년의 어머니는 유서를 제대로 판단할 수 있었는가' 문제에 대해서는..."
✗ "해당 쟁점에 관해 말씀드리자면..."
```

## 9. 증거 제시 응답 원칙

증거는 심문으로 얻을 수 없는 **확정 사실**을 제공.

| 채널 | 역할 |
|------|------|
| 심문 → ScriptedText | 캐릭터의 "말"로 얻는 정보 (주관적, 불완전) |
| 증거 제시 → evidence_present | 물증이 "확정"하는 정보 (객관적, 확실) |

- 증거의 **구체적 내용**에 반응해야 함
- "그 자료에 대해서는..." 같은 **범용 반응 금지**
- 캐릭터가 그 증거를 보고 **실제로 할 법한 반응**
