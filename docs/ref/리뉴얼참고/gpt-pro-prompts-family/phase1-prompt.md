# GPT Pro 요청: family-01 Phase 1 스크립트

## 목적
재판 시작 시 양측 초기 진술을 자동 재생하는 Phase 1 대화 스크립트 생성.
플레이어는 재판관 역할이며, 중간에 3번의 선택지(재판관 발언)를 고릅니다.

## 사건 정보

**사건**: 치매 어머니의 유서
**A**: 윤태성(48, 주방가구 공장 대표) — confrontational. 어머니를 모시고 살았다는 이유로 자신이 당연히 더 받아야 한다고 믿음. 평생 B를 깎아내려 왔다.
**B**: 윤정후(44, 자동차부품 가게 운영) — affect_flattening. 유서를 직접 손댄 건 맞지만 자기 몫을 줄인 조작이었고, 20년간 형과 어머니를 몰래 도우며 형의 출생 비밀까지 지켜 왔다.

**호칭 규칙**:
- 재판관 → 당사자: "윤태성 씨", "윤정후 씨"
- A → B 직접: "정후야" (평시) / "윤정후!" (격앙)
- B → A 직접: "형" (평시) / "윤태성!" (격앙)
- A → 재판관에게 B 언급: "제 동생"
- B → 재판관에게 A 언급: "제 형"

**초기 공개 쟁점**: d-1 "말년의 어머니는 유서를 제대로 판단할 수 있었는가"
**초기 공개 증거**: e-1(60:40 유서 사본), e-2(요양원 방문기록), e-3(전 요양보호사 음성증언)

**핵심 초기 긴장**:
어머니 사후 유서를 열었더니 B 60%, A 40%. A는 평생 어머니를 모시고 산 자신이 40%라는 데 분노. B가 치매 어머니를 움직였다고 확신. B는 담담하게 부인 — 그래서 더 수상해 보인다.

## 구조 규칙

1. **총 30~36대사** (system 2개 + 당사자 대사 + 선택지 3세트 + 분기 대사)
2. **system 대사 2개**: 첫 대사(상황 요약), 마지막 대사(Phase 종료 안내)
3. **선택지 3세트** (choiceId: c1, c2, c3):
   - 각 선택지에 **3개 옵션** (재판관이 하는 말)
   - 각 옵션 뒤에 **2~3개 분기 대사** (branchCondition으로 연결)
4. **흐름**:
   - 도입: A가 먼저 격앙된 톤으로 억울함을 토로
   - c1: A의 주장을 어떻게 받을지 (B에게 직접 묻기 / A에게 더 듣기 / 양측 진정)
   - 중반: B가 담담하게 반박, A가 더 공격적으로
   - c2: B의 태도를 어떻게 다룰지 (추궁 / 보호 / 넘어가기)
   - 후반: 핵심 긴장 고조 — "왜 60:40인지" 양측 최초 대립
   - c3: 이 문제를 어떻게 시작할지 (증거부터 / 감정부터 / 보류)
5. **톤 규칙**:
   - A(confrontational): 공격적, 단정적, 희생 강조. "내가 어머니를 모시고 살았는데..."
   - B(affect_flattening): 감정 억제, 짧은 문장, 데이터 중심. "... 유서를 건드린 적 없습니다."
   - 재판관 대상: 합니다체 필수
   - 당사자 간: 반말
6. **금지**: 번역체, "부득이하게", "~된 것으로 생각됩니다", 쟁점 d-2~d-5 내용 언급 (아직 발견 전)
7. **behaviorHint**: 각 대사에 1문장 연출 힌트 (표정, 몸짓, 말투 묘사)
