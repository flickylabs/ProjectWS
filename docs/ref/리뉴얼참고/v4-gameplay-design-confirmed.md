## 1. 핫바: 맥락 중심 단일 바

### F1/F2/F3 페이지 전환 폐지 → 6슬롯 고정 바

```
[사실추궁] [동기탐색] [공감접근] [증거 제시▼] [증인 소환] [메뉴▼]
  1키        2키        3키        4키          5키       6키
```

- **1~3**: 심문 3종 (항상 활성)
- **4: 증거 제시▼** — 클릭 시 보유 증거 목록 드롭다운
- **5: 증인 소환** — 소환 가능한 증인이 없으면 **비활성화(잠금)**. 해금되면 활성 + 글로우
- **6: 메뉴▼** — 저빈도 액션 드롭다운
  - 분리 심문
  - 비공개 보호
  - 즉답 요구
  - 기록 정리 (요약 스킬)
  - 단계 진행

### 키보드

- **1~6**: 슬롯 직접 선택
- **F1/F2/F3 삭제** — 페이지 전환 없음

### 끼어들기 발생 시

핫바 변경 **없음**. 대신 **팝업 선택지**가 대화 영역 위에 표시:

```
┌─────────────────────────────────────┐
│  B(이준호)가 끼어듭니다              │
│  "그쪽도 적금 건드린 거 아니냐!"     │
│                                     │
│  [허용]        [제지]               │
└─────────────────────────────────────┘
```

- 허용 시: 끼어들기 내용 기반 **반격 질문**이 대화 영역에 일시 표시 (1턴 한정)
  - 예: "적금 건드렸습니까?" 버튼 → 클릭 시 h-d3 트리거 + 조합 보너스
- 제지 시: "상대가 입을 다물지만, 불만이 쌓입니다" 텍스트

## 2. 스킬 시스템

### 2-1. 조합 스킬 — 우패널 하단 2슬롯

```
┌─────────────────────────────────┐
│ [슬롯A: 비어있음] + [슬롯B: 비어있음] │
│           → [조합 실행]              │
└─────────────────────────────────┘
```

**입력 방법**:
- 증거 노트, 발언 노트에서 **드래그앤드롭** 또는 **Shift+클릭**

**결과 유형 3가지**:

| 유형 | 효과 | 예시 |
|------|------|------|
| **새 쟁점 발견** | 숨겨진 쟁점(h-d3, h-d4) 조합으로 발견 가능 | e-5 출금 + e-3 통화 → d-2 부상 가속 |
| **증거 업그레이드** | 기존 증거의 해석이 변경됨 | e-1 영수증 + e-2 GPS → "오피스텔 근처에서만 구매" |
| **결정적 질문 해금** | DossierCard 해금 | e-1 영수증 + e-4 형 문자 → "참고서+가은이=중학생 조카" |

**spouse-v4 조합 레시피**:

| 조합 | 결과 | 유형 |
|------|------|------|
| e-1 영수증 + e-2 GPS | "오피스텔 근처에서만 구매" 패턴 확정 | 증거 업그레이드 |
| e-1 영수증 + e-4 형 문자 | "참고서 + 가은이 = 중학생 조카" 가설 | 결정적 질문 해금 |
| e-5 출금내역 + e-3 통화기록 | "출금 시점과 통화 빈도 일치" | 새 쟁점 발견 (d-2) |
| e-6 투자방 + e-7 해지서류 | "적금 해지→투자→사기" 전체 경로 확정 | 증거 업그레이드 |
| A발언("목돈") + e-5 출금 | "A가 계좌를 봐왔다" 확정 | 결정적 질문 해금 |
| B발언("가족") + e-4 형 문자 | "가족 = 형" 특정 | 결정적 질문 해금 |

**불가능한 쌍**: "이 조합에서는 새로운 것을 발견할 수 없습니다"

### 2-2. 요약 스킬 → "기록 정리"

**위치**: 메뉴▼ 안에 배치
**턴 소비**: 없음 (정보 정리 전용)

```
┌─ 기록 정리 ─────────────────────────┐
│                                     │
│ ■ 확인된 사실                        │
│   ✓ B가 오피스텔에 다니고 있다        │
│   ✓ B가 "아는 사람" 때문이라고 했다   │
│   ? A가 목돈 출금을 알고 있다 (경위?) │
│                                     │
│ ■ 미해결 의문                        │
│   • 오피스텔에 누가 사는가?           │
│   • 3,000만원은 어디로 갔는가?        │
│   • A는 계좌를 어떻게 알게 됐는가?    │
│                                     │
│ ■ 모순 발견                          │
│   ⚡ B: "야근" → "아는 사람" (진술 변경) │
│                                     │
│              [닫기]                   │
└─────────────────────────────────────┘
```

- **확인된 사실**: LieState 전이 + 증거 조사로 확정된 것
- **미해결 의문**: 아직 밝혀지지 않은 핵심 질문 → 플레이어에게 방향 유도
- **모순 발견**: contradictionMeta 기반 자동 수집

### 2-3. 끼어들기 보강

현재 구현 유지 + 다음 보강:

1. **끼어들기 허용 시 "반격 질문" 자동 생성**
   - 끼어든 내용을 기반으로 후속 질문이 대화 영역에 일시 표시 (1턴)
   - 예: B "적금 건드린 거 아니냐" → [A에게: "적금 건드렸습니까?"] 버튼
   - 클릭 시 쟁점 트리거 + 조합 보너스

2. **끼어들기 제지 시 비용 텍스트 명확화**
   - "권위 -2" 수치 대신 서사적 텍스트: "상대가 입을 다물지만, 불만이 쌓입니다"

## 3. 노트 시스템

### 3-1. 증거 노트 → "증거 수첩"

좌패널 상단. 증거별 카드에 발견 메모 자동 기록.

```
┌─ e-1: 영수증 묶음 ──────────┐
│ [획득] B의 차에서 A가 발견    │
│                              │
│ ■ 발견한 내용:               │
│   • 편의점: 컵라면, 삼각김밥  │
│   • 올리브영: 머리끈, 틴트    │  ← 처음엔 이것만
│   • (미확인 항목 3개)        │  ← 조사 진행 시 공개
│                              │
│ ■ 관련 발언:                 │
│   B S1: "그건 제가 산 겁니다" │  ← 자동 연결
│                              │
│ ★ 조합 힌트                  │
└──────────────────────────────┘
```

- investigationStages 진행 → 미확인 항목이 하나씩 공개
- **참고서** 공개 순간이 "앗!" 포인트
- 관련 발언 자동 연결 (해당 증거에 대한 NPC 반응)
- 조합 슬롯에 드래그 가능

### 3-2. 발언 노트 → "양측 발언 비교 뷰"

좌패널 하단. 평소 제목 1줄씩 / 클릭 시 확장.

**기본 뷰 (축소)**:

```
┌─ 발언 노트 ──────────────────┐
│ [d-1] [d-2] [전체]            │
│                               │
│ A: "매일 같은 곳에 들어간다"   │
│ B: "그런 일 아닙니다"          │
│ A: "영수증에 틴트가..."       │
│ B: "아는 사람 때문입니다"      │
│ ⚡ 모순: B 진술 변경           │
│ ...                           │
└───────────────────────────────┘
```

**확장 뷰 (쟁점 탭 클릭 시)**:

```
┌─ d-1에 대한 발언 ───────────────────────┐
│ ┌───────────────┬───────────────┐       │
│ │ A (박지연)     │ B (이준호)     │       │
│ │ "매일 같은 곳  │ "그런 일      │       │
│ │  에 들어간다"  │  아닙니다"     │       │
│ │       ↓       │       ↓       │       │
│ │ "영수증에      │ "아는 사람     │       │
│ │  틴트가..."    │  때문입니다"   │       │
│ │       ↓       │       ↓       │       │
│ │ "목돈도 빠졌다"│ "가족 문제     │       │
│ │  ⚡ 모순!      │  입니다"      │       │
│ └───────────────┴───────────────┘       │
│                                         │
│ ⚡ A "목돈 빠짐" ↔ B "비자금 모름"       │
│                                         │
│ [Shift+클릭으로 조합 슬롯에 추가]        │
└─────────────────────────────────────────┘
```

- 쟁점별 탭: d-1, d-2, h-d3, h-d4, 전체
- 양쪽 대조 배치 → 모순 시각적 확인
- 모순 자동 하이라이트 + 조합 슬롯 드래그 가능
- "전체" 탭 = 기존 시간순 뷰

### 3-3. 타임라인 → "발견 기반 타임라인"

좌패널 확장 버튼으로 열리는 두 번째 레이어 (기존 설계 유지).

```
──●───────────●──────────●──────●──── 현재
  │           │          │      │
 신혼초       8개월전    4개월전  2개월전
  │           │          │      │
 A:계좌확인   각방시작   ???     오피스텔발견
 (S1드러남)   (S2드러남)         (Phase1)
```

- **처음**: Phase1에서 알려진 것만 표시 (거의 빈 타임라인)
- **심문/증거 조사 진행**: 포인트가 하나씩 채워짐 + "기록 추가" 연출
- **"???" 포인트**: "이 시기에 뭔가 있었을 것 같다" 힌트 (조합/심문으로 해금)
- **A 타임라인과 B 타임라인 겹칠 때**: 동시성/모순이 드러남

## 4. 판결 구조 — 4단계

### Step 0: 판결 진입 연출

자유 심리 종료 → "이제 판결을 내려야 합니다" 연출
확인된 사실 / 미해결 의문 / 모순이 한눈에 정리된 요약 팝업

### Step 1: 쟁점별 판단

각 쟁점에 대해 재판관(플레이어)이 판단:

```
d-1: 오피스텔 방문
├── B의 행동은 어떻게 봐야 합니까?
│   ○ 가족을 위한 정당한 행동이었다
│   ○ 배우자에게 알렸어야 했다
│   ○ 숨긴 것 자체가 신뢰를 깬 것이다

d-2: 비자금 3,000만원
├── B의 비자금 운용은?
│   ○ 개인 재산권의 범위 내
│   ○ 부부 공동 재산 위반

h-d3: 적금 해지
├── A의 위임장 조작은?
│   ○ 절박한 상황의 결과 (정상 참작)
│   ○ 명백한 범죄 (법적 책임)

h-d4: 선후관계
├── 누가 더 큰 책임이 있습니까?
│   [슬라이더: A ◄───●───► B]
```

### Step 2: 안건별 책임 판단

각 안건(행동 단위)에 대해 누구 잘못이 더 큰지 판단:

```
■ B의 비자금 은폐 + 3,000만원 무단 사용
  [슬라이더: 경미 ◄──●──► 중대]

■ A의 계좌 감시 (수년간)
  [슬라이더: 경미 ◄──●──► 중대]

■ A의 위임장 조작 + 적금 해지
  [슬라이더: 경미 ◄──●──► 중대]

■ A의 투자 사기 피해 (본인 과실)
  [슬라이더: 경미 ◄──●──► 중대]

■ B의 가족 문제 은폐 (시댁/형/조카)
  [슬라이더: 경미 ◄──●──► 중대]
```

### Step 3: 해결안 선택

```
이 부부에게 어떤 해결을 권고합니까?

□ 재산 정리 후 이혼 절차 (단호한 분리)
□ 상호 사과 + 재산 투명 공개 후 관계 재건 시도
□ A의 법적 책임 고려 + B의 가족 문제 해결 지원 (절충)
□ 전문 상담 의뢰 (관계 회복 우선)
```

### Step 4: 판결문 생성 + 점수

플레이어의 선택을 종합하여 판결문 자동 생성:

```
"본 재판관은 양측 모두의 책임을 인정합니다..."

통찰: 87 (모든 쟁점의 핵심을 파악함)
권위: 72 (절차를 대체로 준수함)
지혜: 91 (양측의 사정을 깊이 헤아린 판결)

칭호: "사려 깊은 재판관"
```

### 점수 산출 핵심

- **통찰**: 진실 발굴 (LieState 진행도, 숨겨진 쟁점 발견 수, 증거 조사 깊이)
- **권위**: 절차 준수 (턴 효율, 증거 남용 없음, 끼어들기 처리)
- **지혜**: 판결 본질 반영 (양쪽 사정 파악, 극단 판결 회피, 해결안 적절성)

**보너스 요소**:
| 조건 | 보너스 | 카테고리 |
|------|--------|---------|
| 모든 숨겨진 쟁점 발견 (d-2, h-d3, h-d4) | +15 | 통찰 |
| 조합으로 결정적 질문 해금 | +10 | 통찰 |
| 양쪽 S3 이상 도달 | +10 | 지혜 |
| 끼어들기 허용 → 반격 질문 사용 | +5 | 권위 |
| 증인 증언으로 핵심 사실 확인 | +8 | 통찰 |

## 5. 전체 흐름 — V4 게임 루프

```
Phase 0: 사건 접수
  → 인물/관계 파악, 초기 증거 확인

Phase 1: 개시 진술 (스크립트)
  → 양측 입장 청취, 초기 쟁점(d-1) 확립
  → 플레이어: "뭔가 이상한데?" 의심 시작

Phase 2: 자유 심리 ★ (게임의 본체)
  ┌─ 심문 (3종) ─────────────────────┐
  │  사실추궁/동기탐색/공감접근         │
  │  → LieState 전이 → NEW FACT 드러남 │
  │  → 숨겨진 쟁점 연쇄 발견            │
  ├─ 증거 제시 ─────────────────────┤
  │  → 타이밍별 다른 반응              │
  │  → 증거 조사로 디테일 해금         │
  ├─ 조합 (2슬롯) ──────────────────┤
  │  → 증거+증거, 증거+발언 조합       │
  │  → 새 쟁점/증거 업그레이드/질문해금 │
  ├─ 끼어들기 (팝업) ──────────────── ┤
  │  → 허용 → 반격 질문 기회           │
  │  → 제지 → 불만 축적               │
  ├─ 특수 행동 (메뉴▼) ────────────── ┤
  │  → 분리심문, 비공개보호, 즉답요구   │
  │  → 증인소환 (해금 시 핫바 활성화)   │
  │  → 기록 정리 (턴 소비 없음)        │
  └─────────────────────────────────┘

Phase 3: 판결
  → Step 0: 진입 연출 + 요약
  → Step 1: 쟁점별 판단 (4개)
  → Step 2: 안건별 책임 판단 (5개)
  → Step 3: 해결안 선택
  → Step 4: 판결문 생성 + 점수/칭호

Result: 성장 반영
  → 재판관 성향 드리프트
  → 퍼크 해금
  → 히스토리 기록
```

## 6. 좌우 패널 최종 레이아웃

### 좌패널
