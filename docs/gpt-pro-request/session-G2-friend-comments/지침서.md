# 조합 재판관 코멘트 생성 — friend-01

## 목표
플레이어가 증거/발언을 조합해 새로운 단서를 발견했을 때, **재판관이 법정에서 하는 코멘트 1줄**을 생성합니다.

## 산출물
`friend-01-combination-comments.json` — 6개 코멘트

```json
[
  {
    "recipeId": "combine-1",
    "comment": "재판관 코멘트 텍스트"
  },
  ...
]
```

## 사건 개요
- **사건**: 송다은(A) vs 최수민(B) — 친구 분쟁
- 손절한 전 친구가 예비신랑에게 연락 → 집착으로 보이지만 실은 경고
- 예비신랑이 먼저 접근했고, A 아버지의 돈 접근 패턴이 반복됨

## 조합 데이터
동봉된 `combination-data.json` 참조.

## 작성 규칙

### 톤
- **재판관 말투**: 합니다체, 단호하지만 중립적
- 관찰자로서 사실을 짚는 톤 (판단은 플레이어가 함)
- 1~2문장, 40자 이내 권장

### 내용 규칙
- **직접적 결론 금지**: "B는 집착이 아닙니다" ← 이런 거 안 됨
- **방향만 제시**: "연락 시점과 다른 기록이 겹치는 부분이 있군요"
- DossierCard(dc-*) 조합은 약간 더 강한 톤: "이 부분은 반드시 짚고 넘어가야겠습니다"
- Lead(L-*) 조합은 가벼운 관찰 톤: "흥미로운 접점이 보입니다"

### 금지 패턴
- 번역체: "~된 것으로 판단됩니다"
- 기계적 관찰: "내용이 확인됩니다"
- 긴 직접 인용

### 예시
- Lead: "연락 기록과 단톡방 캡처의 시간 순서가 의미심장합니다."
- DossierCard: "확인도 없이 결론이 먼저 난 셈인데, 그 순서를 짚어봐야겠습니다."
