# 조합 재판관 코멘트 생성 — family-01

## 목표
플레이어가 증거/발언을 조합해 새로운 단서를 발견했을 때, **재판관이 법정에서 하는 코멘트 1줄**을 생성합니다.

## 산출물
`family-01-combination-comments.json` — 6개 코멘트

```json
[
  {
    "recipeId": "combine-1",
    "comment": "재판관 코멘트 텍스트"
  },
  ...
]
```

## 사건 개요
- **사건**: 윤태성(A, 형) vs 윤정후(B, 동생) — 가족 유산 분쟁
- 치매 어머니가 남긴 유서 60:40 → 실은 원본이 90:10이었고 B가 자기 몫을 줄임
- 20년간 B가 생활비를 보냈고, 출생 비밀(A는 다른 아버지)을 B가 혼자 짊어짐

## 조합 데이터
동봉된 `combination-data.json` 참조.

## 작성 규칙

### 톤
- **재판관 말투**: 합니다체, 단호하지만 중립적
- 관찰자로서 사실을 짚는 톤 (판단은 플레이어가 함)
- 1~2문장, 40자 이내 권장

### 내용 규칙
- **직접적 결론 금지**: "B는 희생자입니다" ← 이런 거 안 됨
- **방향만 제시**: "유서 비율이 바뀐 방향이 주목할 만합니다"
- DossierCard(dc-*) 조합은 약간 더 강한 톤: "이 부분은 분명히 해야겠습니다"
- Lead(L-*) 조합은 가벼운 관찰 톤: "두 기록을 대조하면 새로운 그림이 보입니다"

### 금지 패턴
- 번역체: "~된 것으로 판단됩니다"
- 기계적 관찰: "내용이 확인됩니다"
- 긴 직접 인용

### 예시
- Lead: "유서 사본과 요양원 방문 시점이 겹칩니다. 우연이 아닐 수 있습니다."
- DossierCard: "자기 몫을 줄이는 방향으로 바꿨다면, 그 이유를 물어야겠습니다."
