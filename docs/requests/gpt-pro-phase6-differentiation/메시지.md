# GPT Pro 요청: Phase 6 중재 유형별 게임플레이 차별화

## 배경

솔로몬 법정은 AI 둘의 싸움을 인간이 재판하는 리플레이형 추리 게임입니다.
Phase 6(중재)에서 4가지 경로를 선택할 수 있지만, 현재는 어떤 것을 골라도 Phase 7(판결)에서 동일한 결과로 이어져 **선택의 무게가 없습니다**.

## 현재 구조

### Phase 6 → Phase 7 흐름
```
Phase 6: 중재 유형 선택 (4종)
  ├─ immediate (즉시 판결)
  ├─ conditional (조건부 합의)
  ├─ postpone (보류/추가 조사)
  └─ fact_first (사실확인 우선)
     ↓
Phase 7: 판결 (모든 경로 동일)
  - 쟁점별 사실 판단 (진실/거짓/보류)
  - 책임 비율 배분 (A:B 슬라이더)
  - 해결안 선택 (솔루션 옵션)
  - 증거 적법성 판단
     ↓
Result: 점수 산출 (통찰/권위/지혜)
```

### 현재 3사건
- **spouse-01** (민준-서연): 공동통장, 온라인 베팅, 외도 의심, 휴대폰 접근
- **family-01** (지훈-수진): 부모 재산, 간병 분담, 생활비, 가업 승계
- **friend-01** (현우-동민): 공동 투자, 수익 배분, 계약 해석, 신뢰 파괴

## 요청 사항

### 1) 중재 유형별 Phase 7 영향 설계

각 유형이 Phase 7에 미치는 **구체적이고 차별화된** 영향을 설계해 주세요.

**제약:**
- 어떤 중재 유형도 "정답"이 되면 안 됩니다 — 모든 경로가 유효해야 합니다
- "진실은 플레이어가 직접 밝혀낸다" 원칙 유지
- 영향은 코드로 구현 가능해야 합니다 (수치/조건 기반)

**예상 영향 방향 (참고용, 이에 한정되지 않음):**
- 초기 책임 비율 프리셋이 달라짐
- 특정 솔루션 옵션이 추가/제한됨
- 점수 가중치(통찰/권위/지혜)가 달라짐
- 후일담 톤이 달라짐
- NPC 태도 보너스/패널티

### 2) 중재 유형별 재판관 코멘트 (4개)

Phase 6에서 각 유형을 선택했을 때 재판관이 발화하는 코멘트 1개씩.

| 유형 | 톤 |
|------|-----|
| immediate | 단호하고 결단력 있는 톤 |
| conditional | 신중하고 조건을 따지는 톤 |
| postpone | 사려 깊고 여유를 두는 톤 |
| fact_first | 분석적이고 논리적인 톤 |

**한국어 품질 규칙:**
- 합니다체 필수
- 번역체 금지 ("~된 것으로 생각됩니다", "부득이하게" 등)
- 2~3문장 이내

### 3) 사건별 후일담 톤 키워드

3사건 × 4유형 = 12개 조합에 대해 후일담 톤 키워드 2~3단어.

예시:
```
spouse-01 + immediate → "빠른 결론, 냉랭한 관계"
spouse-01 + conditional → "조건부 화해, 신뢰 시험"
```
