# GPT Pro 요청: 후일담(Aftermath) 스크립트 보충 — family-01, friend-01

## 배경

재판 결과 화면에서 후일담이 표시됩니다. spouse-01은 스크립트가 있으나,
family-01과 friend-01은 아직 없어 LLM 폴백에 의존합니다.
**모든 NPC 대사는 스크립트 단독 운용** 정책에 따라 보충이 필요합니다.

## 기존 구조 (spouse-01 참조)

scriptedText 번들의 `aftermath` 채널:
```json
{
  "channels": {
    "aftermath": {
      "entries": [
        {
          "key": "good",
          "resultClass": "good",
          "variants": [
            {
              "id": "v1",
              "text": "민준 씨와 서연 씨는 재판 이후...(3~5문단)",
              "behaviorHint": "화해 분위기",
              "tags": ["reconciliation"]
            }
          ]
        },
        {
          "key": "neutral",
          "resultClass": "neutral",
          "variants": [{ ... }]
        },
        {
          "key": "poor",
          "resultClass": "poor",
          "variants": [{ ... }]
        }
      ]
    }
  }
}
```

### resultClass 분류
- **good**: 총점 75점 이상 (양측 만족도 높음)
- **neutral**: 총점 55~74점 (한쪽 불만 잔존)
- **poor**: 총점 54점 이하 (불만족, 악화 가능)

### 중재 유형별 톤 키워드 (Phase 6에서 결정)
동봉한 `mediationEffects.json`의 `aftermath_keywords` 참조.

## 요청

### family-01 (지훈-수진: 부모 재산, 간병, 생활비, 가업 승계)
- good / neutral / poor × 각 2개 변주 = 6개 후일담
- 각 3~5문단, 자연스러운 한국어
- 중재 유형별 톤 반영: `aftermath_keywords.family-01` 참조

### friend-01 (현우-동민: 공동 투자, 수익 배분, 계약, 신뢰)
- good / neutral / poor × 각 2개 변주 = 6개 후일담
- 동일 구조

### 총 12개 후일담

## 한국어 품질 규칙
- 번역체 금지
- 합니다체/해요체 혼용 가능 (서술형)
- 당사자 이름 사용 (family-01: 지훈/수진, friend-01: 현우/동민)
- 결말이 확정적이지 않아야 함 — "~할 것 같다", "~하기로 했다" 등 여운 남기기
- 과도한 해피엔딩 금지 — good이라도 완전한 해결은 아님

## 출력 포맷

사건별 JSON:
```json
{
  "caseId": "family-01",
  "aftermath_entries": [
    {
      "key": "good",
      "resultClass": "good",
      "variants": [
        { "id": "v1", "text": "...", "behaviorHint": "...", "tags": ["..."] },
        { "id": "v2", "text": "...", "behaviorHint": "...", "tags": ["..."] }
      ]
    },
    { "key": "neutral", ... },
    { "key": "poor", ... }
  ]
}
```
