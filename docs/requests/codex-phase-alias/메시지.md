# Codex 요청: Phase enum legacy → Phase alias 일괄 교체

## 브랜치
`codex/ui-handoff-freeze-20260411`

## 배경

`src/types/game.ts`에 `Phase` const alias가 추가되었습니다:
```ts
export const Phase = {
  Briefing: GamePhase.Phase0_CaseIntro,
  Pretrial: GamePhase.Phase1_InitialStatement,
  Interrogation: GamePhase.Phase3_Interrogation,
  Mediation: GamePhase.Phase6_Mediation,
  Verdict: GamePhase.Phase7_Verdict,
  Result: GamePhase.Result,
} as const
```

기존 코드에서 `GamePhase.Phase3_Interrogation` 등 legacy 이름을 사용하는 곳을 새 alias로 교체합니다.

## 먼저 읽을 파일
1. `src/types/game.ts` — Phase alias 정의 확인
2. 아래 교체 표 참조

## 교체 규칙

| 기존 (legacy) | 새 (alias) | 비고 |
|---|---|---|
| `GamePhase.Phase0_CaseIntro` | `Phase.Briefing` | |
| `GamePhase.Phase1_InitialStatement` | `Phase.Pretrial` | |
| `GamePhase.Phase3_Interrogation` | `Phase.Interrogation` | |
| `GamePhase.Phase6_Mediation` | `Phase.Mediation` | |
| `GamePhase.Phase7_Verdict` | `Phase.Verdict` | |
| `GamePhase.Result` | `Phase.Result` | |

**교체하지 않는 것:**
- `GamePhase.Phase2_Rebuttal` — deprecated이지만 일부 fallback에서 아직 사용
- `GamePhase.Phase4_Evidence` — deprecated fallback
- `GamePhase.Phase5_ReExamination` — deprecated fallback
- `enum GamePhase` 정의 자체
- `game.ts`의 Phase const 정의 자체

## import 변경

각 파일에서:
- `import { GamePhase }` → `import { GamePhase, Phase }` (또는 Phase만 사용하면 Phase만)
- `import type { ... }` 부분은 건드리지 않음
- `GamePhase`를 타입 어노테이션(`GamePhase` as type)으로 사용하는 곳은 유지

## 주의사항
- `npx tsc -b --force` 통과 필수
- 값 비교(`=== GamePhase.Phase3_Interrogation`)도 교체 대상
- Record 키(`[GamePhase.Phase3_Interrogation]:`)도 교체 대상
- switch/case도 교체 대상
- **GamePhase enum 자체는 절대 삭제하지 않음** — Phase alias는 enum 값을 참조하는 const
