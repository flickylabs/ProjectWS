# GPT Pro 요청: investigationStages 3사건 데이터

## 배경

증거 시스템에 `investigationStages`라는 3단계 조사 질문 체계가 설계되어 있으나,
현재 플레이 가능한 3사건(spouse-01, family-01, friend-01)의 증거 데이터에 이 필드가 정의되지 않았습니다.

## 현재 구조

증거 데이터의 `investigationResults`에는 평면적인 서브액션 맵만 있습니다:
```json
{
  "id": "e-1",
  "name": "공동통장 계좌 내역",
  "investigationResults": {
    "request_original": "원본 확인 결과...",
    "check_metadata": "메타데이터 확인 결과...",
    "verify_source": "출처 확인 결과..."
  }
}
```

`investigationStages`는 이 서브액션들을 **3단계로 나눠 점진적으로 핵심에 접근**하는 구조입니다:
```json
{
  "investigationStages": [
    {
      "stage": 0,
      "label": "기초 확인",
      "questions": ["request_original"],
      "unlockHint": null
    },
    {
      "stage": 1,
      "label": "상세 분석",
      "questions": ["check_metadata", "verify_source"],
      "unlockHint": "원본을 확인하면 메타데이터와 출처를 분석할 수 있습니다."
    },
    {
      "stage": 2,
      "label": "핵심 추궁",
      "questions": ["cross_reference"],
      "unlockHint": "상세 분석이 완료되면 교차 검증이 가능합니다."
    }
  ]
}
```

## 요청

3사건의 **모든 증거 아이템**에 대해 `investigationStages` 배열을 설계해 주세요.

### spouse-01 증거 목록 (동봉 JSON 참조)
- e-1: 공동통장 계좌 내역
- e-2: 온라인 베팅 기록
- e-3: 채팅 캡처
- e-4: 카드 사용 내역
- e-5: 휴대폰 접근 로그
- e-6: 보험사 상담 기록

### family-01, friend-01 증거 목록
동봉된 JSON 파일에서 evidence 배열을 참조해 주세요.

## 설계 원칙

1. **Stage 0**: 누구나 할 수 있는 기초 확인 (원본 요청, 외형 검토)
2. **Stage 1**: 약간의 전문성이 필요한 분석 (메타데이터, 시간대 대조, 금액 추적)
3. **Stage 2**: 핵심에 도달하는 결정적 질문 (교차 검증, 모순 지적, 숨겨진 항목 발견)
4. 각 stage의 `unlockHint`는 **이전 stage 완료 시 표시되는 안내 문구** (한국어, 1문장)
5. `questions` 배열의 각 항목은 기존 `investigationResults`의 키와 매칭되어야 함. 새 키가 필요하면 추가 가능 (이 경우 해당 결과 텍스트도 함께 작성)

## 한국어 품질 규칙
- 번역체 금지
- unlockHint: "~하면 ~할 수 있습니다" 또는 "~를 확인하면 다음 단계가 열립니다" 형태
- stage label: 2~4글자 명사형

## 출력 포맷

사건별 JSON 파일:
```json
{
  "caseId": "spouse-01",
  "evidenceStages": {
    "e-1": {
      "investigationStages": [
        { "stage": 0, "label": "...", "questions": ["..."], "unlockHint": null },
        { "stage": 1, "label": "...", "questions": ["..."], "unlockHint": "..." },
        { "stage": 2, "label": "...", "questions": ["..."], "unlockHint": "..." }
      ]
    },
    "e-2": { ... }
  }
}
```
