# GPT Pro 요청: Phase 3 심문 스크립트 5중 변주 세트

## 배경

솔로몬 법정의 NPC 대사는 **모두 스크립트**로 운영됩니다 (LLM은 비상 폴백일 뿐).
현재 `src/data/scriptedText/{caseId}.json`에 스크립트 번들이 있으나,
같은 LieState에서 같은 심문 유형으로 반복 질문하면 **동일한 스크립트만 반환**됩니다.

**목표**: 각 상황(LieState × 심문 유형)마다 **5종 변주 스크립트**를 준비하여,
같은 조합이라도 매번 다른 응답이 나오게 합니다.

## 현재 스크립트 구조

```json
// scriptedText/{caseId}.json 내부
{
  "channels": {
    "interrogation": {
      "entries": [
        {
          "key": "a:d-1:S0:fact_pursuit:hard",
          "speaker": "A",
          "text": "재판관님, 그건 사실이 아닙니다. ..."
        }
      ]
    }
  }
}
```

키 형식: `{party}:{disputeId}:{lieState}:{questionType}:{tone}`
현재는 키당 1개의 text만 존재합니다.

## 요청 사항

### 1) 변주 키 체계 설계

기존 키에 **변주 번호**를 추가합니다:
```
a:d-1:S0:fact_pursuit:hard:v1
a:d-1:S0:fact_pursuit:hard:v2
a:d-1:S0:fact_pursuit:hard:v3
a:d-1:S0:fact_pursuit:hard:v4
a:d-1:S0:fact_pursuit:hard:v5
```

### 2) 5종 변주 패턴 정의

각 LieState × 심문 유형 조합에 대해 5가지 응답 톤/구조 패턴:

**예시 (S0 + fact_pursuit):**
1. **완강한 부정** (v1) — 사실 자체를 전면 부인, 짧고 단호
2. **화제 전환** (v2) — 다른 쟁점으로 돌리려는 시도
3. **역질문** (v3) — "그걸 왜 제가 증명해야 합니까?" 식 반격
4. **증거 요구** (v4) — "증거 없이 그런 말씀을 하시면..." 식 방어
5. **침묵 후 간략 답변** (v5) — 잠시 멈칫하다가 최소한의 답변

각 패턴에 대해:
- 패턴 ID (v1~v5)
- 패턴명 (한국어)
- 톤 가이드 (2~3문장)

### 3) spouse-01 기준 실제 스크립트 작성

**핵심 6개 조합** × 5변주 = **30개 스크립트** 작성:

| 조합 | 사유 |
|------|------|
| S0 + fact_pursuit | 게임 초반 가장 빈번 |
| S1 + motive_search | 일부 인정 후 동기 탐색 |
| S2 + empathy_approach | 핑계 상태에서 공감 시도 |
| S3 + fact_pursuit | 책임 전가 중 사실 추궁 |
| S4 + empathy_approach | 감정적 상태에서 공감 |
| S5 + motive_search | 자백 상태에서 마무리 |

**각 조합에서 당사자 A(민준) 기준으로 5개 변주 text 작성.**

**spouse-01 기본 정보:**
- 당사자 A: 민준 (남편) — archetype: avoidant (회피형)
- 당사자 B: 서연 (아내) — archetype: confrontational (대립형)
- 쟁점 d-1: 공동통장 관리, d-2: 온라인 베팅, d-3: 외도 의심, d-4: 휴대폰 접근

### 4) 변주 선택 로직 제안

scriptedTextLoader에서 변주를 선택할 때의 규칙:
- 직전 턴과 같은 변주 번호 회피
- 3턴 내 동일 변주 재사용 금지
- archetype별 기본 선호 (avoidant → v2화제전환/v5침묵 선호)
- 감정 상태별 가중치 (angry → v3역질문 확률↑)

## 한국어 품질 규칙

- 재판관 대상: **합니다체 필수**
- 번역체 금지: "~된 것으로 생각됩니다", "~인 측면이 있었습니다", "부득이하게" 등
- "사전 상의/협의" (S0-S2에서 금지)
- 재판관에게 상대 언급 시: "제 아내가~" (callTerms.toJudge)
- S0-S1: "해당 금액", "그 사람" (Truth Throttle)
- S3+: 구체적 금액/이름 허용
- "특정 X" 패턴 금지
- "~만을" → "~만"
