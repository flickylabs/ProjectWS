## 1. 컨텍스트 — 사건 frame

**spouse-01** 사건은 부부 외도 의심 → 가족 돌봄 진실 흐름.
- **partyA (박지연)**: 학원 데스크 직원. 남편 외도를 의심하며 위임장 조작·공동 적금 무단 해지 → 투자방 송금 (claimant 측, 의심하는 쪽).
- **partyB (이준호)**: avoidant archetype. 형 사업 실패로 가족 도움이 필요한 상황을 박지연에게 숨김. 박지연 난임 진단 후 본인 정서 정리 중 (defendant 측, 알리바이 대는 쪽).

**e-10 (예비 부모 정서 도서)** 등장 흐름:
1. e-1 「영수증 묶음 5장」이 player에게 잠금 해제됨 (영수증 stage 1~3 점진 조사)
2. player가 영수증 stage 3 (대상복원, "중학생용 참고서는 누구를 위해?") 도달 후 박지연이 이준호에게 영수증을 제시
3. 박지연 측 questionAngle = "교보문고 결제 안에 참고서와 별도 결제된 도서가 한 권 더 있다. 그 도서를 누구를 위해 산 것인지"
4. → e-10 「예비 부모 정서 도서」 cascade emerge (책 본체 확보 + d-3 misdirection 동시 emerge)

**surface frame**:
- B가 (누군가의) 예비 부모를 준비? → A 측 의심: "내연녀가 임신했나?" (d-3 misdirection 강화)
- 책의 실제 정독자가 누구인지 미확인 상태

**진실 (단계 진행으로 점진 노출)**:
- B 본인이 박지연 난임 진단 후 부모 될 마음을 정리한 자료
- 단 본 단계에서 박지연 난임 / 임신 / h-d4 keyword 직접 노출 X (mediation/confession에서 통합)

## 3. 작성 요청 항목

### 3-1. 책 외관 (cover) — 1 entry

| field | 내용 |
|---|---|
| `title` | 책 제목 (한국어 실제 출간된 자기계발/부모 정서 도서 톤) |
| `subtitle` | 부제 (선택, 더 구체적 영역 명시) |
| `author` | 저자 이름 (한국어 자연 이름 또는 외국 저자 한국어 번역명) |
| `publisher` | 출판사 이름 |
| `isbn` | 13자리 ISBN (실재하지 않는 가상 번호) |

**톤 가이드**:
- 「예비 부모를 위한 마음 가이드」류 = 부모 정서 정리 + 두려움 다스리기 + 자기 준비 영역
- 실제 출간된 유사 도서: 『두려움 없이 부모 되기』, 『엄마가 되기 전에』 등 (한국어 자기계발/심리 영역)
- 책 제목 단어에서 "임신" / "출산 준비" / "태교" 같은 진실 keyword 직접 노출 회피 (mom-to-be 영역 강조 X). **"부모 정서 / 마음 / 준비 / 두려움"** 영역으로 frame

### 3-2. 목차 (toc) — 6 chapter

| field | 내용 |
|---|---|
| `chapter` | 챕터 번호 (1~6) |
| `title` | 챕터 제목 |
| `highlighted` | 책갈피/강조 marker 여부 (true/false) |

**구성 가이드**:
- 강조 챕터 (highlighted: true) 3개 = **챕터 1, 2, 4** 권장 (전 단계 frame과 정합)
- 강조 챕터 영역 = 부모 정서·두려움 다스리기·준비 영역
- 비강조 챕터 3개 = 일반 부모 가이드 영역 (양육 일상, 교육, 가족 관계 등)
- 챕터 제목에서 "임신" / "출산" / "태교" 같은 keyword 직접 노출 X

### 3-3. 접힌 페이지 (dogearedPages) — 3 entry

| field | 내용 |
|---|---|
| `page` | 페이지 번호 (현재 placeholder: 47, 89, 134 — 변경 가능) |
| `chapter` | 해당 챕터 번호 (강조 챕터와 매칭) |
| `excerpt` | 해당 페이지 본문 발췌 (2-4 문장, 부모 정서 영역) |
| `notes` | 메모 (밑줄 또는 여백 메모 1-2개) |

**메모 톤 가이드**:
- B 본인 필체로 작성된 메모 — **자기 시점 1인칭** ("나는...", "내가...") 또는 **추상 영역** ("이 두려움을 어떻게...", "준비란...")
- 진지함 + 자기 정서 정리 영역. **감상문이 아닌 자기 다짐 / 자기 정리** 영역
- **금지 keyword**:
  - "박지연" / "지연" / "아내" 등 박지연 직접 지칭 — 진실 영역 직접 노출 X
  - "난임" / "임신" / "출산" / "태교" — h-d4 진실 영역 keyword 직접 노출 X
  - "형" / "조카" / "시댁" / "회생" — 다른 진실 영역 keyword (`ref-policy-spouse01-truth-disclosure.md` 정합)
- **허용 영역**:
  - "두려움" / "준비" / "마음" / "부모" / "스스로" / "내 자리" 등 일반 부모 정서 영역
  - "이 책을 읽고 나서 정리하기로 한다" / "스스로 받아들이는 시간이 필요하다" 등 자기 정리 영역
