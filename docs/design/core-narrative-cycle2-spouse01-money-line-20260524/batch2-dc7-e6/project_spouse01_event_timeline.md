## spouse-01 사건 흐름 (권위)

**시간 순서**:
1. **이준호 측 사건** (배경) — 형 사업으로 부모님 재산 날린 가족 사정. 형/조카 챙김. 시댁 갈등.
2. **이준호의 비밀 행동** — 발신자 미상 문자(가족 쪽 연락), 오피스텔 출입(형 가족 방문), 개인 계좌에서 큰돈 현금 출금(가족 도움). 모두 박지연에게 숨김.
3. **박지연의 외도 의심 시작** — 이준호의 위 행동들을 외도로 오인. 의심 굳어짐.
4. **박지연의 위임장 조작** — 외도 의심으로 이혼 대비 결심 → 이준호 명의 도용해 공동 적금 해지 위임장 위조
5. **공동 적금 해지 실행** — 박지연이 위임장으로 공동 적금 해지
6. **투자방 송금** — 해지한 돈을 투자방(텔레그램)에 송금. 사기당함.
7. **양측 침묵** — 이준호는 가족 사정 숨기느라, 박지연은 위임장 조작·송금 사기 숨기느라

## 핵심 정합성 포인트

- **이준호 = "외도 X, 가족 도움 진실 숨김"** (dc-1 오피스텔, dc-2 시댁, dc-3 3000만원 권한 / 박지연 입장에선 이준호 외도 의심 → 위임장 조작 진행)
- **박지연 = "외도 의심으로 위임장 조작 + 비밀 송금"** (dc-4 2000만원 수치, dc-5 6000만원 순서 / 진실은 본인이 큰 손실 만든 측)
- **공동 적금 해지** = 박지연 측 행동 (이준호 측 동의 없음, 위임장 조작)
- **개인 계좌 출금** = 이준호 측 비자금 행동 (가족 도움)
- **두 가지를 같은 evidence_combo entry에 link하면 데이터 오류** (사용자 batch 7a [1] 발견)

## 자주 발생하는 데이터 매핑 오류 영역

1. **"개인 계좌 출금" + "공동 적금 권한"** 동시 추궁 — 별개 사안, 같은 entry에 묶이면 오류 (batch 7a [1])
2. **"확인이 먼저 vs 송금이 먼저"** — 박지연 측 사건은 외도 의심(확인) → 위임장 조작 → 적금 해지 → 송금 순. "확인이 먼저"가 맞고 "송금이 먼저"는 사실 아님 (batch 7b [9])
3. **"투자방 송금"** 영역에서 송금 직전에 "공동계좌 무단 해지" 사실이 있어야 정합 (사용자 polish [10]에서 명시)

## 자연화 작업 적용

각 batch 진단 전:
1. entry의 evidence 묶음 / dossier 카드 / 추궁 내용이 위 사건 흐름과 정합한지 검증
2. 불일치 발견 시 자연화 보류, 데이터 매핑 backlog 추가
3. 사용자에게 사실 관계 확인 후 폐기 / 재작성 / 다른 entry 수정 결정
