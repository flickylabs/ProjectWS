1 배경 이미지

전체 화면을 채우는 배경. 울트라와이드 대응을 위해 가로를 넓게 제작합니다.

에셋제작 사이즈포맷설명
메인 홈 배경5120 × 2880PNG석조 법정 분위기. 중앙에 천칭 실루엣. 좌우 여백은 어둡게 자연 페이드.
재판 법정 배경5120 × 2880PNG게임 플레이 중 고정 배경. 나무 패널, 법대, 어두운 조명.
결과 화면 배경3840 × 2160PNG판결 후 분위기. 여명/석양 톤, 차분한 느낌.
사건 소개 배경3840 × 2160PNG사건 진입 전 브리핑 배경. 서류/증거물 분위기.
울트라와이드 대응 가이드

핵심 콘텐츠(제목, 인물)는 중앙 3840px 안에 배치하세요. 좌우 640px씩은 장식/어둠 영역입니다.

색상 톤

• 주조색: #0e0e14 ~ #1a1a28 (매우 어두운 남색)

• 강조: #d4a24e (골드) — 테두리, 장식 라인에만 사용

• 절대 밝은 배경 금지. 게임 UI 텍스트가 밝은색이므로 배경은 어두워야 합니다.

9-slice 제작 원칙

배너/패널은 가로 가변 크기입니다. 아래 규칙을 지켜주세요:

• 좌우 끝 장식(코너)은 48px 이내로 고정

• 중앙 영역은 단순 패턴 반복 또는 단색 그라데이션

• 코너에 복잡한 장식을 넣되, 중앙은 깨끗하게 비워주세요

9-slice 구조 (배너 예시):

  코너 고정 (48px)      중앙: stretch/repeat      코너 고정 (48px)
┌────────────────┬──────────────────────────┬────────────────┐
│  ╔══╗          │    단순 그라데이션 영역    │          ╔══╗  │
│  ║장║식        │    (텍스트가 들어갈 자리)   │        장║식║  │
│  ╚══╝          │                          │          ╚══╝  │
└────────────────┴──────────────────────────┴────────────────┘

→ 개발팀이 CSS border-image-slice로 자동 처리합니다.

CSS로 상태(hover/press/disabled) 처리하므로 normal 상태 1종만 납품하면 됩니다.

에셋제작 사이즈포맷설명

CTA 중형 (강화/착용)480 × 96PNG보조 액션 버튼.
탭 버튼 (active)320 × 80PNG"재판관 타이틀" / "판결 조각" 토글.
탭 버튼 (inactive)320 × 80PNG위와 동일 형태, 비활성 톤.
세션 카드 프레임320 × 320PNG4×3 세션 그리드 카드 배경. 아이콘은 별도.
상태 처리 — 이미지 1종만 필요

hover: 밝기 +10% (CSS filter: brightness 1.1)

press: 축소 (CSS transform: scale 0.97)

disabled: 투명도 30% (CSS opacity: 0.3)

5 오브제 / 장식

게임 분위기를 결정하는 장식 요소. 모두 투명 배경 PNG.

에셋제작 사이즈포맷설명
천칭 저울 (메인 심볼)800 × 800PNG홈 화면 중앙 장식. 반투명 워터마크로도 사용.
법봉 (gavel)256 × 256SVG판결/입장 아이콘. 버튼 내부용.
타이틀 엠블럼 9종384 × 384PNG타이틀 선택/상세에서 대형 표시. 각 타이틀 개성 반영.
감정 이펙트 5종256 × 256PNG분노(빨강)/불안(파랑)/체념(회색)/고백(보라)/폭발(주황).
별/등급 마크 5종96 × 96SVG점수 등급 (1~5성).
타이틀 엠블럼 9종 목록

각 엠블럼은 해당 타이틀의 3축 조합을 상징합니다:

1. 냉철한 심판자 (논리+엄격+원칙) — 칼날/저울

2. 실용적 분석가 (논리+엄격+화해) — 톱니바퀴/악수

3. 신중한 중재자 (논리+관용+원칙) — 방패/올리브

4. 균형의 현자 (논리+관용+화해) — 천칭/별

5. 직감의 심판관 (직관+엄격+원칙) — 눈/번개

6. 열정의 조정관 (직관+엄격+화해) — 불꽃/손

7. 온화한 수호자 (직관+관용+원칙) — 방패/하트

8. 따뜻한 중재자 (직관+관용+화해) — 나뭇잎/고리

9. 중립의 관찰자 (중립×3) — 돋보기/원

SVG 제작 규칙

• viewBox: 0 0 24 24 또는 0 0 32 32

• stroke 기반, strokeWidth 1.5 ~ 2

• 색상: currentColor 사용 (CSS에서 제어)

• 파일당 1KB 미만

• fill 사용 최소화 (라인 아이콘 스타일 통일)

Steam 필수 주의사항

• 모든 캡슐 이미지에 게임 제목(로고)이 반드시 포함되어야 합니다.

• 캡슐에 리뷰 점수, 수상 로고 등 마케팅 문구 삽입 금지 (Steam 정책).

• 히어로 이미지의 좌측 1/3은 텍스트 없이 비워두세요 (Steam UI가 덮음).

• 스크린샷에 스토어 UI나 Steam 로고 포함 금지.
