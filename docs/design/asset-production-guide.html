참고 문서: 솔로몬의 딜레마_QA - UI 디자인.pdf → A안 (1열) 전체 선택

모든 에셋은 A안의 분위기를 따릅니다. A안의 핵심 키워드:

  1. 사실적인 법정 인테리어 — 마호가니 나무 패널, 법전 책꽂이, 황동 램프, 간접 조명. 추상적 그라데이션이 아닌 실제 공간감이 느껴지는 사진/페인팅 스타일.
  2. 따뜻한 마호가니+골드 톤 — 차가운 남색/회색이 아니라 따뜻한 갈색+어두운 금색이 기본. 법정의 나무 질감과 황동 장식이 분위기를 지배.
  3. 장식적인 프레임 — 패널/말풍선은 단순한 1px 보더가 아니라 조각된 나무 테두리, 골드 코너 장식이 있는 격식 있는 프레임.
  4. 입체감 있는 골드 아이콘 — 미니멀 라인 아이콘이 아니라 약간의 입체감과 질감이 있는 골드 일러스트. 방패/천칭/법봉 등 법정 모티프.
  5. 세미리얼 캐릭터 — 장식적인 원형/방패형 프레임 안에 세미리얼리스틱 초상화. 만화가 아닌 법정 드라마 느낌.

2. 패널 프레임 (7종) — 장식적 프레임 스타일

A안 참고: 모든 패널은 단순한 사각형이 아닙니다. 나무 조각/골드 장식이 있는 격식 있는 프레임입니다. A안의 설정 화면, 내정보 화면의 카드/패널 테두리를 보세요.
프레임 스타일 공통

• 모서리: 약간 라운딩 + 코너마다 골드 장식 포인트 (꽃/잎 또는 기하학적 무늬)

• 테두리: 이중선 — 안쪽 얇은 골드 라인 + 바깥쪽 나무 질감 보더

• 내부: 반투명 어두운 마호가니 (#1a1610, 불투명도 90~95%)

적용 방식 (2026-04-22 확정, 9-slice 지침 철회)

• 기존 "9-slice 48px 코너" 지침 → 실제 납품 시 네온/장식 프레임이 두꺼워 9-slice가 깨지는 문제가 확인됨.

• 확정 적용 방식: background-image: url(...); background-size: 100% 100%; background-repeat: no-repeat

• 이미지는 완성된 일체형 프레임으로 설계. 네온/골드 장식/내부 패널 모두 포함.

• 게임 UI는 원본 비율 유지 우선 (min-width / min-height), 가변 영역은 가로 stretch만 권장.

• 9-slice를 다시 시도하려면 모서리를 완전 비워두고(장식 없음) 좌우 끝에만 장식을 배치한 새 납품이 필요함.

적용 유보 — 재디자인 필요 (2026-04-22)

다음 에셋은 게임 UI에 적용 시도했으나 시각적으로 깨져 적용 보류, CSS 원본 복구:

• PL-1/2/3 말풍선 — 이미지가 "네온 테두리 + 투명 갭 + 내부 나무 패널" 3중 레이어 구조. 텍스트량이 가변인 말풍선과 맞지 않음.
→ 재디자인 요청: 내부가 "꽉 찬 나무 패널" 단일 레이어이고, 네온 테두리가 바로 붙은 형태.

• PL-6 hotbar-bg — 2400×200 (12:1 가로)을 실제 UI ~1000×100 (10:1)에 stretch 시 세로 압축이 심함. 장식 디테일이 왜곡됨.
→ 재디자인 요청: 1000×120 또는 1200×140 수준의 실제 UI 비율에 맞는 크기, 또는 좌우 48~64px 이외 영역이 flat/repeatable한 구조.

• PL-4 card-evidence, PL-7 popup-token — 가이드 자체가 "고정 크기"로 명시. 9-slice 불가, 고정 비율로만 사용 가능.

  5. DO: 의상: 현실적 (캐릭터 직업에 맞는 복장)
  6. DO: 투명 배경 필수. 게임에서 장식 원형 프레임이 CSS로 씌워짐.
  7. DON'T: 배경색/그라데이션 배경 금지
  8. DON'T: 과도한 만화/애니메이션 스타일 금지
  9. DON'T: 프레임/테두리 포함 금지 (CSS에서 별도 처리)
