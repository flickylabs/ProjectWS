번역체 단순 어휘 치환 ("부인→부정") 차원이 아니라 **문장 구조 자체의 자연화**가 필요할 때, 아래 8 차원을 모두 점검한다. 의미 보존이 최우선.

**Why**: 2026-05-21 family-01 e-4 sweep 후 사용자가 자연화 요구. v1에서 "장남으로 살아온 자리" → "장남이라는 것 자체"로 옮겨 **fact-level 의문**으로 의미 변질 사고. 사용자 30+ anchor 직접 수정으로 정착된 가이드.

**How to apply**: 한국어 자연화 작업 시 8 차원 모두 점검. EN/JA/ZH-CN 번역자가 의미를 명확히 잡을 수 있는 minimal context 유지 (생략은 예민한 판단).

## 0. 의미 보존 우선 — 추상명사가 nuanced 함축을 담을 때

자연화 ≠ 추상명사 제거. "자리/세월/시간/무게"가 책임감/자존심/체면 같은 함축을 담을 때는 **함축을 다른 한국어 단어로 살림**. 단순 제거하면 의미 변질.
- "장남으로 살아온 자리" = "장남으로 짊어져 온 무게/책임/체면/자존심"
- "그 자리가 흔들리는 질문" = "그걸 흔드는 질문" (책임 가리키는 지시 유지)

## 1. 시제·상 — 지속·진행형 활용

- "짊어진" → "짊어져 온" (장남으로 오래 책임 진 nuance)
- "가볍게 여긴 적이 없습니다" → "내려놓은 적이 없었습니다" (시각적·정서적)
- "괴롭습니다" → "괴로웠습니다" (과거 회상 톤)

## 2. 완곡 추측 "~것 같다" — 한국 화법 핵심

화자가 자기 행동·감정을 단언하지 않고 추측·관조하는 어조. self-monitoring 격식체 완화의 핵심.

- "방어부터 나옵니다" → "방어기재가 작동하는 것 같습니다"
- "더 흔들렸습니다" → "더 흔들린 것 같습니다"
- "말이 세게 나갔어요" → "말이 세게 나간 것 같습니다"
- "뒤엉켜 있었습니다" → "뒤엉켜 있었던 것 같습니다"

심리학·정신분석 용어 ("방어기재", "보상 심리") 도입 OK — 화자의 자기 통찰 톤이 자연스러워짐.

## 3. 부사·지시어 정리 — 영어 직역 흔적 제거

- "그렇게 가볍게" → "가볍게" (*so lightly* 직역의 "그렇게" 제거)
- "그게 다" → "모두"
- "그 부분" → "그걸" (입말 축약)
- "그 시간이" → "시간이" 또는 명료성 차원 keep
- "지금은" → "이제" (시점 전환)

## 4. 격식·입말 균형 — "단정" keep, 입말 동사로

v1/v2 실수: "단정"을 무조건 제거. 사용자는 "단정"체를 유지하는 걸 선호.

- "전부를 잘라 말하진 않겠습니다" → "전부를 단정지어 말씀드리진 않겠습니다"
- "다 그렇다고 단정 짓진" → "모든 것을 단정짓진 않겠습니다"
- "전부를" → "모든 것을" (영어 *all of it* → 한국어 자연 어순)

## 5. 심리·정서 정확화 — 한국어 관용 표현

- "자존심이 발끈" → "자존심이 상할 수밖에 없습니다 / 상하더군요" (자존심+상하다 관용)
- "탐욕으로 받아들였습니다" → "탐욕으로 느껴졌습니다" (수동 감각화)
- "분노를 먼저 택했습니다" → "사실 여부보다 분노가 앞섰습니다"
- 화자가 "감정을 X했다" 행위 동사보다 "감정이 X했다/느껴졌다" 수동 감각이 자연

## 6. 수동·능동·주체성 정확화

- "유리하게 끝난 결과" → "동생에게만 유리하게 작성됐어요" (수동→능동)
- "어머니 뜻만으로" → "어머니 의지로" (의지 강조)
- "지키는 사람인 척" → "보호하는 사람으로 있었지만" (역할 명시)
- "끌고 간 사람" → "제 의지로 상황을 끌고간 사람" (주체성 강조)
- "왜 그랬는지를 그냥 못 넘기겠어요" → "왜 그랬는지 그냥 넘길 수 없습니다"

## 7. 한자어 명사화 vs 풀어쓰기 — 정확한 어휘 선택

자연화가 항상 풀어쓰기는 아니다. 한자어 명사가 더 정확하고 자연한 경우도 있음. **내 본능적 진단(풀어쓰기 우선)이 자주 과잉으로 흐름** — 사용자 polish에서 한자어 keep이 자주 선택됨.

- "그렇게 자주 드나든 점" → "잦은 방문" (한자어가 더 자연)
- "어머니 말년 모습" → "어머니 말년의 상황"
- "이유를 안 댄" → "이유를 일일이 대지 않은"
- "강하게" — "세게"보다 더 자연한 경우도 있음
- "상대를 배제한 판단" — 자연 한국어. "상대를 빼놓고 내린 판단" 풀어쓰기는 오히려 어색 (2026-05-22 polish 학습)
- "확신하신 이유" — 한자어 단일 동사 단순. "어떤 확신으로 ...밀어붙였는지" 풀어쓰기·복합동사는 격동 톤이라 법정 발화에 부적합

진단 시 한자어 = 번역체 신호로 단정 X. **법정·재판관 발화는 한자어가 톤 자연성·간결성에서 우월한 경우 많음.**

### 7a. 법정·사안 한자어 적극 활용 (NEW v6 — 2026-05-22)

재판관 발화는 사안에 맞는 한자어 용어를 적극 활용하는 게 격식·정확성 둘 다 우수.

- "돈 문제" → "경제적 문제"
- "단순한 방어였다는 설명" → "단순한 방어 취지였다는 설명"
- "서류를 꾸민 행동" → "서류 조작"
- "본인이 직접 실행한 점" → "본인이 직접 하신 행동" (구체) 또는 한자어 명사화 가능

### 7b. 정중 청유 어미 "~신건지" (NEW v6)

NPC 존중 답변 청유 시 "~신건지 / ~으신지"가 자연 정중.

- "부부로 남고 싶은 마음이 있었는지" → "부부 관계를 유지하고 싶으신건지"
- "지금 어떤 후회로 남았는지" — keep 가능 (이미 자연)

## 8. 생략 + 번역 안전성 균형 (핵심 메타가이드 — v7 강화 2026-05-22)

한국어는 일부 상황에서 목적어·주어·지시어를 생략해야 더 자연스럽다. 하지만 **다국어 번역 시 오역 위험** 있는 경우 명료 유지. 사용자 강조 (2026-05-22): "한국어 특성상 주어·목적어를 생략하거나 뭉뚱그리는 경우가 많다보니 오역이 발생할 위험이 크다."

### 8a. 모호 지시어 줄이기

polish가 "그걸/그것/그쪽/그/이" 같은 모호 지시어로 단순화되면 다국어 번역자가 referent 잡기 어려움.

- (위험) "그것에 대해 말씀해 주십시오" — "그것"이 무엇? (영어 *that*은 더 모호)
- (안전) "그 책임에 대해 말씀해 주십시오" — referent 명시
- (위험) "그 차이를 고려하여" — referent 잡기 가능하지만 multilingual 번역 시 명사 보강 권장

### 8b. 한국어 생략 vs 영문 번역 명시화 균형

한국어 polish 시 생략한 부분이 영문에서 명사구로 복원 가능한지 검증.
- "본인이 한 행동을" — *what you did* (OK, 동작 행위로 복원 가능)
- "그 권한을" — 권한 = authority/right. 명사 명시. OK
- "그것에 대해" — *about that* (모호. 한국어 자연하지만 번역 시 보강 필요)

### 8c. 사건 사실 명시 우선

진실 누설 회피 + 다국어 안전성을 위해 추상 reference보다 **사건 명시** 우선.
- (모호·번역 위험) "그 사정" — *that situation* 모호
- (명시·안전) "그 가족 사정" 또는 "그 어려운 상황" (단, 진실 누설 키워드 회피)

번역 오역 우려:
- "장남으로 짊어진 무게" → 영어로 옮길 때 *what I've shouldered as the eldest son* — "the eldest son's role/responsibility" 함축을 살려야 함
- "그걸 흔드는 질문" — "그걸"이 무엇인지 앞 문장 컨텍스트로 명확해야 번역 가능

### 8d. polish 단계 다국어 검증 체크리스트

각 polish 시안에 대해:
1. 주어가 명시되어 있는가? 생략이면 문맥상 복원 가능한가?
2. 목적어가 명시되어 있는가? 생략이면 직전 문장에서 명확한가?
3. 지시어 ("그/이/그것/그쪽")가 referent 명확한가?
4. 추상 명사 ("사정/상황/문제/판단")의 구체화 정도가 영문 번역 시 충분한가?
5. 한자어 단축 ("실행/조작/배제/확신")이 영문 번역어와 1:1 매핑 가능한가?

## 9. 카테고리 위계 정합 (NEW v4) — 분기는 같은 등급에서

감정·행동·동기 등 추상 명사를 분기할 때 **상위 카테고리가 같아야 함**. 위계가 어긋나면 논리 충돌로 어색해짐.

- (X) "두려움이 배신이었는지, 버려짐이었는지" — 두려움은 감정 카테고리, 배신/버려짐은 사건 카테고리. 위계 어긋남.
- (O) "감정은 배신당했다는 분노였는지, 버려질지 모른다는 불안이었는지" — 감정 카테고리(분노/불안)로 통일

또한 "~지 ~지" 종속 의문보다 **분리 의문문 "~ㅂ니까, ~ㅂ니까?"**가 자연한 경우 많음. 두 선택지를 대비할 때 분리형 권장.

## 10. 군더더기 수식어구·강조 부사 제거 (NEW v4)

질문에 시간·상황 수식어구를 너무 많이 붙이면 게임 톤에서 어색. **단순·직접 질문**이 자연.

- "혼자 견디던 시간이 어떤 감정으로 쌓였는지" → "어떤 감정이 들었는지" (시간 수식어 제거)
- "각자 가장 늦게 인정한 감정" → "느낀 진정한 감정" (구체 단계 묘사 제거, 핵심만)
- "솔직히 말씀해 주십시오" → "말씀해 주십시오" (솔직히 등 강조 부사 제거)
- "오피스텔 문제를 두고" → "오피스텔 문제와 관련하여" (격식 접속 자연화)

### 10a. 메타 부사 vs 구체 청유 부사 구분 (NEW v5 — 2026-05-22 학습)

**제거 대상 = 메타·태도 강조 부사**: "솔직히", "분명히", "확실하게" — 화자가 자기 주관 강조하는 톤 (게임 채굴 강요 느낌)

**활용 대상 = 구체 청유·범위 부사**: "정확하게", "상세하게", "숨김없이", "각자 따로" — 답변 형식·범위를 구체 안내 (정중)

예:
- (X 메타) "솔직히 말씀해 주십시오" → 제거
- (O 구체) "그 이유를 상세하게 말씀해 주십시오" — 답변 깊이 안내
- (O 구체) "각자 한 행동들을 숨김없이 말씀해 주십시오" — 응답 범위 안내
- (O 구체) "각자 따로 말씀해 주십시오" — 두 분 청자에게 응답 분리 안내

## 12. 명사화 ↔ 동사화 균형 (NEW v5)

추상 명사화가 무조건 번역체는 아니지만, **양극 명사화** ("X와 Y") 구조는 동사화가 자연한 경우 많음. 단, 한자어 단일 명사·동사는 keep (가이드 #7).

- "숨김과 단정이 서로를 키웠다" → "숨기고 단정지은 것이 상황을 키웠다" (양극 명사 → 동사)
- "출금을 본 것" → "출금을 발견한 것" (일반 동사 → 한자어 동사, 격식 톤 강화)
- "그 사이 빈 곳" → "그 간극" (풀어쓰기 → 한자어 명사, 간결)

판단 기준: 입말에서 자주 쓰는 형태로. 양극 대비 추상명사 ("숨김 vs 단정")는 어색, 한자어 단일 동사 ("정정/배제/확신")는 자연.

### 12a. 3중+ 나열은 한자어 명사 통일 (NEW v6 — 2026-05-22)

세 가지 이상 행위 나열 시 동사화 풀어쓰기보다 **사안 한자어 명사로 통일**이 법정·격식 톤에서 강력.

- (X) "오피스텔을 숨긴 일, 계좌를 감시한 일, 돈을 직접 움직인 일을 각각 시점별로" — 동사화 장황
- (O) "오피스텔 방문, 계좌 감시, 무단 출금을 각 시점별로" — 한자어 명사 통일

3중+ 나열 시 동사 표현이 늘어지면 한자어 사안 명사 (방문/감시/출금/조작 등) 통일이 더 자연. 가이드 #12 양극→동사화와 구분.

## 13a. 추궁 톤 구체화 (NEW v6 — #13 보완)

비난·추궁 강화 시 추상 동사("침묵"/"방관") → 구체 동사("숨기고 있으니"/"외면하니")로 사안 정확성 + 비난 톤 강화.

- "상대가 침묵하면 내 행동이 정당화된다는" → "상대가 숨기고 있으니 내 행동도 정당화된다는" (추상→구체 + "도" 비교)

## 17. 간접 의문문 우선 (NEW v6 — 정중 청유)

"왜 X했는지" 직접 의문보다 "X한 원인이 무엇이라고 생각하는지" 간접 의문이 정중·NPC 자기 분석 청유.

- "왜 상대를 더 외롭게 만들었는지" → "상대를 더 외롭게 만들게 된 원인이 무엇이라고 생각하는지"
- 또한 "왜 X한지 그 이유를"  → "X한 이유를" (이중 의문 단순화)

## 17a. 동기 변환: 의지 → 강제·상황 (NEW v6.1 — 2026-05-22)

NPC 동기 묘사할 때 의지·선택 표현보다 강제·상황 표현이 정서적으로 부드러움.

- "그 마음이 왜 숨기는 방식을 택했는지" → "그걸 왜 숨길 수 밖에 없었는지"
- "왜 그렇게 행동했는지" → "왜 그렇게 할 수밖에 없었는지"
- NPC 책임 추궁 시에도 "택했다" 의지 강요 < "수밖에 없었다" 상황 인정이 더 자연 (NPC가 답할 여지 많음)

## 18. 응답 안내 부드러움 (NEW v6 — #10a 보완)

답변 reflection 시간을 주는 응답 안내 부사·구문은 정중 강화.

- "말씀해 주십시오" → "생각해보고 말씀해 주십시오" (reflection 시간 주기)
- "인정한 뒤 말씀해 주십시오" → "고려하여 말씀해 주십시오" (메타 강요 제거)
- 가이드 #10a 메타 부사 제거와는 다른 방향 — 강요 톤 X, 청유 톤 ✓

## 13. 대비 구조 주어 생략 (NEW v5)

두 주체·행위를 대비할 때 주어 매번 명시하면 장황. **동사만 대비**가 자연.

- (X) "숨긴 사람은 무엇을 숨겼고, 단정한 사람은 왜 단정했는지" — 주어 반복
- (O) "무엇을 숨겼고, 왜 그렇게 단정 지었는지" — 동사만 대비 (청자 두 분 = "두 분"으로 이미 호명)

## 14. 단정·강도 조절 (NEW v5 — #4 보완)

"단정 keep"이 절대 원칙은 아님. NPC 정서·dispute 단계에 따라 단정 ↔ 의심 강도 조절.

- 강한 단계: "단정" (확정·압박 톤)
- 약한 단계: "의심" (탐색·완곡 톤)
- 예: "외도라는 단정을 거두지 못한 이유" → "외도라는 의심을 거두지 못한 이유" (NPC에게 너무 단정 압박 부적절한 맥락에서)

## 15. 피동 자연성 (NEW v5)

행위 주체보다 사건 자체를 강조할 때 피동 자연.

- "그 현금이 누구에게 어떤 사정으로 건너갔는지" → "그 돈이 누구에게 어떤 사정으로 건네어졌는지" (피동 + 일반어)
- 능동 강조가 어색한 맥락 (누가 했는지 자체가 추궁 대상이 아니라 사건 흐름 추적인 경우)에서 피동 우선

## 16. 단정 동사 → 완곡 추측 (~보입니다 / ~느껴집니다) (NEW v5 — #2 확장)

판단·평가 동사는 "~보입니다", "~느껴집니다"로 완곡화하면 차분 톤 강화. 가이드 #2 "~것 같다"의 격식체 확장.

- "부족합니다" → "부족해보입니다"
- "이상합니다" → "이상하게 느껴집니다"
- "적절하지 않습니다" — 그대로 차분, OK
- 재판관 발화에서 자기 판단 단언 → 완곡 추측으로 톤 부드럽게

## 11. 질문의 게임 유효성 검토 (NEW v4 — 단순 polish 넘어)

자연화 작업 중 **질문 자체가 답변 가능한지 / 게임 메커닉상 가치 있는지** 검토 필요. 표현 polish로 해결 안 되는 경우 재설계·폐기 후보로 표시.

검토 기준:
- NPC가 답할 수 있는 질문인가? (서로 의도를 숨긴 상태에서 "엇갈림에 대해 말해" 같은 추상 질문은 답 불가)
- 답이 어떤 정보를 unlock하는가? (단서/감정/트러스트 등 게임 변수와 연결)
- 답이 dispute 진행에 영향을 주는가?
- 메타적·관조적 질문(상황 자체에 대한 reflection 요구)은 보통 게임 메커닉상 무용

예 (Sample 6): "상처를 줄까 봐 숨긴 마음과 상처받지 않으려 확인한 마음이 어떻게 엇갈렸는지" — 표현은 자연하지만 답변 가능성·게임 가치 둘 다 불명. polish 대신 재설계 검토 표시.

**답변 가능 정보로 전환 패턴** (2026-05-22 학습):
- "어디서 갈라졌는지 [메타 reflection]" → "**X, Y, Z에 대해 생각하시는 바를** [구체 항목]"
- 추상 reflection 자연화 = 구체 정보 항목 명시
- 예: "돈이 빠진 방식과 그 돈을 해석한 방식이 어디서 갈라졌는지" → "돈이 빠져나간 경위와 출처 및 사용처에 대해 생각하시는 바를"

## 18a. 직업 호칭 회피 (NEW v7.1 — 2026-05-22)

증인·관계자 호칭에 직업명 직접 사용은 어색·번역체 느낌. 이름 호칭 또는 생략 권장.

- (X) "은행 직원님, 해지 서류 접수 당시의..."
- (O) "해지 서류 접수 당시 확인 절차와 함께..." (호칭 생략, 응답 청유로 시작)
- (O) "박미라 씨, 링크를 ..." (이름 호칭)
- 단, 직업 호칭이 정착된 경우 (판사님, 의사 선생님 등)는 OK

## 18b. 단정 회피·조건절 활용 (NEW v7.1)

증인·NPC 답변 청유 시 가정 강요 단정 피하고 **조건절** 활용. 답할 여지 보장.

- (X 단정) "미흡했던 부분을 구분해 말씀해 주십시오" — 미흡 가정
- (O 조건) "특이사항이 있었다면 모두 말씀해 주십시오" — 가정 X, 응답 자유

## 18c. 시점 의문 풀어쓰기 (NEW v7.1)

명사화 시점 ("X한 시점")보다 풀어쓰기 의문 ("X를 언제 했는지")이 더 자연.

- "링크를 보낸 시점과" → "링크를 언제 보냈는지, 그리고"
- "송금이 일어난 시점" → "송금이 언제 있었는지"

## 19. 사건 흐름 정합성 사전 검증 (NEW v7 — 2026-05-22)

자연화 작업은 표현 polish이지만, **entry 자체의 사실 관계가 사건 흐름과 맞지 않으면 polish 해도 무의미**. 자연화 시도 전 entry 진실성 검증.

검증 포인트:
1. evidence 묶음이 dossier 카드와 정합한가? (서로 다른 dossier 영역 evidence가 같은 entry에 link되면 데이터 오류)
2. NPC 발화의 사건 시점이 timeline과 맞는가? (외도 의심 → 위임장 조작 → 적금 해지 → 송금 순서)
3. 추궁 내용이 실제 진실/거짓 구조와 맞는가? ("X가 먼저 vs Y가 먼저" 같은 frame이 사실과 맞는지)
4. case별 [[project_spouse01_event_timeline]] 등 참조

발견 시 자연화 보류 + 데이터 매핑 backlog 추가. 사용자에게 사실 관계 확인 후 폐기/재작성/다른 entry 수정 결정.

## 적용 — 작업 패턴

자연화 작업 시 순서:
1. **사건 흐름 정합성 검증** (#19) — entry 사실 관계가 timeline에 맞는지
