# 07. 캐릭터 frame (Cycle 4 신규 backstory 반영)

## 박지연 (A — claimant, 외도 의심하는 쪽)

| 영역 | 내용 |
|---|---|
| 나이/직업 | 36세 / 학원 데스크 직원 |
| archetype | `victim_cosplay` (피해자 위치를 먼저 잡고 말하는 패턴) |
| pride / fear / riskAppetite | 6 / 위임장 조작이 범죄로 확정 + 출산 화제 회피 / 5 |
| digitalHabit | `messenger_main` |

### 신규 backstory (Cycle 4)

- **신혼 초기 난임 진단** (결혼 1~3년차)
- **본인 인지**: 본인 난임 진단 인지
- **반응**: 충격으로 출산 포기. 그 이후로 임신·출산 화제가 나오면 자리를 피하거나 침묵으로 닫음
- **이준호의 혼자 조사는 모름**: 남편이 혼자 출산 가능성을 더 알아본 사실은 인지 X
- **fear에 추가된 영역**: "신혼 초기 난임 진단을 받은 이후 출산이라는 화제 자체를 다시 꺼내야 하는 자리도 견디지 못한다."
- **dailyRoutine에 추가**: "난임 진단 이후로는 산부인과·임신 관련 화제가 나오면 자리를 피하거나 침묵으로 닫는다."

### speechStyle (기존 유지)

> 배신당한 사람이라는 위치를 먼저 잡고 말하지만, 동기 질문이 들어오면 수치심과 불안을 핑계로 설명 범위를 넓힌다.

### verbalTells

- victim_frame (cornered) — 자신도 이미 배신당한 사람처럼 먼저 위치를 잡는다.
- helplessness (shame) — 그때는 다른 선택이 없었다는 말로 계산된 선택의 각도를 흐린다.
- soft_confession (shame) — 작은 인정부터 꺼내고 가장 수치스러운 사실은 마지막에 말한다.

### callTerms

- toPartner: 자기
- toJudge: 제 남편
- angry: 이준호!

### h-d4 영역에서 박지연의 발화 frame

- **S0~S1**: 비자금 사용처 = 형으로 확정. 다른 목적 영역은 모름 / 형 외 가능성은 일축
- **S2**: 신규 자료(e-8/e-9) 영역 인정 — 한때 외도 의심도 했으나 형 일과 다른 영역이라는 점 받아들임
- **S3**: "그 사람이 그걸 혼자 알아봤었구나" — 본인 영역과의 연결은 아직 직접 언급 X
- **S4**: "그 화제는 내가 닫아 둔 거였다" — 본인 난임 진단 + 회피 책임 직접 언급
- **S5**: 두 사람의 침묵을 한 묶음으로 진술. 부부 침묵의 한 축 + 회피의 책임 명시

### 박지연 영역 자연성 주의

- 외도 frame은 S1까지 일부 유지 ("내연녀 임신 의심", "수익자 의심" 등)
- 본인 난임 진단 영역은 S4 이전에 직접 언급 절대 X (forbiddenKeywords)
- "남편이 혼자 알아봤다"는 사실에 대한 감정은 분노보다 침잠 (자기 화제 회피의 책임 인식)

## 이준호 (B — defendant, 알리바이 대는 쪽)

| 영역 | 내용 |
|---|---|
| 나이/직업 | 38세 / 가전매장 직원 |
| archetype | `avoidant` (모호어로 시간 벌다 한꺼번에 털어놓는 패턴) |
| pride / fear / riskAppetite | 6 / 형 이야기 시댁 갈등 + 아내가 닫은 난임 화제 다시 들춤 / 4 |
| digitalHabit | `minimal` |

### 신규 backstory (Cycle 4)

- **인지**: 박지연의 난임 진단 + 출산 포기 + 화제 회피 모두 인지
- **결정**: 아내 결정을 존중하면서도 부담을 주지 않으려 화제를 다시 꺼내지 못한 채 혼자 출산 가능성을 더 알아보기로 함
- **조사 방법**: 의사 친구의 비공식 상담 (전화/만남) + 휴대폰으로 산부인과·여성 질환·고위험 임신·시험관 비용 등 의학 영역 검색 + 여러 보험사에서 의료비 보장 특약 상담을 받았으나 **가입은 한 건도 없음** (결정에 도달 못 함)
- **자금 마련**: 신혼 초기부터 본인 명의 별도 계좌에 비자금 3,000만원 모금
- **자금 전환**: 형 개인회생 사건 발생 후 그 자금을 형에게 전달
- **fear에 추가된 영역**: "그리고 아내가 닫아 둔 난임이라는 화제를 다시 들춰 부담을 주는 것도 똑같이 두렵다."
- **dailyRoutine에 추가**: "아내 모르게 산부인과·고위험 임신 관련 자료를 검색하고 의사 친구와 통화하며 보험 상담도 비공식으로 받아 왔다."

### speechStyle (기존 유지)

> 사실을 완전히 부정하기보다 중요한 이유를 뒤로 미루고, 모호어로 시간을 벌다가 압박이 누적되면 한꺼번에 털어놓는다.

### verbalTells

- answer_delay (avoiding) — 질문을 바로 받지 않고 한 박자 늦게 받아 핵심어를 피한다.
- partial_scope (cornered) — 큰 사실은 인정하되 가장 아픈 이유는 마지막까지 자른다.
- minimize_harm (defensive) — 선의였다는 말로 절차 위반의 무게를 먼저 낮추려 한다.

### callTerms

- toPartner: 자기
- toJudge: 제 아내
- angry: 박지연!

### h-d4 영역에서 이준호의 발화 frame

- **S0**: "그냥 모은 돈" frame strict. 사용처 = 형. 다른 목적 절대 부정
- **S1**: "원래는 형 일과 별개로 모았다" — 진짜 목적은 회피. "나중에 생긴 일"이라는 표현으로 시기 분리
- **S2**: 휴대폰 검색 + 보험 상담 본인 것 인정. "가입까지 가지 않았다." 용도는 회피 ("그냥 알아본 정도")
- **S3**: "혼자라도 알아봐야 했다" — 의사 친구 + 보험 상담 + 가입 없음 + 부담 회피 동기 인정. **난임/치료비 keyword X**.
- **S4**: "치료비"라는 단어 처음 꺼냄. 본 목적 명시
- **S5**: "그 돈은 처음엔 당신을 위한 거였다" — 완전 자백

### 이준호 영역 자연성 주의

- avoidant archetype 특성 살리기 — 모호어 시간 벌이 + 한 박자 늦은 답
- 본인 가족 호칭은 자기시점 ("우리 형 / 형네 / 우리 집") — "시댁" 절대 X (남편 본인이 자기 가족을 '시댁'으로 부르면 어색)
- 아내를 가리킬 때 NPC 발화에서는 "제 아내" (toJudge) / "자기" (toPartner) / 격앙 시 "박지연!"
- 난임/치료비 keyword는 S4부터 등장 OK. S3까지는 "혼자 알아봄" / "부담 회피" 등 우회 표현
- 부담 회피 동기는 "아내가 닫아 둔 화제를 다시 들추지 않으려" frame이 가장 자연

## 두 캐릭터 간 발화 dynamics (h-d4 영역)

| 단계 | A frame | B frame | 두 사람 사이 |
|---|---|---|---|
| S0 | "그냥 형에게 갔다" | "그냥 모은 돈" | 두 사람 모두 표면 frame |
| S1 | "다른 이유 있을 수도" | "원래는 형 일 별개로 모았다" | A의 의문 + B의 부분 인정 |
| S2 | "수상한 자료, 외도 의심도 했었다" | "검색·상담 본인 것 맞다, 용도는…" | 신규 자료 양쪽 인정 |
| S3 | "혼자 알아봤구나" | "혼자라도 알아봐야 했다" | A의 인식 변화 + B의 부분 자백 |
| S4 | "그 화제는 내가 닫아 둔 거" | "치료비" 처음 꺼냄 | A의 본인 책임 인정 + B의 본 목적 명시 |
| S5 | 두 사람 침묵 한 묶음 | 처음엔 당신을 위한 거였다 | 부부 침묵 한 축으로 통합 |
