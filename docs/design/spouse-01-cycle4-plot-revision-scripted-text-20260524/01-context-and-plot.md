### 신규 캐릭터 backstory

#### 박지연 (A) — 신혼 초기 난임 진단

- **시기**: 결혼 1~3년차 (신혼 초기)
- **본인 인지**: 본인 난임 진단 인지함
- **반응**: 충격으로 출산 자체를 포기. 그 이후로 임신·출산 화제가 나오면 자리를 피하거나 침묵으로 닫음
- **fear**: 위임장 조작이 범죄로 확정되는 것 + 출산 화제를 다시 꺼내야 하는 자리
- **이준호 조사는 모름**: 남편이 혼자 출산 가능성을 더 알아본 사실은 인지 X

#### 이준호 (B) — 혼자 난임 치료비 마련

- **인지**: 박지연의 난임 진단 + 출산 포기 + 화제 회피 모두 인지
- **결정**: 아내의 결정을 존중하면서도 부담을 주지 않으려 화제를 다시 꺼내지 못한 채 혼자 출산 가능성을 더 알아보기로 함
- **조사 방법**:
  - 의사 친구의 비공식 상담 (전화 / 만남)
  - 휴대폰으로 산부인과·여성 질환·고위험 임신·시험관 비용 등 의학 영역 검색
  - 여러 보험사에서 의료비 보장 특약 상담을 받았으나 **가입은 한 건도 없음** (결정에 도달 못 함)
- **자금 마련**: 신혼 초기부터 본인 명의 별도 계좌에 비자금 3,000만원 모금
- **자금 전환**: 형이 개인회생에 들어가자 그 자금을 형에게 전달 (4회 분할 현금 출금)

### 진실 reveal 흐름

1. **d-1 reveal**: 오피스텔 방문 대상 = 형/조카 (외도 X) 확인
2. **d-2 reveal**: 비자금 사용처 = 형 개인회생 자금 전달 확인
3. **신규 의문 부상**: 비자금이 10년 가까이 모인 자금인데 형 사건이 생기기 전부터 모인 자금. 휴대폰의 산부인과 검색 + 보험 상담 견적은 무엇이었나? 처음엔 외도 의심으로 보였지만 형 사건과는 무관한 영역.
4. **신규 증거 발현**: e-8 (휴대폰 의학 검색 기록) + e-9 (보험사 견적 자료, 가입 없음)
5. **단서 카드 부상**: dc-8 (이준호의 또 다른 침묵) — e-8 + e-9 결합으로 등록
6. **h-d4 발현**: d-2 S5 자백 + 신규 증거 Original 이상 + dc-8 부상 → 새 쟁점 "비자금의 원래 목적" 등록
7. **h-d4 reveal**: 비자금 원래 목적 = 박지연 난임 치료비 마련. 이준호 혼자 의사 친구 상담 + 보험 알아봤으나 가입은 못 함.

### 책임 분담 (h-d4)

- **B 70 / A 30**
- B: 침묵 + 독단으로 혼자 조사·자금 마련. 부부 공동 영역을 단독 결정으로 가져감
- A: 화제를 닫고 회피한 것도 부부 침묵의 한 축. 소통 단절의 일부 책임

### 자금 timeline

- **stage 1 (결혼 1~3년차)**: 박지연 난임 진단 + 이준호 혼자 조사·자금 마련 시작 (신규 stage)
- **stage 3 (10년간)**: 비자금 누적 ~3,000만원 (원래 목적 = 난임 치료비, 형 사건 후 전환)
- **stage 4 (사건 발생 4개월 전)**: 형 사건 발생 → 4회 분할 현금 출금
- **stage 5 (사건 발생 6주 전)**: A가 외도 단정 후 위임장 위조 + 공동 적금 해지
- **stage 6 (해지 직후)**: 박미라 소개 투자방에 송금 → 사기로 손실
