# PC UI 디자인 시스템 가이드 v2.0

> **목적**: v1.0(`PC-UI-DESIGN-SYSTEM.md`)의 토큰 시스템을 유지하면서, 사용자 5개 결정(시각 스타일 갈아엎기 OK / 설정 신설 / Judge Desk 우선순위 유지 / 풀스크린 / Phase 3a 동일 구조)을 반영해 **시각 스타일 매트릭스 + UX 변경안 + 설정 카테고리 + 풀스크린 적용 가이드**를 새로 정립한다.
>
> **버전**: v2.0 — 2026-04-25
>
> **베이스**: v1.0 (토큰/컴포넌트/타입스케일/애니메이션 모두 유지)
>
> **변경 범위**: 시각 스타일 옵션화 / 모달→풀스크린 / 설정 카테고리 9종 신설 / Judge Desk 풀스크린 / Phase 3a·판결·결과는 컬러+버튼만

---

## 0. v1.0 → v2.0 차이 요약

| 영역 | v1.0 | v2.0 |
|---|---|---|
| 시각 톤 | 다크 우드 + 골드 단일 | **4가지 옵션 매트릭스** (사용자 선택) |
| 모달/풀스크린 | 모달 중심 (Settings, Profile) | **체류형은 풀스크린** 권장 |
| 설정 카테고리 | 해상도 1종 | **9종** (화면/오디오/게임플레이/데이터/언어/접근성/키보드/계정/정보) |
| Judge Desk | 패널형 | **풀스크린 3섹션** (프로필 / 9조각 / 6성향+퍼크) |
| 토큰 시스템 | 정립됨 | **유지** + 옵션별 변형 정의 |
| Phase 3a/판결/결과 | 리뉴얼 1순위 | **기본 구조 동일**, 컬러·버튼만 토큰 치환 |

## A. 시각 스타일 옵션 매트릭스 (4가지)

> 사용자가 1개를 선택. 토큰 값만 옵션별로 교체하면 전체 화면에 일관 적용. 컴포넌트 구조 변경은 없음.

### 옵션 1 — 현재 톤 정밀화 (Polished Wood) ⭐ 보수적 선택

| 항목 | 값 |

| **톤 키워드** | 무게감 / 권위 / 안정감 |

| **핵심 차이** | "지금 화면을 좀 더 단정하게" — `--pc-amber`/`--pc-gold` 통합, spacing/radius 토큰 도입 |

## B. UX 변경안

### B.1 모달 → 풀스크린 분류 가이드

| 분류 기준 | 모달 유지 | 풀스크린 전환 |
|---|---|---|
| **체류 시간** | < 10초 | ≥ 30초 |
| **선택지 수** | 1~3개 | 4개+ 또는 카테고리 분기 |
| **상태 변경** | 단일 확인 | 다단계/여러 항목 |
| **시각 정보량** | 텍스트 위주 | 이미지/그리드/탭 포함 |

### B.2 현재 게임의 모달/팝업 일람 + 권장 UX

| 화면/팝업 | 현재 | 권장 v2 | 이유 |
|---|---|---|---|
| 설정 (Settings) | 모달 | **풀스크린** | 카테고리 9종 + 옵션 다수 |
| 프로필 / Judge Desk | 모달 (모바일 유산) | **풀스크린** | 9조각 + 6성향 + 15퍼크 시각화 |
| 사건 선택 | 풀스크린 (이미) | 유지 | 그리드 + 필터 |
| Phase 3a 중재 | 인페이즈 | **유지** (구조 동일) | 사용자 결정 |
| 판결 (Verdict) | 풀스크린 (이미) | 유지 (컬러/버튼만 치환) | 사용자 결정 |
| 결과 (Result) | 풀스크린 (이미) | 유지 (컬러/버튼만 치환) | 사용자 결정 |
| 증거 카드 자세히 | 모달 | 모달 유지 | 단일 확인 |
| 도시에 카드 (DossierCard) | 모달 | 모달 유지 | 단일 사용 액션 |
| 확정 다이얼로그 (취소/리셋) | 모달 | 모달 유지 | 1~3 선택지 |
| 사건 종료/이탈 확인 | 모달 | 모달 유지 | 단일 확인 |
| 시스템 알림 (해금/모순) | 토스트/배너 | 토스트 유지 | 비차단형 |
| 도움말/단축키 | 모달 | **풀스크린** (선택) | 정보량 많음 |

### B.3 네비게이션 패턴 비교

| 패턴 | 장점 | 단점 | 권장 사용처 |
|---|---|---|---|
| **하단 핫바** | 게임플레이 액션 빠름 | 메뉴 영역 좁음 | Phase 1~2 액션 (현재) |
| **상단 메뉴** | 화면 분할 분명 | 게임 몰입도↓ | Home, 설정, Judge Desk |
| **사이드바** | 카테고리 많을 때 효율 | 가로 폭 차지 | 설정 좌측, Judge Desk 좌측 |

> **결정**: 게임플레이는 핫바 유지, 풀스크린 화면(설정/Judge Desk)은 **좌측 사이드바 + 우측 콘텐츠**.

### B.4 입력 인터랙션 패턴

| 입력 | 패턴 | 적용 |
|---|---|---|
| **마우스 클릭** | 단일 액션, 선택, 확인 | 모든 버튼 |
| **마우스 호버** | 미리보기, 툴팁 | 카드, 증거, 퍼크 |
| **마우스 드래그** | 슬라이더, 책임 배분 | 판결 ResponsibilitySlider |
| **키보드 단축키** | Esc(닫기), Enter(확인), Tab(이동) | 풀스크린 화면 필수 |
| **방향키** | 카드 그리드 내비 | 사건 선택, 9조각 인벤토리 |
| **숫자키** | 빠른 선택 (1~9) | 핫바 액션 (선택사항) |

> **신규 권장**: 풀스크린 화면 진입 시 좌상단에 [Esc 닫기] 힌트 표시. 키보드 fokus 링은 골드 1px outline.

## C. 설정 카테고리 신규 매트릭스

> 모달 → **풀스크린**. 좌측 카테고리 사이드바(9종) + 우측 옵션 영역.

### C.1 카테고리 구조

| # | 카테고리 | 아이콘 컨셉 | 우선순위 | 옵션 수 |
|---|---|---|---|---|
| 1 | **화면 (Display)** | 모니터 | 필수 | 4~6 |
| 2 | **오디오 (Audio)** | 스피커 | 필수 | 5 |
| 3 | **게임플레이 (Gameplay)** | 게임패드 | 권장 | 6~8 |
| 4 | **데이터 (Data)** | 디스크 | 권장 | 4 |
| 5 | **언어 (Language)** | 글로브 | 권장 | 1 (확장) |
| 6 | **접근성 (Accessibility)** | 눈 | 선택 | 5 |
| 7 | **키보드 (Controls)** | 키보드 | 선택 | 가변 |
| 8 | **계정 (Account)** | 사용자 | 선택 (확장) | 1~3 |
| 9 | **정보 (About)** | i 마크 | 필수 | 4~5 |
