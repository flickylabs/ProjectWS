## Evidence Frame

### e-4: 발신자 미상 문자
B 이준호가 받은 문자. 진실: 형으로부터 문자 (진실은 진실 노출 전까지 회피).

### e-5: 개인 계좌 현금 출금
B 이준호의 개인 계좌 출금. 진실: 형의 회생 자금 (진실은 진실 노출 전까지 회피).

### e-6: 투자방 텔레그램
A 박지연이 가입한 투자방. 박지연이 직접 송금했다가 손실.

### e-7: 송금 기록
A 박지연 → 투자방 송금 (공동 적금 해지 후 진행). 박지연의 위임장 영역 evidence.

---

## 본 batch 특성

- 발화 주체: A (박지연, claimant) — e-6/e-7 송금·위임장 영역 + B (이준호, defendant) — e-4/e-5 자금 영역
- 어색 패턴 검출: 45 variants — 강조 부사 / 추상명사 / 직역 어미
- 진실 누설: 본 batch entries는 직전 진실 누설 회피 batch에서 빠진 영역. hidden 키워드 직접 등장 X 가정.
  → polish 시 hidden 단어 **신규 도입 X** 만 보장.
- lieBand 분포: early / mid / late
- stage 분포: 일반 (1/2/3) + 특수 (check_metadata / request_original / restore_context) — e-6/e-7는 메타 stage 다수

---

## lieBand · stage 의미 가이드

| lieBand | stage | NPC 톤 |
|---------|-------|--------|
| early | 1 / 2 / 3 / check_metadata | 초반 회피·부정·방어 |
| mid | 1 / 2 / 3 / request_original / undefined | 중반 부분 인정·변명 |
| late | 1 / 2 / 3 / restore_context / undefined | 후반 진실 인정 |

특수 stage 의미:
- **check_metadata**: 첫 자료 제시 시 NPC가 자료 자체 검증 (날짜·금액 확인)
- **request_original**: NPC가 자료 원본을 추가 요청 (방어)
- **restore_context**: NPC가 자료의 맥락 (의도·이유) 보강

→ 각 stage 톤·발화 의도 보존 필수.

## 출력 형식

```
## Batch 2 결과

a-e-4-early-1-v...:
변경 후: <<polish 결과 KO 한 줄 (또는 두 줄)>>
변경 영역: <<어떤 어색 패턴을 어떻게 자연화했는지 1~2줄>>

... (45건 모두)
```

### 출력 시 주의사항

1. 각 ID는 표의 ID 그대로 사용
2. 변경 후 텍스트는 자연 한국어 한 문장 또는 두 문장 (원본 구조 따라)
3. 변경 영역은 짧고 명료하게 — 어떤 어색 패턴 (강조 부사/추상명사/직역 어미/피동) 자연화했는지
4. 추측·해설 추가 X — polish 결과만 명확히 제시
5. NPC 발화 톤 (재판관 청유 X) 보존
6. lieBand 단계 톤 (early 방어 / mid 인정+변명 / late 진실 인정) 보존
7. 특수 stage 톤 (check_metadata 검증 / request_original 방어 / restore_context 맥락 보강) 보존
8. **진실 누설 자가 점검** — hidden 키워드 (가족/집안/시댁/형/회생/형사/사기/횡령/범죄/위조/위법) 신규 도입 X
9. **band=late entries**: 일부는 이미 진실 노출 단계 — KO 원본의 hidden 키워드 **보존 OK** (제거 X). 의도된 진실 인정 발화.
