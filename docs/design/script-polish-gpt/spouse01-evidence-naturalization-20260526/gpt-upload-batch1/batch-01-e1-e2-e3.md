# Batch 1 — evidence_present e-1 + e-2 + e-3 자연화 의뢰 (50 variants) ★ NPC 자연화

> 본 file을 진행하기 전 `policy-01-natural-korean.md` 와 `policy-02-truth-disclosure.md` 를 정독해 주세요.

## Evidence Frame

### e-1: 학원생 참고서 영수증
B 이준호가 학원생용 참고서를 사다 줌. 진실: 형 자녀의 학원비를 이준호가 대신 부담 (진실은 진실 노출 전까지 회피).

### e-2: GPS 차량 좌표
B 이준호 차량이 오피스텔 방문 기록. 진실: 형을 만나러 간 위치 (진실은 진실 노출 전까지 회피).

### e-3: 통화기록
B 이준호 → 미저장 번호 새벽 통화. 진실: 형 번호 (진실은 진실 노출 전까지 회피).

---

## 본 batch 특성

- 발화 주체: A (박지연, claimant) + B (이준호, defendant)
- 어색 패턴 검출: 50 variants — 강조 부사 / 추상명사 / 직역 어미 / 피동
- 진실 누설: 본 batch entries는 직전 진실 누설 회피 batch에서 빠진 영역. hidden 키워드 직접 등장 X 가정.
  → polish 시 hidden 단어 **신규 도입 X** 만 보장.
- lieBand 분포: early / mid / late (3 단계 모두 등장)

---

## lieBand · stage 의미 가이드

| lieBand | stage | NPC 톤 |
|---------|-------|--------|
| early | 1 / 2 / 3 | 초반 회피·부정·방어. "...아닙니다" / "...어렵습니다" |
| mid | 1 / 2 / 3 / undefined | 중반 부분 인정·변명. "...맞습니다, 다만..." |
| late | 1 / 2 / 3 / undefined | 후반 진실 인정. "...입니다. 책임이 있습니다." |

→ polish 시 같은 entry 안의 variants는 같은 단계 톤 유지, 단조 반복은 피하고 표현 다양화.

## 출력 형식

```
## Batch 1 결과

a-e-1-early-1-v...:
변경 후: <<polish 결과 KO 한 줄 (또는 두 줄)>>
변경 영역: <<어떤 어색 패턴을 어떻게 자연화했는지 1~2줄>>

... (50건 모두)
```

### 출력 시 주의사항

1. 각 ID는 표의 ID 그대로 사용
2. 변경 후 텍스트는 자연 한국어 한 문장 또는 두 문장 (원본 구조 따라)
3. 변경 영역은 짧고 명료하게 — 어떤 어색 패턴 (강조 부사/추상명사/직역 어미/피동) 자연화했는지
4. 추측·해설 추가 X — polish 결과만 명확히 제시
5. NPC 발화 톤 (재판관 청유 X) 보존
6. lieBand 단계 톤 (early 방어 / mid 인정+변명 / late 진실 인정) 보존
7. **진실 누설 자가 점검** — hidden 키워드 (가족/집안/시댁/형/회생/형사/사기/횡령/범죄/위조/위법) 신규 도입 X
8. **band=late entries**: 일부는 이미 진실 노출 단계 — KO 원본의 hidden 키워드 ("가족"/"형"/"집안" 등) **보존 OK** (제거 X). 의도된 진실 인정 발화이므로 자연화만 수행하고 단어는 유지.
