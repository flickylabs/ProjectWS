## 사건 구도 (★ family-01)

- **A = 윤정희** (claimant): 큰누나, 어머니의 마지막 1년 거의 못 찾아옴. 유서·자필 90:10 불일치 의심.
- **B = 윤정후** (defendant): 동생, 어머니 직접 모심. 공증 단계 진행 재촉 정황. 친부 = 정후 (출생 비밀, e-7 영구 봉인).

## 본 batch evidence

- **e-5**: 자필 유언장 연습본 (90:10 영역 → late stage = 진실 인정)

### 출력 시 주의사항

1. Archetype N 번호 + sample ID 명기
2. 변경 후 텍스트는 자연 한국어 한 문장 또는 두 문장
3. **archetype 자연화** — 1~10 entries 동시 적용 영역. evidence-specific 동사 X
4. NPC 발화 톤 (재판관 청유 X) 보존
5. **B late 톤 보존** — 자기 책임 부분 인정 + 후술 약속
6. **family-01 진실 누설** — 모두 late stage = e-5 (90:10) / e-4 (재촉 정황) 영역 보존 OK. 단, **출생 비밀 / 친부 실명 / 정후 진실 등 hidden keyword 신규 도입 X**.
7. **호명**: "어머니" 보존
8. **core + 보강 일관성** — Arch 3-5는 Arch 2 core polish와 일관된 보강 문장 처리
