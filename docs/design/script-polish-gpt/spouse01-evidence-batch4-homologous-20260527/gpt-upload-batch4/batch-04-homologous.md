### early (Groups 1-21, 21 archetypes)
박지연의 **외도 단정 회피 시도 → 자기 의심 굳히기 → 책임 분산** 톤.

### 출력 시 주의사항

1. Group N 번호 + archetype key 명기
2. 변경 후 텍스트는 자연 한국어 한 문장 또는 두 문장 (원본 구조 따라)
3. 변경 영역은 짧고 명료하게
4. **archetype 자연화 — evidence-specific 동사/명사 X** (5 evidence 동시 적용 영역)
5. NPC 발화 톤 (재판관 청유 X) 보존
6. lieBand 단계 톤 보존 (early 단정·자기 결론 굳히기 / mid 부분 인정·자기 반성)
7. **어색 패턴 강제 제거** + **어미 다양화** (없었습니다/있었습니다/아닙니다 등 반복 회피)
8. **진실 누설 자가 점검** — hidden 키워드 (가족/집안/시댁/형/회생/형사/사기/횡령/범죄/위조/위법) 절대 도입 X (모두 early/mid stage = 진실 노출 전 영역)
