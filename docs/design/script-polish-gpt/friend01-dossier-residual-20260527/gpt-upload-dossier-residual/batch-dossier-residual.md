### 출력 시 주의사항

1. ID 표 그대로 사용
2. 변경 후 텍스트는 자연 한국어 (원문 길이/리듬 보존)
3. 변경 영역은 짧고 명료
4. dossier 답변 톤 보존 (formal honorific, 재판관님 호명)
5. **자기지시 정책**: NPC 자기 발화 영역 본인/자신 사용 X → 저/제
6. **직역 어미 자연화**: "가리킵니다 / 드러납니다 / 이어집니다"
7. **추상명사 구체화**: "그 부분 / 그 점 / 그 판단 / 그 결론" → 구체 referent
8. **강조 부사 정밀**: "그렇게 / 끝까지 / 차분히 / 완전히 / 진짜" 영역별 정리
