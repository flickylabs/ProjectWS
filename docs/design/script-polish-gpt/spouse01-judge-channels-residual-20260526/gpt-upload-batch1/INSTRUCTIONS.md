## 핵심 원칙 요약

### 원칙 1. 번역체 최대한 배제
- 직역 어순, 추상명사 양극 대비, "보입니다·느껴집니다" 직역체 회피
- 단순 어휘 치환 X — **문장 구조 자체 자연화** 필요
- 어색 패턴: "X가 Y를 가리킵니다" / "X로 모입니다" / "~으로 보여집니다"
- 정중 청유 어미 반복 ("들려주시겠습니까" / "말씀해 주시겠습니까") 다양화

### 원칙 2. 불필요한 의미 추가 절대 금지
- 원본에 없는 새 사실/단서/암시/평가/판단 추가 X
- 모호한 곳에 임의 명사구 추가 X

### 원칙 3. 게임 톤 = 법정 재판관 발화
- 격식체 + 자연 한국어 발화 균형
- depth 1→4 추궁 강도 보존 (depth=1 차분 청유 → depth=4 단정·즉시)
- NPC 호명 ("이준호 씨" / "박지연 씨" / "두 분") 유지

### 원칙 4. 진실 누설 절대 회피
- `policy-02-truth-disclosure.md` 의 hidden 키워드 목록 모두 회피
- spouse-01: 시댁 / 가족 / 집안 / 형 / 회생 / 형사 / 사기 / 횡령 / 범죄 / 위조 등 직접 등장 X
- 본 Batch 1은 자연화 위주 (직접 위반 entry 없음). 단 polish 결과에 hidden 단어 신규 도입 X
- 원본의 모호 referent ("다른 관련자" / "다른 사정" / "그쪽" 등) 보존

## 출력 시 주의사항

1. 각 ID는 원본 file의 ID 그대로 사용 (`judgeq-d-X-questionType-depth-vN`)
2. 변경 후 텍스트는 자연 한국어 한 문장 또는 두 문장 (원본 구조 따라)

4. 추측·해설 추가 X — polish 결과만 명확히 제시
5. 사용자 spot check 시 활용하므로 변경 영역은 검토 가능한 정밀도 필요
6. tone(depth) 차이 보존 — depth=4 variants는 단정 톤 유지
7. 진실 누설 자가 점검 필수 (policy-02 + 본 batch frame 영역 참조)
