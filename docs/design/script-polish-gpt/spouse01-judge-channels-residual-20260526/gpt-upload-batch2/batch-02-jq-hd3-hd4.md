### 그 외 진실 누설 자가 점검

- "해지 서류 조작" → "해지 서류에 대리 서명" / "해지 서류에 손댄" / "해지 서류 임의 처리"
- "서류 조작" → "서류 처리" / "서류 손댄 일" / "임의 작성"
- "본인이 한 일" 류 NPC 화자 발화처럼 들리는 표현 자연 변환

### 출력 시 주의사항

1. 각 ID는 원본 file의 ID 그대로 사용 (`judgeq-h-dX-questionType-depth-vN`)
2. 변경 후 텍스트는 자연 한국어 한 문장 또는 두 문장 (원본 구조 따라)
3. 변경 영역은 짧고 명료하게 (어떤 어색 패턴을 어떻게 자연화했는지)
4. 추측·해설 추가 X — polish 결과만 명확히 제시
5. tone(depth) 차이 보존 — depth=4 variants는 단정 톤 유지
6. **★ 진실 누설 자가 점검 필수** (policy-02 + 본 file 위반 영역 표) — "범죄" / "위조" / "조작" / "가족" / "집안" 등 hidden 키워드 단어 단위 등장 X
7. **★ Batch 2 진실 누설 위반 4 entries는 회피형으로 반드시 재작성**
