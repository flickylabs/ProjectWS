## 핵심 원칙 요약

### 원칙 1. 번역체 최대한 배제
- 직역 어순, 추상명사 양극 대비, "보입니다·느껴집니다" 직역체 회피
- 단순 어휘 치환 X — **문장 구조 자체 자연화** 필요
- 정중 청유 어미 반복 다양화

### 원칙 2. 불필요한 의미 추가 절대 금지
- 원본에 없는 새 사실/단서/암시/평가/판단 추가 X

### 원칙 3. 게임 톤 = 법정 재판관 발화
- 격식체 + 자연 한국어 발화 균형
- depth 1→4 추궁 강도 보존
- NPC 호명 ("이준호 씨" / "박지연 씨" / "두 분") 유지

### 원칙 4. ★ 진실 누설 절대 회피 (Batch 2 핵심)
- `policy-02-truth-disclosure.md` 의 hidden 키워드 목록 모두 회피
- "범죄" / "조작" / "위조" / "위법" 단어 단위 등장 절대 X
- 본 batch frame 영역의 **★ 진실 누설 위반 4 entries (judgeq-h-d3-fact_pursuit-4-v1, judgeq-h-d3-motive_search-4-v2, judgeq-h-d4-fact_pursuit-4-v3, judgeq-h-d4-motive_search-3-v4)** 회피형 재작성 필수
- 의미는 "법적 책임이 따르는 행동" / "서류 처리" / "대리 서명" / "선을 넘은 행동" 등 모호 referent로 전달

## 출력 시 주의사항

1. 각 ID는 원본 file의 ID 그대로 사용 (`judgeq-h-dX-questionType-depth-vN`)
2. 변경 후 텍스트는 자연 한국어 한 문장 또는 두 문장 (원본 구조 따라)
3. 변경 영역은 짧고 명료하게 (어떤 어색 패턴을 어떻게 자연화했는지)
4. 추측·해설 추가 X — polish 결과만 명확히 제시
5. tone(depth) 차이 보존 — depth=4 variants는 단정 톤 유지
6. **★ 진실 누설 자가 점검 필수** — polish 결과에 "범죄" / "조작" / "위조" / "위법" / "가족" / "집안" 등 hidden 단어 등장 X
7. **★ 4 위반 entries는 회피형으로 반드시 재작성** (frame 영역 표 참조)
