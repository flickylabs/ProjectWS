## 핵심 원칙 요약

### 원칙 1. 번역체 최대한 배제
- 직역 어순, 추상명사 양극 대비, "보입니다·느껴집니다" 직역체 회피
- 단순 어휘 치환 X — **문장 구조 자체 자연화** 필요
- 어색 패턴: "X가 Y를 가리킵니다" / "X로 모입니다" / "~으로 보여집니다"

### 원칙 2. 불필요한 의미 추가 절대 금지
- 원본에 없는 새 사실/단서/암시/평가/판단 추가 X
- 모호한 곳에 임의 명사구 추가 X

### 원칙 3. 게임 톤 = 법정 재판관 발화
- 격식체 + 자연 한국어 발화 균형
- "말씀해 주십시오" / "들려주시겠습니까" 정중 청유
- NPC 호명 ("이준호 씨" / "박지연 씨") 유지
- hard tone variant는 단정형 강조 keep

### 원칙 4. 진실 누설 절대 회피
- `policy-02-truth-disclosure.md` 의 hidden 키워드 목록 모두 회피
- spouse-01: 시댁 / 가족 / 집안 / 형 / 회생 / 형사 / 사기 / 횡령 등 직접 등장 X
- 본 Batch 1은 외도 evidence 조합 영역. 원본 위반 entry 없으나 hidden 정책 동일 적용
