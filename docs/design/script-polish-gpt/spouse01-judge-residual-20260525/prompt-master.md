## 사용자 polish 패턴 example (★ 학습 필수)

다음은 직전 14건 polish에서 사용자가 직접 작성한 polish 패턴. 이 톤을 정확히 따라야 함:

| Before (Claude 시안 — 번역체) | After (사용자 polish — 자연 한국어) |
|--------|-------|

| 그 사정이 두려워 계속 숨겨 오신 부분 | 갈등이 두려워 계속 숨겨 오신 사항 |
| 통화 상대와 문자 내용이 같은 사정으로 모입니다. 더는 단순한 연락이라고만 정리하실 수 없습니다 | 통화 상대와 발신자 미상 문자가 겹칩니다. 더이상 단순 연락으로 치부하실 수 없습니다 |
| 그 너머의 사정을 왜 끝까지 빼두셨습니까 | 그 너머의 사정을 왜 끝까지 숨기셨습니까 |
| 숨김의 이유가 단순한 연락 이상임을 가리킵니다 | 숨긴 이유가 단순 연락 이상이었음을 의심하게 합니다 |
| 그 사정을 두고 무엇을 숨기셨는지 | 그 상황에 대해 무엇을 숨기신 것인지 |
| 그곳에 갔다는 말씀이 변명이 아니려면 그곳의 사정을 왜 끝까지 숨기셨는지까지 | 그곳에 가신 것을 왜 끝까지 숨기셨는지도 |
| 무엇을 두려워하셨는지 | 무엇이 두려우셨던 것인지 |
| 별도 사용처로 큰돈을 옮기신 까닭을 ... 알리지 못하셨는지 | 별도 사용처로 큰돈을 옮기신 것을 ... 알리지 못하셨는지 |
| 다른 쪽 사정이 있고... 정황을 ... 알리지 못하셨는지 | 다른 사정이 있으셨다면, 그것을 왜 ... 알리지 못하셨는지 |
| 따로 급한 사정이 있어 보이지만 큰돈을 혼자 움직이신 문제도 남습니다 | 따로 급한 사정이 있으셨다 해도 큰돈을 따로 움직이신 것은 설명이 필요합니다 |
| 별도의 사정이 연결됩니다. 개인 돈이라는 말 뒤에 숨으실 수 없습니다 | 또다른 문제가 됩니다. 개인적인 사용이라는 말로 덮으실 수 없습니다 |
| 다른 쪽 사정 때문이었다면 돈의 성격을 더 명확히 말씀하셔야 합니다 | 다른 사정이 있으신 것이라면 더욱 그 돈의 성격을 명확히 말씀하셔야 합니다 |

### 학습 패턴 정리
1. **단순 의문문 선호** — "그게 무엇인지" / "그것을" 직접 의문 자연
2. **구체 키워드 활용** — "갈등" / "숨기셨습니까" / "치부하실" / "의심하게 합니다" 명료한 한자어/동사
3. **조건절 자연** — "다른 사정이 있으셨다면" / "있으신 것이라면"
4. **부정 회피보다 단정 강조** — "치부하실 수 없습니다" / "덮으실 수 없습니다"
5. **추상 referent 제거** — "그 사정을 두고" → "그 상황에 대해"
6. **자기지시 회피** — "무엇을 두려워하셨는지" → "무엇이 두려우셨던 것인지"
7. **시적/생경 표현 회피** — "그 사정이 두려워" → "갈등이 두려워" 구체 명사
