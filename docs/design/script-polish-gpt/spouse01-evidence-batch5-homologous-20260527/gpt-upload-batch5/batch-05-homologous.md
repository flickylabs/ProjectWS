### 출력 시 주의사항

1. Group N 번호 + archetype key 명기
2. 변경 후 텍스트는 자연 한국어 한 문장 또는 두 문장
3. 변경 영역은 짧고 명료하게
4. **archetype 자연화 — 5 evidence 동시 적용 영역** — evidence-specific 동사/명사 X
5. NPC 발화 톤 (재판관 청유 X) 보존
6. lieBand 단계 톤 보존 (mid 자기 반성 / late 단정 책임 인정·부분 인정)
7. **어색 패턴 강제 제거** + **어미 다양화**
8. **자기지시 정책**: NPC 1인칭 자기 발화에서 "본인 / 자신" 사용 X — "저 / 제" 자연
9. **진실 누설 자가 점검** — hidden keyword (가족/집안/시댁/형/회생/형사/사기/횡령/범죄/위조/위법) 절대 도입 X. "외도" 단정 표현은 박지연 의심 frame 보존 OK
