## 본 batch 배경

직전 Batch 2 (e-4~e-7) GPT 시안에서 다음 영역이 자연화 부족:
- **명시 어색 패턴 미제거**: "그렇게" / "차분히" / "그 흐름" / "느껴집니다" / "그 판단" 보존 (tone 핑계로 유지)
- **evidence-specific 동사 단일 처리**: b-e-{4,5}-mid-stage1-v5/v7 에서 "그렇게 움직였습니다" 등 그렇게 + 일반 동사로 끝남

본 batch는 12 entries 재의뢰. **명시 패턴 강제 제거** + evidence-specific 동사 선정 필수.

## Evidence Frame

### e-4: 발신자 미상 문자
B 이준호가 받은 문자. 진실: 형으로부터 문자 (진실은 진실 노출 전까지 회피).

### e-5: 개인 계좌 현금 출금
B 이준호의 개인 계좌 출금. 진실: 형의 회생 자금 (진실은 진실 노출 전까지 회피).

### e-6: 투자방 텔레그램
A 박지연이 가입한 투자방. 박지연이 직접 송금했다가 손실.

### e-7: 송금 기록
A 박지연 → 투자방 송금 (공동 적금 해지 후 진행). 박지연의 위임장 영역 evidence.

원형: "제가 한 일은 맞습니다. 사정이 있어서 그렇게 [동사]. 그래서 설명이 늦었습니다."

| evidence | Batch 1 적용 결과 | 동사 선정 근거 |
|----------|-------------------|----------------|
| e-1 (학원생 참고서) | "사정이 있어서 제가 **나섰습니다**" | "나서다" = 처리에 직접 관여 |
| e-2 (GPS 차량 좌표) | "사정이 있어서 제가 **움직였습니다**" | "움직이다" = 이동 |
| e-3 (통화기록) | "사정이 있어서 제가 **연락했습니다**" | "연락하다" = 전화/문자 |

| **e-5 (현금 출금)** | **본 batch 선정 필요** | 출금 = 처리/움직였다/빼다 류 |

### 출력 시 주의사항

1. 각 ID는 표의 ID 그대로 사용
2. **명시 어색 패턴 강제 제거** — "tone 보존" 명목으로 보존 X
3. evidence-specific 동사 (영역 A)는 e-4/e-5 evidence 맥락 정확히 반영
4. NPC 발화 톤 (재판관 청유 X) 보존
5. lieBand 단계 톤 보존 (early 방어 / mid 인정+변명 / late 진실 인정)
6. **진실 누설 자가 점검** — hidden 키워드 (가족/집안/시댁/형/회생/형사/사기/횡령/범죄/위조/위법) 신규 도입 X
