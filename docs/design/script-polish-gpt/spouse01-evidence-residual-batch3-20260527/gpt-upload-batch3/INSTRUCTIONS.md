## 핵심 원칙 요약

### ★ 본 batch 강조 원칙

1. **어색 패턴 강제 자연화** — 표에 명시된 패턴은 반드시 제거/대체. "tone 보존" 명목으로 유지 금지.
   - "그렇게" → 제거 또는 명확한 부사구 대체 ("사실대로" / "실제로" / "그런 식으로" 등)
   - "그 흐름" → 의미 동사구 ("이어진 정황" / "쌓인 흐름" / "오간 문자" 등)
   - "느껴집니다" (피동) → 능동 발화 ("저는 ... 무겁게 받아들이고 있습니다" / "느낍니다" 능동)
   - "그 판단" → 의미 발화 ("그 생각" / "제 결론" / "제 짐작" 등 + 명확한 술어)

2. **evidence-specific 동사 (b-e-4/5-mid-stage1-v5/v7)**:
   - e-1/e-2/e-3 동형 entries 적용 사례 (참고):
     - e-1 (학원생 참고서) "사정이 있어서 제가 나섰습니다" / "그때는 제가 처리해야 한다고 봤습니다"
     - e-2 (GPS 차량 좌표) "사정이 있어서 제가 움직였습니다" / "그때는 제가 움직여야 한다고 봤습니다"
     - e-3 (통화기록) "사정이 있어서 제가 연락했습니다" / "그때는 제가 연락해야 한다고 봤습니다"
   - 본 batch 적용 (evidence 맥락 맞춤 동사 선정):
     - e-4 (발신자 미상 문자) — 답신/회신/응대/받았다 류
     - e-5 (개인 계좌 현금 출금) — 출금/처리/움직였다/뺐다 류

3. **NPC 자기 발화 보존** — 재판관 청유 X. "...했습니다 / ...입니다" NPC 발화 어미.

4. **lieBand 톤 보존**:
   - early: 회피·부정·방어
   - mid: 부분 인정·변명
   - late: 진실 인정 (★ hidden 키워드 보존 OK)

5. **진실 누설 정책**:
   - hidden 키워드 신규 도입 X (가족/집안/시댁/형/회생/형사/사기/횡령/범죄/위조/위법)
   - band=late 원본 등장 hidden 키워드는 보존
