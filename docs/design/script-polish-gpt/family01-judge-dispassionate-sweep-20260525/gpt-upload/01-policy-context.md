# 01 — 정책 컨텍스트 (재판관 어법 dispassionate)

## 권위

신규 메모리 `feedback_judge_dispassionate_action_focused` (2026-05-24 Cycle 7 도입). memory/ 폴더에 self-contained 사본.

## 규칙

재판관(judge) 발화 영역에서:

1. **감정·가치 판단 어휘 회피** — 재판관은 사실 확인자이지 판단자가 아님 (사실 확정 전 단계)
2. **사실/행위/선후관계 중심 어휘 사용** — 누가/언제/어떤 행위
3. **"관련"으로 중립 유지** — "반증/그 X" → "관련 X" / "해당 X"

## 위반 vs 권장 어휘 사전

| 영역 | ✗ 위반 (감정·가치 판단) | ✓ 권장 (사실·행위) |
|---|---|---|
| 행위 평가 | "선을 넘은 행동" | "절차에 손댄 행동" / "절차에 직접 손댄 행동" |
| 인과 표현 | "흐름입니다" / "흐름이 보입니다" | "정황입니다" / "선후관계가 있습니다" / "흔적이 있습니다" |
| 자료 요청 | "반증 자료" (대립 frame) | "관련 자료" (중립) |
| 지시 대명사 | "그 문서" / "그 자료" | "관련 문서" / "해당 자료" / "이 문서" |
| 단정 cascade | "낙인의 시작점이 정리됐으니" | "앞서 [X]가 등재됐습니다. 관련 사실관계 확인이 필요합니다" |

## "선을 넘다" 전용 변환 가이드 (family-01 영역)

family-01 사건 영역에서 "선을 넘다"는 주로 윤정후의 어머니 유서 작성 개입 / 절차 손댄 행위를 가리킴. 변환 후보:

| 위반 context | 권장 frame |
|---|---|
| "선을 넘었다면" (유서 개입) | "절차에 직접 손을 댔다면" / "어머니 의사 형성에 직접 손댔다면" |
| "선을 넘었습니까" (절차 손댄 행위) | "절차에 직접 손을 댔습니까" / "절차에 손댄 이유가 무엇입니까" |
| "법적 선을 넘은 판단" | "법적 절차를 넘은 판단" / "법적 절차에 직접 손댄 판단" |
| "어디서 선을 넘었습니까" | "어디서 절차에 직접 손을 댔습니까" / "어디서 어머니 의사 영역을 넘었습니까" |
| "선을 넘은 이유를" | "절차에 직접 손댄 이유를" / "이 절차를 넘은 이유를" |

## "흐름" 전용 변환 가이드 (family-01 영역)

family-01 영역의 "흐름"은 정후→어머니→윤태성 공장 자금 routing을 가리키는 경우가 많음. 변환 후보:

| 위반 context | 권장 frame |
|---|---|
| "계좌 흐름이 보입니다" | "계좌 정황이 있습니다" / "계좌상 송금 선후관계가 있습니다" / "계좌상 자금 이동 흔적이 있습니다" |
| "계좌 흐름은 작은 도움을 넘어선 흐름입니다" | "계좌 정황은 작은 도움 수준을 넘는 흔적입니다" / "계좌상 자금 이동은 작은 도움 수준을 넘습니다" |
| "정기 지원금과 사업 자금 흐름이 보입니다" | "정기 지원금과 사업 자금 송금 선후관계가 있습니다" / "정기 지원금과 사업 자금 이동 흔적이 있습니다" |

⚠ "흐름"이라는 단어는 일상 한국어이므로 본문 명사 ("계좌 흐름"이 "계좌 이동" 등 사실 명사로 바뀔 때 어색하지 않으면 OK). 단 동사 "흐름이 보입니다" 같은 추측·평가 어휘는 회피.
