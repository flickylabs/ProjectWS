# 04 — 변환 가이드 (judge dispassionate 어법)

## 핵심 원칙

1. **사실/행위 frame 우선** — 평가·감정·가치 어휘 회피
2. **자연성 우선** — 단순 어휘 치환 X. 문장 흐름 보고 통째 재구성 가능
3. **격식 보존** — `...십시오` / `...습니까` (재판관 격식 유지)
4. **dispute 명사 활용** — "유서" / "수정된 유서" / "변경된 유서" / "공증인 메모" / "계좌 송금" 등 사건 명사 직접 호명 OK

## 영역별 변환 패턴

### 1. "그 X" (지시 대명사) → 중립 대체

| 위반 | 권장 |
|---|---|
| "그 문서를 고치던 순간" | "관련 문서를" / "수정 접수된 문서를" / "이 문서를" / "유서 수정본을" |
| "그 문서가 각자에게" | "관련 문서가" / "수정된 유서가" / "이 문서가" |
| "그 문서를 보는 순간" | "관련 문서를" / "수정된 유서를" / "변경된 유서를" |
| "그 문서가 어머니 뜻을" | "수정된 유서가" / "이 문서가" / "관련 문서가" |

⚠ family-01 영역의 "그 문서"는 대부분 "수정된 유서" / "변경된 유서" 의미. 구체화 가능.

### 2. "선을 넘다" (행위 평가) → 사실 frame

| 위반 context | 권장 변환 |
|---|---|
| "선을 넘었다면 왜 그랬습니까" | "절차에 직접 손을 댔다면 왜 그랬습니까" / "어머니 의사 형성에 직접 손댔다면 왜 그랬습니까" |
| "선을 넘었습니까" (절차 개입) | "절차에 직접 손을 댔습니까" / "어디까지 절차에 손댔습니까" |
| "법적 선을 넘은 판단" | "법적 절차를 넘은 판단" / "법적 절차에 직접 손댄 판단" |
| "어디서 선을 넘었습니까" | "어디서 절차에 직접 손을 댔습니까" / "어디서 어머니 의사 영역을 넘었습니까" |
| "그 선을 넘은 이유" | "절차에 직접 손댄 이유" / "법적 절차를 넘은 이유" |

⚠ 변환 시 "절차" 명사 활용 자연. "어머니 의사" / "법적 절차" 등 dispute frame 맞춤.

### 3. "흐름" (인과 평가) → 사실 frame

| 위반 context | 권장 변환 |
|---|---|
| "계좌 흐름이 보입니다" | "계좌 정황이 있습니다" / "계좌상 송금 선후관계가 있습니다" / "계좌상 자금 이동 흔적이 있습니다" |
| "정기 지원금과 사업 자금 흐름이 보입니다" | "정기 지원금과 사업 자금 송금 선후관계가 있습니다" / "정기 지원금과 사업 자금 이동 흔적이 있습니다" |
| "계좌 흐름은 작은 도움을 넘어선 흐름입니다" | "계좌 정황은 작은 도움 수준을 넘는 흔적입니다" / "계좌상 자금 이동은 작은 도움 수준을 넘습니다" |
| "계좌 흐름이 보여 주는 사실" | "계좌상 정황이 보여 주는 사실" / "계좌상 송금 기록이 보여 주는 사실" |

⚠ "흐름"은 일상 한국어. "계좌 흐름" 같은 본문 명사 사용은 OK. 단 "흐름이 보입니다" 같은 추측·평가 어휘는 회피.

### 4. tone 강도 보존

- **soft**: 부드럽게 들춰내는 단계. "들려주십시오" / "말씀해 주시겠습니까" / "함께 봐야 합니다"
- **mid**: 직접 묻는 단계. "말씀하십시오" / "설명해 주십시오"
- **hard**: 단호한 추궁. "...덮을 수 없습니다. ...십시오"

변환 후 tone 일관성 유지.

### 5. 격식 어미 일관성

| 어미 | 사용 영역 |
|---|---|
| `...십시오` | 명령형 격식 (재판관 → NPC) |
| `...습니까` | 의문형 격식 |
| `...겠습니까` | 부드러운 청유형 |
| `...십시오. ...십시오.` | 단호한 반복 (hard tone) |

⚠ "...해주세요" / "...해주세요." 같은 부드러운 끝맺음 회피 (격식 부족).

## 변환 X 영역

다음 영역은 본 의뢰서에서 변경 X:

1. NPC 발화 (contradiction_pursuit / interjection / dossier 의 NPC 자기 발화 등) — P1 후속
2. `noteText` / `successConditionSummary` (analysis 영역)
3. dispute truth advance 직후 (S3+) 재판관 정리 발화 (사실 확정 단계)
4. 다국어 영역 (EN/JA/ZH-CN) — 본 의뢰서 적용 후 별도 Codex 의뢰

## truth-leak 회피

변환 시 hidden lexeme 등장 X (진실 누설 정책 [[feedback_truth_leak_prohibition]] 권위):
