### 출력 시 주의사항

1. ID 표 그대로 사용
2. 변경 후 텍스트는 자연 한국어 한 문장 또는 두 문장
3. 변경 영역은 짧고 명료
4. **재판관 청유 톤 보존** (NPC 자기 발화 X)
5. NPC 호명 ("이준호 씨", "박지연 씨") 보존
6. **"본인" 보존 OK** — 재판관 발화에서 정책 부합
7. 직역 어미 ("가리킵니다" / "드러납니다") 자연화
8. 강조 부사 ("끝까지" / "차분히") — 자연 영역 보존, 직역체에서만 자연화
9. 어미 단조 회피 ("말씀해 주십시오 → 다양화")
10. evidence 명칭 보존 (외도 의심 / 발신자 미상 문자 / 출금 내역 / 투자방 텔레그램 / 공동 적금 해지 서류 / 현금 출금)
11. 진실 누설: hidden keyword 신규 도입 X
