## 핵심 원칙 요약

### ★ 본 batch 특이성

1. **재판관 발화** = 제3자가 NPC 가리킴. 본 batch entries 모두 재판관 청유 어미 ("말씀해 주십시오 / 답하십시오 / 들려주시겠습니까")

2. **자기지시 정책**:
   - **"본인" 사용 OK** — 재판관이 NPC를 가리킬 때 자연 (정책 부합)
   - "자신" 등장 시 통일 권장 → 본 batch는 "본인" 사용 entries만 추출됐으므로 통일 대상 아님
   - "본인" 회피 X — 적절한 위치에서 유지

3. **어색 패턴 자연화 영역** (★ 본 batch 처리 대상):
   - **직역 어미**:
     - "가리킵니다" → "맞물려 있습니다 / 보여 줍니다 / 같은 줄거리에 있습니다 / 가리키고 있습니다 (자연 어순)"
     - "드러납니다" → "확인됩니다 / 보입니다 / 나타납니다 (자연) / 드러나 있습니다"
   - **강조 부사**:
     - "끝까지" — 재판관 추궁 자연 영역 (왜 끝까지 숨기셨습니까 = 자연). 직역체에서만 자연화
     - "차분히" — 재판관 청유 자연 영역 (차분히 말씀해 주십시오 = 자연). 직역체에서만 자연화
     - "그렇게" — 명확 referent로 자연화

4. **재판관 청유 어미 다양화** (★ 어미 단조 회피):
   - "말씀해 주십시오 / 들려주십시오 / 답하십시오 / 밝히십시오 / 짚어 주시겠습니까" 다양화
   - 단, 명확한 추궁 톤 보존

5. **NPC 호명 보존**:
   - "이준호 씨" / "박지연 씨" / "두 분"

6. **진실 누설 정책**:
   - 본 batch entries는 재판관 발화 = 사건 진행 frame 영역
   - 원본에 등장하는 표현 ("외도 의심" / "발신자 미상 문자" / "출금 내역" / "투자방 텔레그램" / "공동 적금 해지 서류" / "현금 출금") 보존 OK — 사건 evidence 명칭
   - hidden keyword (가족/집안/시댁/형/회생/형사/사기/횡령/범죄/위조/위법) 신규 도입 X
