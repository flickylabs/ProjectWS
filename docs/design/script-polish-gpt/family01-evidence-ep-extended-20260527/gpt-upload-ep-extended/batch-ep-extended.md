### 출력 시 주의사항

1. ID 표 그대로 사용
2. 변경 후 텍스트는 자연 한국어 (한 문장 또는 두 문장, 원문 길이/리듬 보존)
3. 변경 영역은 짧고 명료
4. NPC lieBand/stage 톤 보존
5. **자기지시 정책**: NPC 자기 발화에 "본인 / 자신" 사용 X → "저 / 제"
6. **직역 어미 자연화**: "가리킵니다 / 드러납니다 / 이어집니다 / 연결됩니다"
7. **추상명사 구체화**: "그 부분 / 그 점 / 그 상황 / 그 결론" → 구체 referent
8. **강조 부사 정밀**: "그렇게 / 완전히 / 차분히" 격앙/단정/직역체 영역 정리
9. **진실 누설 자가 점검**: family-01 hidden keyword 신규 도입 X
