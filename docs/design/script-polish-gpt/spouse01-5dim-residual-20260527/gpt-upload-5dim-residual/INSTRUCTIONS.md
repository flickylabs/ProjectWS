## 5 차원 정책 ([[feedback_natural_korean_npc_active_voice]])

### 차원 1. 강력 어휘 완화 (★ lieState 단계 분리)

NPC 본인이 자기 행동을 묘사할 때 범죄 단어 ("혐의 / 사기 / 횡령 / 범죄")는 너무 강력.

- **S5 자백 영역 (보존)**: "위조가 범죄인 걸 알면서도", "범죄로 이어졌습니다", "범죄인 건 압니다" 등 NPC 자기 인정 — **이미 본 batch에서 제외됨**.
- **S0~S4 회피/변명 영역 (정리)**: 일반 단어로 완화
  - "외도나 횡령을 단정하진" → "외도나 다른 문제로 단정짓지" (혐의 → 문제)
  - "사기였습니다" → "속았습니다" (피해자 입장)
  - "사기 의심이 가는 대화" → "수상한 대화" (혐의 단어 회피)

### 차원 2. 모호 referent → 명확 동사구

GPT가 자주 사용하는 모호 referent를 명확한 동사구/명사구로:

- "다른 쪽 일에 손을 보태야 했습니다" → "제 도움이 필요한 일이 있었습니다"
- "다른 사정이라" → "사정이 있어"
- "제 일과 관련된" → "저와 관련된"
- "다른 일" → 구체 referent

### 차원 3. 피동 직역체 → 적극 발화

- "드러납니다" → "얽혀있어 말씀드리기 어렵습니다"
- "관련 있습니다" → "있었습니다"

### 차원 4. 직역체 구문 → 한국어 내면 발화

- "그 행동에는 ... 뜻이 있었습니다" → "제 도움이 필요했던 상황이라 ..."
- "목적은 ... 것이었습니다" → "저는 그저 ~ 싶었던 것 뿐입니다"

### 차원 5. 자연 완충재 활용

NPC가 진실 누설 회피하면서도 명확하게 변명하려면 자연 완충재 활용:

- "말씀드리기 어렵지만" (회피 + 명확)
- "사정이 있어" (회피 + 자연)
- "어쩔 수 없었습니다" (변명 + 자기 인정)
- "분명 잘못입니다" (강조 + 자기 평가)
- "변명의 여지가 없습니다" (강력 인정)
