# 정책 02 — spouse-01 진실 누설 회피 정책

## 사건 개요

**사건**: spouse-01 (이준호·박지연 부부 사건)

겉으로는 외도 의심·자금 갈등 영역으로 시작. 진실은:
- 이준호 (B)의 **형이 자금 문제** → 형 개인회생·형사 영역 자금 흐름
- 박지연 (A)이 **위임장 영역**에 개입 + 투자방 직접 송금하여 손실
- 양측 모두 가족·금전·법적 영역의 숨김 행위 존재

진실 노출은 게임 후반부 lieState breakthrough 이후. **본 polish 단계는 진실 노출 전**이므로 hidden 키워드 직접 명명 모두 금지.

다음 표현으로 hidden 키워드 회피 가능:

- "다른 사정"
- "별도 사용처"

- "다른 곳"
- "다른 쪽 일"

본 batch 단계에서는 evidence 조합으로 "숨긴 자금 흐름이 있다" 정도까지 시사 가능. 그 사용처가 무엇인지 (가족/형/회생/법적 영역) 직접 명명 X.
