## 핵심 원칙 요약

### 원칙 1. 번역체 최대한 배제

- 직역 어순 / 추상명사 양극 대비 / 피동 직역체 회피
- 사용자 polish 패턴 7 차원 (policy-01) 적용

### 원칙 2. 의미 보존 (★ NPC 발화 특성 반영)

- evidence_present는 **NPC가 evidence 받았을 때 발화 영역**
- "이준호"가 evidence 추궁 받고 변명·인정·회피하는 영역
- 원본 의미 (변명 의도 / 인정 / 회피 등) 그대로 보존
- 단 hidden 키워드 (가족/집안/횡령)는 모호 referent로 치환

### 원칙 3. NPC 발화 톤 = 일상 격식 (재판관 격식과 다름)

- "~합니다 / ~네요 / ~겠습니다" 일상 격식체
- 변명 / 인정 / 회피 / 미루기 / 묵비 등 감정 톤 다양
- 재판관 격식 ("말씀해 주십시오") X — NPC는 본인 발화

### 원칙 4. ★ 진실 누설 절대 회피

#### Hidden 키워드 (모두 등장 금지)
- 시댁 / 시집 / 시아버지 / 시어머니
- **가족 / 집안 / 친정 / 처가** ← 본 Batch 핵심
- 형 / 동생
- 개인회생 / 회생 / 파산
- 형사절차 / 형사사건 / 형사고소
- **사기 / 횡령** ← Batch 1 횡령 2건 영역

#### 허용 모호 referent
- "다른 사정" / "별도 사용처" / "또다른 문제"
- "숨긴 흐름" / "다른 곳" / "다른 쪽 일"
- "특정 사용처" / "개인적인 일"
- "급한 일" / "혼자 처리해야 할 일"

#### 변환 패턴 (참고)
- "가족 쪽 일" / "가족 쪽 사정" → "다른 사정" / "다른 일"
- "집안 사정" / "집안 일" → "다른 사정" / "별도 사용처"
- "집안 문제" → "다른 문제" / "혼자 떠안은 문제"
- "집안 부탁" → "다른 부탁" / "급한 부탁"
- "가족 문제" → "다른 문제" / "급한 일"
- "가족" (명사 단독) → "관련된 사람" / "그 사람"
- "외도나 횡령을 단정하진" → "외도나 다른 혐의를 단정하진" 또는 "외도로 단정하진"
