# 정책 01 — 한국어 자연화 원칙 + 사용자 polish 패턴

## 필수 원칙 (★ 절대 준수)

### 원칙 1. 번역체 최대한 배제

다음 번역체 흔적 모두 회피:

- **직역 어순** — 영어 SVO 어순 직역 ("X를 가리킵니다" / "X로 모입니다" 식 어색 격식)
- **추상명사 양극 대비** — "사정/상황/문제/판단/흐름" 등 추상명사 X와 Y 양극 대비 구조 ("X와 Y가...")
- **"보입니다" / "느껴집니다" 직역체** — 원본 의도가 추측이 아닌데 완곡 추측으로 옮기지 X
- **단순 어휘 치환** — "부인→부정" 차원 polish 아닌 **문장 구조 자체 자연화**
- **인공적 시적 표현** — "그 사정을 두고" / "그 너머의 사정" 같은 시적·생경 표현
- **수식어구 군더더기** — "지금/이제/모두/끝까지/차분히" 등 강조 부사 남발
- **피동 어색** — "보여집니다" 등 직역체 피동
- **정중 청유 반복** — "차분히 들려주시겠습니까" 같은 정중 청유 어미 반복

### 원칙 2. 불필요한 의미 추가 절대 금지

원본 KO 의미만 보존 + 자연화. 다음 행위 금지:

- 원본에 없는 새 사실/단서/암시 추가
- 원본에 없는 새 평가/판단/태도 추가
- 화자 추측·태도 강조 부사 (솔직히/분명히/확실히) 추가
- 의도가 명확한 곳에 모호 표현 도입

### 원칙 3. 게임 톤 = 법정 재판관 발화

- 격식체 + 자연 한국어 발화 균형
- 직접 추궁 + 정중 청유 균형 ("말씀해 주십시오" / "들려주시겠습니까")
- 한자어 사안 명사 활용 OK (조작/배제/확신/실행/판단)
- NPC 호명 ("이준호 씨" / "박지연 씨") 유지
- 명령형 "답하십시오" 보다 청유 "답해 주십시오" 권장 (단 hard tone hard는 단정 keep)

다음은 직전 spouse-01 judge_evidence_combo 14건 polish에서 사용자가 직접 작성한 polish 패턴입니다. **이 톤을 정확히 따라야 합니다**:

### Before → After 대조표

| 그 사정이 두려워 계속 숨겨 오신 부분 | 갈등이 두려워 계속 숨겨 오신 사항 |
| 통화 상대와 문자 내용이 같은 사정으로 모입니다. 더는 단순한 연락이라고만 정리하실 수 없습니다 | 통화 상대와 발신자 미상 문자가 겹칩니다. 더이상 단순 연락으로 치부하실 수 없습니다 |
| 그 너머의 사정을 왜 끝까지 빼두셨습니까 | 그 너머의 사정을 왜 끝까지 숨기셨습니까 |
| 숨김의 이유가 단순한 연락 이상임을 가리킵니다 | 숨긴 이유가 단순 연락 이상이었음을 의심하게 합니다 |
| 그 사정을 두고 무엇을 숨기셨는지 | 그 상황에 대해 무엇을 숨기신 것인지 |
| 그곳에 갔다는 말씀이 변명이 아니려면 그곳의 사정을 왜 끝까지 숨기셨는지까지 | 그곳에 가신 것을 왜 끝까지 숨기셨는지도 |
| 무엇을 두려워하셨는지 | 무엇이 두려우셨던 것인지 |
| 별도 사용처로 큰돈을 옮기신 까닭을 ... 알리지 못하셨는지 | 별도 사용처로 큰돈을 옮기신 것을 ... 알리지 못하셨는지 |
| 다른 쪽 사정이 있고... 정황을 ... 알리지 못하셨는지 | 다른 사정이 있으셨다면, 그것을 왜 ... 알리지 못하셨는지 |
| 따로 급한 사정이 있어 보이지만 큰돈을 혼자 움직이신 문제도 남습니다 | 따로 급한 사정이 있으셨다 해도 큰돈을 따로 움직이신 것은 설명이 필요합니다 |
| 별도의 사정이 연결됩니다. 개인 돈이라는 말 뒤에 숨으실 수 없습니다 | 또다른 문제가 됩니다. 개인적인 사용이라는 말로 덮으실 수 없습니다 |
| 다른 쪽 사정 때문이었다면 돈의 성격을 더 명확히 말씀하셔야 합니다 | 다른 사정이 있으신 것이라면 더욱 그 돈의 성격을 명확히 말씀하셔야 합니다 |

## 학습 패턴 정리 (★ 핵심 7 차원)

### 1. 단순 의문문 선호
"그게 무엇인지" / "그것을" 같은 직접 의문이 자연.
~ "그 부담이 어느 정도였는지" 같은 추상 의문은 어색

### 2. 구체 키워드 활용
"갈등" / "숨기셨습니까" / "치부하실" / "의심하게 합니다" 등 명료한 한자어/동사 활용.
~ "그 사정" 같은 추상 referent는 회피

### 3. 조건절 자연 톤
"다른 사정이 있으셨다면" / "있으신 것이라면" 같은 조건절 톤.
~ "다른 쪽 사정이 있고..." 같은 어색 연결은 회피

### 4. 부정 회피보다 단정 강조
"치부하실 수 없습니다" / "덮으실 수 없습니다" 같은 강한 단정.
~ "정리하실 수 없습니다" 같은 약한 부정은 회피

### 5. 추상 referent 제거
"그 사정을 두고" → "그 상황에 대해" / "그 너머의 사정" → "큰돈을 따로 움직이신 것" 등 구체화.
~ 모호한 "그 / 그것" 지시어는 명사구로 보강

### 6. 자기지시 회피 + 주체 전환
"무엇을 두려워하셨는지" → "무엇이 두려우셨던 것인지" 처럼 행위자에서 사물 주어로 전환.
~ 주체 명시 어색 회피

### 7. 시적/생경 표현 회피
"그 사정이 두려워" → "갈등이 두려워" 구체 명사로 변환.
~ 추상 시적 표현 회피

## Polish 시 자가 점검 list

각 entry polish 후 다음 점검:

- [ ] 원본 의미 100% 보존 (새 사실/평가/태도 추가 X)
- [ ] 번역체 어색 패턴 (위 원칙 1) 제거됨
- [ ] 사용자 polish 패턴 7 차원 따름
- [ ] 게임 톤 (법정 재판관 격식체) 유지
- [ ] NPC 호명 ("이준호 씨" / "박지연 씨") 유지
- [ ] tone (soft / mid / hard) 차이 보존 (hard는 단정 강조)
- [ ] 진실 누설 회피 (`policy-02-truth-disclosure.md` 참조)
