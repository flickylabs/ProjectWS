- 원본 의미 그대로 보존, hidden 키워드만 모호 referent로 치환

### 원칙 3. NPC 발화 톤 = 일상 격식 (재판관 격식 X)
- "~합니다 / ~네요 / ~겠습니다" 일상 격식체
- 변명 / 인정 / 회피 / 미루기 / 묵비 등 감정 톤 다양

### 원칙 4. ★ 진실 누설 절대 회피

#### Hidden 키워드 (모두 등장 금지)
- **시댁 / 시집 / 시아버지 / 시어머니** ← Batch 2 e-4 early|3 1건 영역
- **가족 / 집안 / 친정 / 처가** ← 본 Batch 다수
- 형 / 동생
- 개인회생 / 회생 / 파산
- 형사절차 / 형사사건 / 형사고소
- **사기 / 횡령** ← Batch 2 횡령 1건 영역

#### 허용 모호 referent
- "다른 사정" / "별도 사용처" / "또다른 문제"
- "숨긴 흐름" / "다른 곳" / "다른 쪽 일"
- "특정 사용처" / "개인적인 일"
- "급한 일" / "혼자 처리해야 할 일"

#### 변환 패턴 (참고)
- "가족 쪽 일" / "가족 쪽 사정" → "다른 사정" / "다른 일"
- "집안 사정" / "집안 일" → "다른 사정" / "별도 사용처"
- "집안 문제" → "다른 문제" / "혼자 떠안은 문제"
- "집안 부탁" → "다른 부탁" / "급한 부탁"
- "시댁 문제" → "다른 문제" / "또 다른 사정"
- "가족한테 온 전화" → "급한 일로 온 전화" / "다른 사람 전화"
- "외도나 횡령을 단정하진" → "외도나 다른 혐의를 단정하진"
