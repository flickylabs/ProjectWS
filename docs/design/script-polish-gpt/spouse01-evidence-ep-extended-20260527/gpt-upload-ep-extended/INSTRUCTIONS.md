## 핵심 원칙

1. **NPC 자기 발화 톤 보존** — lieBand (early/mid/late) × stage (1~5) 정합
2. **NPC 호명 보존**: 박지연 씨, 김도윤 씨
3. **자기지시 정책** ([[feedback_self_reference_speaker_context]]):
   - NPC 1인칭 자기 발화에서 "본인 / 자신"은 어색 → "저 / 제"로 자연화
   - 다만 제3자가 NPC 가리키는 영역은 "본인" 자연 영역
4. **직역 어미 자연화**:
   - "가리킵니다" → "맞물려/이어져 있습니다"
   - "드러납니다" → "확인됩니다 / 보이게 됩니다 / 알려질 수밖에 없습니다"
   - "이어집니다" → "연결됩니다 / 닿아 있습니다"
   - "확인됩니다" → 직역체 아님 (OK, 다만 반복은 다양화)
5. **강조 부사 정밀**:
   - "그렇게" 격앙 영역 외 정리 (NPC 차분 톤 영역)
   - "완전히" 단정 강조 영역 → "전부 / 통째로 / 다" 다양화
   - "차분히" 직역체 영역 (NPC가 자기 발화에 쓰면 어색 — 정리)
6. **추상명사 구체화**:
   - "그 부분" → 구체 referent (그 항목 / 그 결정 / 그 조항 / 거기)
   - "그 점" → 구체 referent (그 사실 / 그 부분 / 그 대목)
   - "그 상황" → 구체 referent (당시 / 그 자리 / 그 시점)
   - "그 결론" → 구체 referent (그 판단 / 그 답)
7. **NPC 적극 발화 5 차원** (policy-01): 강력 어휘 완화 + 모호 referent → 명확 동사구 + 피동 회피 + 직역체 → 내면 발화 + 자연 완충재
8. **진실 누설 자가 점검** (policy-02): spouse-01 진실 누설 정책: 가족/개인회생/형사 절차 자백 전 등장 X. 가족 = 오직 형 사업 영역.
