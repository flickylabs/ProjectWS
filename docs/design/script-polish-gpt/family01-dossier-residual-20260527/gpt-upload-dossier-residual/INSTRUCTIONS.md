4. **직역 어미 자연화**:
   - "가리킵니다" → "맞물려/이어져 있습니다"
   - "드러납니다" → "확인됩니다 / 보이게 됩니다"
   - "이어집니다" → "연결됩니다 / 닿아 있습니다"
5. **강조 부사 정밀**:

   - "완전히" — 단정 강조 영역 다양화 (전부 / 통째로 / 다)
   - "진짜" — 강조 부사 영역 정리 (그때 / 실제로)
6. **추상명사 구체화**:
   - "그 부분" → 구체 referent (그 항목 / 그 결정 / 거기 / 그 대목)
