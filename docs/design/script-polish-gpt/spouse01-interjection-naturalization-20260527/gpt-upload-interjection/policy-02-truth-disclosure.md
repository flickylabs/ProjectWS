# 정책 02 — spouse-01 진실 누설 회피 정책

## 사건 개요

**사건**: spouse-01 (이준호·박지연 부부 사건)

겉으로는 외도 의심·자금 갈등 영역으로 시작. 진실은:
- 이준호 (B)의 **형이 자금 문제** → 형 개인회생·형사 영역 자금 흐름
- 박지연 (A)이 **위임장 영역**에 개입 + 투자방 직접 송금하여 손실
- 양측 모두 가족·금전·법적 영역의 숨김 행위 존재

본 polish 단계는 **재판관 발화 자연화** 작업. 재판관은 진실 노출 전 단계에서 hidden 키워드 직접 명명 금지.

---

## ★ Hidden 키워드 (재판관 발화에서 직접 등장 절대 금지)

### 가족·관계 영역

- "시댁" / "시집" / "시아버지" / "시어머니"
- "가족" / "집안" / "친정" / "처가"
- "형" / "동생" (이준호의 형이 자금 문제의 진실)
- "친척" / "친지"
- "부모님" / "어머니" / "아버지" (특정 영역 외 회피)

### 법적·재무 영역

- "개인회생" / "회생절차" / "회생" / "파산"
- "형사절차" / "형사사건" / "형사고소" / "고소"
- "사기" / "횡령" (혐의 단어 직접 X — 재판관이 단정 X)
- "변제" / "채권" / "채무"
- "범죄" — 진실 노출 후 NPC 자백 시 OK, 재판관이 추궁하며 단정 X
- "위조" — 재판관이 단정 X (NPC 자백 시 OK)

---

## ★ 허용 표현 (모호 referent — hidden 회피용)

다음 표현으로 hidden 키워드 회피 가능:

- "다른 사정"
- "별도 사용처"
- "또다른 문제"
- "숨긴 흐름"
- "다른 곳"
- "다른 쪽 일"
- "특정 사용처"
- "관련자" (시댁·가족 정체 회피용)
- "그쪽" (referent 불명확화)

## ★ 본 batch 잔존 entries 진실 누설 위반 영역 (확인된 곳)

본 batch 작업 대상 (judge_question / judge_contradiction / judge_witness_summon)에서 위반 영역:

### Batch 3 (judge_contradiction d-2 mid)

| ID | 원본 위반 키워드 | 변환 방향 (예시) |
|----|-----------------|------------------|
| judgec-d-2-mid-vN | "...뒤늦게 **집안 내에서 오간 돈**으로 정정하시면..." | "...뒤늦게 **다른 곳으로 흘러간 돈**으로 정정하시면..." 또는 "...뒤늦게 **별도 사용처로 흘러간 돈**으로 정정하시면..." |

→ Batch 3 진행 시 d-2 mid 5 variants 중 "집안" 등장 entry는 모두 회피형으로 재작성 필수.

### 그 외 직접 위반 등장 entry — 없음 (자연화 위주)

단, 본 batch 모든 entry 작업 후 자가 점검 필수:
- "가족" / "집안" / "형" / "회생" / "형사" / "범죄" / "사기" / "횡령" / "위조" 단어 단위 등장 X

---

## ★ 자연화 시 hidden 키워드 신규 추가 회피

polish 작업이 의미 보강을 위해 hidden 키워드를 새로 도입하지 않도록 주의. 예:

❌ "다른 관련자의 사정" → "그 가족의 사정" (위반 — 가족 추가)
❌ "다른 쪽 일" → "집안 일" (위반 — 집안 추가)
✅ "다른 관련자의 사정" → "그쪽의 사정" / "다른 사람의 사정"
✅ "다른 쪽 일" → "그쪽 일" / "별도 사정"

---

## ★ 진실 누설 의도가 명확한 곳에서 모호 referent 보존

본 잔존 entries에는 진실 누설 회피를 위해 이미 모호 referent를 사용한 영역이 있음. **이런 모호 referent는 보존 필요**:

| 보존해야 할 모호 referent | 의미 |
|-------------------------|------|
| "다른 관련자" | 친형/조카 정체 회피 |
| "다른 사정" | 외도 vs 진실 분기점 |
| "그 사정" / "그곳의 사정" | hidden 단어 회피 |

자연화로 인해 이러한 모호 referent가 hidden 단어로 구체화되지 않도록 주의.

---

## Polish 시 진실 누설 자가 점검

각 entry polish 후 다음 점검:

- [ ] hidden 키워드 (가족/집안/시댁/형/회생/형사/사기/횡령/범죄/위조 등) 단어 단위 등장 X
- [ ] 자금 사용처가 무엇인지 직접 명명 X (모호 referent만 허용)
- [ ] 외도 / 다른 사정 분기점 정도까지만 시사 OK
- [ ] 모호 referent로 의미 충분히 전달되는지 확인 (의미 손상 X)
- [ ] 원본의 모호 referent ("다른 관련자" 등)가 hidden 단어로 구체화되지 않았는지 확인
