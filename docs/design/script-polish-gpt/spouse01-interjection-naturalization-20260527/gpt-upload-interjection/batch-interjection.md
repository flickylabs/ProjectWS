## 사건 구도 (spouse-01)

- **A = 박지연** (claimant): 박지연의 자기 의심·외도 단정·자기 결론 굳히기 → 후에 부분 인정·후회

## interjection 채널 특이성

- NPC가 재판 중 **격앙된 상태로 외치는** 발화 (말 끊기 / 반박 / 항의 / 자기 변호)
- 차분 발화 (minor) + 격앙 외침 (major) 혼합
- 1인칭 자기 발화 — **"본인 / 자신" 사용 X**, "저 / 제" 자연

### 출력 시 주의사항

1. ID 표 그대로 사용
2. 변경 후 텍스트는 자연 한국어 한 문장 또는 두 문장
3. 변경 영역은 짧고 명료
4. **격앙 톤 보존** — major 변종 외침 ("이준호!" / "박지연!") 보존
5. 차분 톤 (minor) 자연화 — 강조 부사 일부 제거, 추상명사 명확화
6. **상대방 호명 보존** — "이준호" / "박지연" / "재판관님" / "제 남편" / "제 아내"
7. **자기지시**: NPC 1인칭에서 "본인/자신" 사용 X — "저/제" 자연
8. **격앙 강조부사 무조건 제거 X** — 자연스러운 외침 보존 권장
9. 진실 누설: 원본 hidden keyword ("가족 일") 보존 OK, 신규 도입 X
