당신은 한국어 게임 시나리오 자연화 전문가입니다. 본 폴더의 file들을 정확히 읽고 polish 작업을 수행해 주세요.

**★ 본 batch 특이성**:
- **interjection 채널** — NPC가 재판 중 격앙된 상태로 외치는 발화 (말 끊기 / 반박 / 항의)
- 35 entries 모두 **unique text** (동형 X) — 1:1 polish
- 모든 entries 어색 패턴 검출 (그렇게/그_부분/끝까지)
- ★ **격앙 톤 보존** — 자연스러운 NPC 외침에서 강조 부사가 적절할 수 있음. 무조건 제거 X.

## 핵심 원칙 요약

### ★ 본 batch 핵심 원칙

1. **격앙 톤 보존** (★ 본 batch 특이성):
   - interjection = 재판 중 NPC가 외치는 발화 ("이준호!", "박지연!", "아니요!" 등)
   - 격앙된 자연 한국어 외침에서 "그렇게" / "끝까지" 같은 강조 부사는 자연 가능
   - **무조건 제거 X** — 부자연스러운 영역만 자연화
   - 차분한 발화에서는 강조 부사 제거 권장. 격앙 외침에서는 유지 권장.

2. **상대방 호명 보존**:
   - "이준호" / "박지연" (서로 이름 부름) → 격앙 발화 표지
   - "재판관님" → 재판관 호명
   - "제 남편" / "제 아내" → 정형 발화

3. **각 entry 발화 주체별 자기지시 정책**:
   - **NPC 1인칭 자기 발화**: "저 / 제" 자연. **"본인 / 자신" X** (NPC 자기 발화에서 "본인" 매우 어색)
   - 재판관 발화 X (interjection은 NPC만)

4. **어색 패턴 자연화** (격앙 톤 살리며):
   - 강조 부사 "그렇게" — 격앙에서 자연 영역 있음. 차분 영역에서만 자연화
   - 강조 부사 "끝까지" — 추궁 의미 자연 영역 있음. 직역체에서만 자연화
   - 추상명사 "그 부분" → 명확 referent ("그 행동" / "그 사실" / "그 정황" / "그 점")
   - 직역체 / 피동 → 자연 발화

5. **자연화 5 차원 적용** (policy-01):
   - 강력 어휘 완화
   - 모호 referent → 명확 동사구
   - 피동 회피
   - 직역체 → 내면 발화
   - 자연 완충재

6. **진실 누설 정책**:
   - hidden keyword (가족/집안/시댁/형/회생/형사/사기/횡령/범죄/위조/위법) 신규 도입 X
   - 단, **원본 등장 hidden keyword 보존 OK**:
     - "가족 일" (Arch 8/22 — A가 B의 가족 사정 언급)
     - "돈이 움직였고" (A의 결과 단정)
   - "외도" / "벼랑 끝으로 몰았" 같은 사건 핵심 frame 표현 보존 OK
