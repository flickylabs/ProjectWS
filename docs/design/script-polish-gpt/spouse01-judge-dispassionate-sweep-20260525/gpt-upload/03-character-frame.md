# 03 — spouse-01 캐릭터 frame (변환 톤 일관성)

## 재판관 (judge)

- **격식 (KO)**: `...십시오`, `...습니까`, `재판관님` 호명 안 사용 (NPC가 부를 때만)
- **태도**: 사실 확인자. 평가·가치 판단 회피. 사실관계·선후관계·정황 중심
- **호칭**: NPC 본인 호명 시 "박지연 씨" / "이준호 씨" (성+씨)
- **추궁 강도 tone**: soft / mid / hard 단계. mid 이상은 직접 추궁 OK (단 평가 어휘 회피)
- **dispute 명사 활용**: 사건 명사 직접 호명 OK ("위임장 조작" / "공동 적금 해지" / "투자방 송금" / "공동 적금 출금" 등)

## A 박지연 (claimant, female 37)

- **archetype**: 의심·자기방어 + 외도 두려움 + 위임장 조작 자기 정당화
- **frame**: "남편의 침묵이 더 큰 잘못" / "나는 살아남으려 했다" / "처음에는 확인이었다" frame
- **단정 위험**: "선을 넘었습니다" (NPC outburst 단정 OK — 본 의뢰서 scope 밖)
- **응답 패턴**: 격앙 시 단정형, 평정 시 자기 합리화 frame

## B 이준호 (defendant, male 39)

- **archetype**: 침묵·은폐 + 형 일 (개인회생) 보호 + 위임장 사후 인정
- **frame**: "외도가 아니었다" / "형 일을 숨겼다" / "결국 침묵이 가장 큰 잘못" frame
- **응답 패턴**: 회피 / 늦은 인정. 단정형 회피 (자기 frame 보호)

## 핵심 dispute 영역

- **d-1**: 외도 의심 (e-1 오피스텔 방문 + e-2 통화 패턴). h-d4와 분리됨 (h-d4는 형 일 영역)
- **d-2**: 공동 적금 출금 패턴 (위임장 조작 전 단계, 박지연 명의)
- **h-d3**: 공동 적금 해지 + 위임장 위조 (박지연 행위 인정)
- **h-d4** (Cycle 4 신설): 박지연 난임 치료비 영역 (비자금 원래 목적). 이준호 휴대폰 의학 검색 + 출산 보험 관련 자료
