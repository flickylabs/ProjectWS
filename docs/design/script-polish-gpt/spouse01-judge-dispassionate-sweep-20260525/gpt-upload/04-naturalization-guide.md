# 04 — 변환 가이드 (judge dispassionate 어법)

## 핵심 원칙

1. **사실/행위 frame 우선** — 평가·감정·가치 어휘 회피
2. **자연성 우선** — 단순 어휘 치환 X. 문장 흐름 보고 통째 재구성 가능
3. **격식 보존** — `...십시오` / `...습니까` (재판관 격식 유지)
4. **dispute 명사 활용** — "위임장" / "출금" / "공동 적금" 등 사건 명사 직접 호명 OK

## 영역별 변환 패턴

### 1. "그 X" (지시 대명사) → 중립 대체

| 위반 | 권장 |
|---|---|
| "그 통화 상대" | "관련 통화 상대" / "그 시각 통화 상대" / "당시 통화 상대" |
| "그 기록을 처음 본 순간" | "관련 기록을 처음 본 순간" / "해당 기록을 처음 본 순간" / "이 기록을 처음 본 순간" |
| "그 자료가" | "해당 자료가" / "관련 자료가" / "이 자료가" |
| "그 기록이 남은 이유" | "관련 기록이 남은 이유" / "이 기록이 남은 이유" |

⚠ "관련"이 어색할 때 대체:
- "이 X" (당장 직접 가리킬 때 — 증거 등재 직후)
- "해당 X" (격식)
- "당시 X" / "그 시각 X" (시점 명시)
- 구체 명사 ("통화" → "새벽 통화", "기록" → "출금 기록")

### 2. "선을 넘다" (행위 평가) → 사실 frame

| 위반 context | 권장 변환 |
|---|---|
| "추궁하는 선을 넘게 했습니까" | "직접 추궁하게 했습니까" / "추궁으로 옮기게 했습니까" |
| "본인이 선을 넘은 행동" | "본인이 절차에 손댄 행동" / "본인이 직접 옮긴 행동" |
| "왜 그 선을 넘었는지" | "왜 절차에 직접 손을 댔는지" / "왜 서류를 직접 손댔는지" |
| "선을 넘은 행동" | "절차를 손댄 행동" / "절차에 직접 손댄 행동" |

⚠ NPC 발화의 "선을 넘었다"는 self-evaluation으로 본 의뢰서 scope 밖. JUDGE 발화만 변환.

### 3. tone 강도 보존

- **soft**: 부드럽게 들춰내는 단계. "들려주십시오" / "말씀해 주시겠습니까"
- **mid**: 직접 묻는 단계. "말씀하십시오" / "설명해 주십시오"
- **hard**: 단호한 추궁. "...덮을 수 없습니다. ...십시오"

변환 후 tone 일관성 유지.

### 4. 격식 어미 일관성

| 어미 | 사용 영역 |
|---|---|
| `...십시오` | 명령형 격식 (재판관 → NPC) |
| `...습니까` | 의문형 격식 |
| `...겠습니까` | 부드러운 청유형 |
| `...십시오. ...십시오.` | 단호한 반복 (hard tone) |

⚠ "...해주세요" / "...해주세요." 같은 부드러운 끝맺음 회피 (격식 부족).
