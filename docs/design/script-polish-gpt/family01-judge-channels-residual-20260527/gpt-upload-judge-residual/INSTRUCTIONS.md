## 핵심 원칙

1. **재판관 청유/추궁 톤 보존** — 채널별 톤 정합:
   - judge_evidence_combo: soft/mid/hard 3단계 청유 어미
   - judge_question: 일반 추궁 질문 (단정 X)
   - judge_contradiction: 모순 지적·확인 (확인 형식)
   - judge_witness_summon: 증인 소환·확인 (격식)
2. **NPC 호명 보존**: 김도윤 씨, 김민서 씨 (사건별 호명)
3. **자기지시 정책** ([[design_self_reference_bonin_consistency]]):
   - 재판관 → NPC 지칭에 "**본인**" 사용 자연 (정책 부합 — 이미 batch에서 제외)
   - 재판관 → NPC 지칭에 "**자신**" → "**본인**" 통일 (본 batch에 일부 포함)
   - NPC 1인칭 자기 발화 영역은 본 batch에 없음 (NPC 발화 채널 X)
4. **직역 어미 자연화**:
   - "가리킵니다" → "맞물려/이어져 있습니다"
   - "드러납니다" → "확인됩니다 / 보이게 됩니다"
   - "이어집니다" → "연결됩니다 / 닿아 있습니다"
   - "나타납니다" → "확인됩니다 / 보입니다"
5. **강조 부사 정밀**:
   - "그렇게" — 격앙 영역 외 정리 (재판관 차분 톤이라 정리)
   - "끝까지" — 추궁 자연 영역 보존 ("끝까지 ~지 않았습니까") / 직역체 정리
   - "차분히" — 직역체 영역 자연화 (재판관 자기 발화 부적합)
   - "완전히" — 단정 강조 다양화 (전부 / 통째로 / 다)
   - "진짜" — 강조 부사 영역 정리 (그때 / 실제로)
6. **추상명사 구체화**:
   - "그 부분 / 그 점" → 구체 referent (그 항목 / 그 사실 / 그 대목)
   - "그 판단 / 그 결론" → 구체 referent (그 답 / 그 사실 / 단정)
   - "그 상황" → 구체 referent (당시 / 그 자리 / 그 시점)
7. **피동 회피**: "느껴집니다 / 보여집니다 / 생각됩니다" → 능동 영역으로 자연화
8. **진실 누설 자가 점검** (policy-02): family-01 진실 누설 정책: 5 keyword × dispute disclosure tier (출생/정후 돈/자필 90:10/공장 양보/유산).
