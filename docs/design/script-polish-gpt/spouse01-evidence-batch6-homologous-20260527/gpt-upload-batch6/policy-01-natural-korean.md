# 정책 01 — 한국어 자연화 원칙 + NPC 적극 발화 5 차원

## 본 batch 특성 — evidence_present 채널 (NPC 발화 영역)

본 batch는 spouse-01 사건의 **evidence_present 채널** = 재판관이 NPC에게 evidence를 제시할 때 NPC가 반응하는 자기 발화 영역.

**발화 주체**:
- partyA (박지연) — claimant, 외도 의심·자금 추궁 측
- partyB (이준호) — defendant, 침묵·해명 측

**stage 구조** (variant 정렬):
- lieBand: early (초반 회피·방어) / mid (중반 인정·변명) / late (후반 진실 인정)
- stage 1/2/3: investigation 단계별 반응 강도
- self / other / both / check_metadata / request_original / restore_context: 보조 stage

**자연화 우선 영역 = NPC 적극 발화**.

## ★ NPC 적극 발화 5 차원 (★ 본 batch 핵심)

NPC가 자기 발화로 evidence에 반응할 때 다음 차원으로 자연화:

### 1. 강력 어휘 완화 (혐의·사기·횡령 등)
- "혐의" / "사기" / "횡령" / "위조" 단어 직접 사용 회피
- band=late S5 자백 단계에서는 NPC가 "범죄/위조" 인정 OK (이미 진실 인정 단계)
- early/mid 단계에서는 회피형 ("법적 책임이 따를 수 있는 일" / "선을 넘는 일")

### 2. 모호 referent → 명확 동사구
- ❌ "그 사정이 있었습니다" / "그쪽 일이 있었습니다"
- ✅ "제 도움이 필요한 일이 있었습니다" / "그분께 손을 보태야 했습니다"
- referent를 NPC 행동·의도가 드러나는 동사구로 구체화

### 3. 피동 회피
- ❌ "보여집니다" / "느껴집니다" / "이어집니다" (직역체 피동·자동사)
- ✅ "보입니다" / "느낍니다" / "이어졌습니다" — 행위 주체 명확화
- 단 "이어집니다"가 자료의 흐름을 가리키는 자연 사용 영역은 보존 (자연 한국어)

### 4. 직역체 → 내면 발화
- ❌ "그 판단이 한동안 이어졌습니다" (직역 명사+추상)
- ✅ "저는 그렇게 판단했고, 그 마음이 한동안 이어졌습니다" 또는 "그 생각을 한동안 굳히고 있었습니다"
- NPC 내면 상태가 드러나는 발화로 재구성

### 5. 자연 완충재 활용
- "말씀드리기 어렵지만..." / "사정이 있어..." / "어쩔 수 없었습니다"
- NPC가 진실을 완전히 못 밝히는 단계 (early/mid)에서 자연스럽게 회피하는 완충재
- 단 hidden 키워드 신규 도입 X (policy-02 참조)

## 필수 원칙 (★ 절대 준수)

### 원칙 1. 번역체 최대한 배제

다음 번역체 흔적 모두 회피:

- **직역 어순** — 영어 SVO 어순 직역
- **추상명사 양극 대비** — "사정/상황/문제/판단/흐름" 등 추상명사 X와 Y 양극 대비 구조
- **"보입니다 / 느껴집니다" 직역체** — 원본 의도가 추측이 아닌데 완곡 추측으로 옮기지 X
- **단순 어휘 치환** — 문장 구조 자체 자연화 필요
- **인공적 시적 표현** — "그 사정을 두고" 같은 시적 표현
- **수식어구 군더더기** — "지금/이제/모두/끝까지/차분히/그렇게" 등 강조 부사 남발
- **피동 어색** — "보여집니다 / 이어집니다"
- **NPC 자기 발화 어색** — 재판관 발화처럼 "...주십시오" 청유 어미 NPC가 쓰지 않음

### 원칙 2. 불필요한 의미 추가 절대 금지

원본 KO 의미만 보존 + 자연화. 다음 행위 금지:

- 원본에 없는 새 사실/단서/암시 추가
- 원본에 없는 새 평가/판단/태도 추가
- 화자 추측·태도 강조 부사 (솔직히/분명히/확실히) 추가
- 의도가 명확한 곳에 모호 표현 도입

### 원칙 3. 게임 톤 = NPC 발화 (재판관 X)

- **NPC 자기 발화** — "...했습니다" / "...입니다" / "...였습니다" (재판관 청유 X)
- 격식체 + 감정 자연 발화
- "재판관님" 호명 보존 (NPC가 재판관에게 자기 진술하는 형식)
- NPC 화자 어조 (defensive / admitting / regretful) 보존

### 원칙 4. lieBand·stage 단계 차이 보존

| lieBand | NPC 톤 |
|---------|--------|
| early | 초반 회피·부정·방어 ("...아닙니다" / "...어렵습니다") |
| mid | 중반 부분 인정·변명 ("...맞습니다, 다만...") |
| late | 후반 진실 인정 ("...입니다. 책임이 있습니다.") |

→ polish 시 같은 NPC 발화의 단계별 톤 손상 X

## ★ 사용자 polish 패턴 example (★ 톤 학습 핵심)

다음은 spouse-01 사건의 직전 폴리시에서 사용자가 직접 작성한 patch 패턴입니다:

### Before → After 대조표

| Before (Claude/GPT 시안 — 번역체) | After (사용자 polish — 자연 한국어) |
|--------|-------|
| 그 부담이 어느 정도였는지 들려주시겠습니까 | 그게 무엇인지 말씀해 주시겠습니까 |
| 그 사정이 두려워 계속 숨겨 오신 부분 | 갈등이 두려워 계속 숨겨 오신 사항 |
| 그 너머의 사정을 왜 끝까지 빼두셨습니까 | 그 너머의 사정을 왜 끝까지 숨기셨습니까 |
| 무엇을 두려워하셨는지 | 무엇이 두려우셨던 것인지 |
| 따로 급한 사정이 있어 보이지만 큰돈을 혼자 움직이신 문제도 남습니다 | 따로 급한 사정이 있으셨다 해도 큰돈을 따로 움직이신 것은 설명이 필요합니다 |
| 별도의 사정이 연결됩니다. 개인 돈이라는 말 뒤에 숨으실 수 없습니다 | 또다른 문제가 됩니다. 개인적인 사용이라는 말로 덮으실 수 없습니다 |

### 학습 패턴 정리

1. **추상 referent 제거** — "그 사정/그 흐름/그 판단" → 구체 명사구 또는 동사구
2. **강조 부사 정리** — "그렇게/차분히/끝까지/이미" 등 의미 손상 없는 영역 제거
3. **직역 어미 자연화** — "이어집니다/가리킵니다" → 자연 술어 ("이어졌습니다/맞물립니다/시사합니다")
4. **NPC 톤 강화** — 단순 보고가 아닌 NPC의 감정·태도가 드러나는 발화
5. **시적/생경 표현 회피** — 한자어/현대 자연 한국어 우선
