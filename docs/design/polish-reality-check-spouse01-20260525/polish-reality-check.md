## §0 사건 요약

- **관계**: 부부 (박지연 A / 이준호 B)
- **표면 분쟁**: 박지연이 남편 이준호의 외도를 의심
- **실체**: ① 이준호의 새벽 외출은 친형(개인회생 중) 오피스텔에서 중2 조카 돌봄, 10년 비자금 3,000만 원은 원래 박지연 난임 치료비 → 형 사건 후 형 지원으로 전환 / ② 박지연은 외도 확신 후 위임장을 위조해 공동 적금 2,000만 원 해지 + 투자방 운영자에게 송금 → 사기로 전액 손실
- **법정 절차**: 이혼 소송 + 박지연 위임장 위조 별도 형사 책임

## §1 평가 기준

각 entity를 4 차원으로 본다.

1. **존재** — 현실에서 그러한 형태로 존재할 수 있는가
2. **소유** — 현실에서 누가 가지고 있을 수 있는가 (본인 명의 자료를 상대가 임의 보유 가능한가)
3. **제출** — 어떤 경로로 법정에 등장하는가 (수사 영장 / 본인 제출 / 제3자 협조 / 발견 사본 등)
4. **중복/패턴 회피** — 다른 entity와 형태가 겹치지 않는가

등급: ✅ 합리적 / ⚠ 약간 어색 / ❌ 변경 필수

우선순위: **P0** 변경 필수 / **P1** 조정 권장 / **P2** 향후 검토

→ **권고: 1안**. "이준호 ATM 출금 영수증 묶음" → 차량/지갑/책상에서 A가 우연 발견 + 카드 명세서·창구 출금증과 시각 대조로 hard 입증. 분할 출금 흐름이 그대로 보이고 발견 경로가 자연스러움.
