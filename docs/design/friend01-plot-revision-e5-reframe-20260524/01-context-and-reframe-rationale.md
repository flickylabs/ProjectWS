## e-5 reframe rationale (사용자 권위 영역)

### 기존 e-5 본질 (현)

> "송다은 아버지가 예비신랑에게 "결혼 전에 잠깐만 도와주면 금방 돌려준다", "다은이한테는 아직 말하지 마"라고 보낸 문자 기록."

### 사용자 지적 (Cycle 8 cycle 세션 2단계 영역)

> "e-5는 상황 자체가 좀 이상해. 캐릭터B는 워낙 배려심이 많고 생각이 많아서 숨기고 알아서 처리하려 한다 했어도 예비신랑은 그럴 성격이 아니야. 예비신랑에게 아버지가 접근을 완료했다면 오히려 숨길 수 없었을거야. 아버지가 시도하려고 하고 그걸로 인해 결혼 자체에 위기가 올게 걱정이 된 B가 그걸 막아보려고 했던걸로 내용이 좀 바껴야 될 것 같아."

### 자연 chain (사용자 의도)

1. **아버지의 시도** (탐색 단계, 완료 전 또는 일부 시도)
2. **예비신랑이 회사·친구 사이에서 떠벌림** (숨기지 않는 성격 — 회사 동료 단톡방에서 "다은이 아버지가 결혼 자금 좀 도와달래" 같은 말 토로)
3. **w-2 박준혁이 그것을 들음** (회사 후배 + 필라테스 수강생 이중 관계 → 자연 인지)
4. **w-2가 B에게 알림**
5. **B가 결혼 위기 걱정** → **예비신랑에게 직접 9일간 차단 연락 시도**

### 새 e-5 본질 (시안 S1)

> "예비신랑 김태윤이 회사 동료 단톡방에서 '다은이 아버지가 결혼 자금 좀 도와달래'라며 토로한 캡처와, 그 시점 직후 최수민이 예비신랑에게 보낸 9일간의 차단 메시지 원본."

### reframe 결과 명세

| 차원 | 변경 |
|---|---|
| **자료 source** | 아버지가 예비신랑에게 직접 보낸 문자 → 예비신랑이 회사 단톡방에 토로한 캡처 + B의 9일간 메시지 원본 |
| **아버지의 접근 상태** | 완료 → **시도 (탐색 단계)** |
| **예비신랑 묘사** | 숨기는 성격 → **떠벌리는 성격 (회사·친구에 자연스레 토로)** |
| **B 9일간 연락 의도** | "경고" → **"결혼 위기 차단 시도 (직접 연락해 막으려 함)"** |
| **w-2 chain 연결** | w-2 d-2 영역 한정 → **w-2 d-3 영역 추가 (떠벌림 → B에게 알림 chain 증언)** |

### narrative 정합 효과

- e-1 (B 9일간 연락 기록 메타) → e-5 (메시지 원본 + 떠벌림 흔적) 자연 chain
- e-4 (예비신랑 선 넘는 메시지 + B 거절, Line B) + 새 e-5 (B 9일간 차단 연락, Line C) = Line B+C 동일 9일 영역 양측 자료
- w-2 knowledgeScope ("회사에서 예비신랑이 떠벌린 이야기를 우연히 듣고 최수민에게 알린 적이 있다" — Cycle 7 확정) → 새 e-5 chain의 핵심 증언자 자연 정합
- d-3 truthDescription에서 "경고"보다 "결혼 위기 막으려 직접 연락해" frame이 더 자연 (B character `affect_flattening` 정합 — 경고는 명시적 행위, 차단은 침묵 frame 안에서 가능)

## anchorTruth / resolutionDilemma (case meta) 검토

`friend-01.case.ts` meta 영역:

- **anchorTruth**:
> 최수민의 9일간 연락은 집착이 아니라 송다은 아버지의 돈 접근 패턴을 결혼 직전 예비신랑에게 경고하려던 것이었다. 과거 손절의 진짜 원인은 송다은 아버지가 최수민에게 투자 명목으로 돈을 받아간 사기였고, 최수민은 송다은이 무너질까 봐 끝내 그 사실을 말하지 못한 채 악역을 자처했다. 송다은은 확인 없이 단톡방에서 최수민을 매도했고, 같은 구조가 반복됐다.

→ **anchorTruth는 reword 필요** ("경고하려던" → "결혼 위기를 막으려 직접 연락한"). 다만 본 의뢰서 영역 외부의 의사결정이라 CT 세션 진행 시 사용자에게 확인 권장.

- **emotionalBait**:
> 손절한 전 절친이 내 예비신랑에게 계속 연락한다. 결혼 3주 전, 그 장면만 보면 누구라도 친구가 선을 넘었다고 생각한다.

→ 변경 없음 (B의 9일간 연락이 핵심 frame, 시도 vs 완료 영역과 무관).

- **resolutionDilemma**:
> 최수민의 침묵이 매번 보호에서 비롯됐다 해도, 결과적으로 더 큰 오해와 낙인을 만들었다. 송다은의 성급한 단정은 잔인했지만 아버지의 진실을 모른 채 반응한 것이기도 하다. 두 사람 모두 확인 전에 단정한 책임이 남는다.

→ 변경 없음 (큰 frame은 reframe과 무관).
