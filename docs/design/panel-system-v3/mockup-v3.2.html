3. v3 통일 결정 사용자 6건 피드백 반영

① 헤더 1행 패턴 통일
모든 패널 = grid-template-columns: 1fr auto 1fr
· LEFT (col 1, 1fr): subtitle/eyebrow/tags 좌측 정렬
· CENTER (col 2, auto): title 진짜 중앙 (1fr 대칭으로 viewport 중심선)
· RIGHT (col 3, 1fr): close × 또는 marker, 우측 정렬
이전: eyebrow 위 / title 아래 vertical stack → 한 줄로 합쳐 세로 폭 절약 + 시각 통일.
② 너비 5단 → 2단 (640 / 760)
popup = 640 / structural = 760. 이전 600/640/760/880/960 5단이 "제각각"이라 단순화.
evidence + contrast가 760으로 좁아짐 — stages는 세로 stack, VS는 컴팩트 quote.
⏳ 적용 시 contrast wide layout이 좁아질 수 있음 — 검토 필요
③ Typography 통일
이전 popup title 22px / body 14.5px → structural 18px / 13px로 일치.
모든 패널 동일 토큰:
· subtitle 11/800/uppercase/gold
· title 18/850/white
· body 13/400
· button 13/700
④ 컬러 #7 기준 (dispute selector 톤)
bg dark gradient · border rgba(212,162,78,0.22) · subtitle muted gold · title warm white. 모든 패널 동일.
⑤ Marker pin (선택적)
.panel-pin 신규 — top border 위에 절반 overlap.
· ◆ diamond = state_change modal (신뢰 창 등)
· ⚖ scale = 심문 방식 패널 (선택)
헤더 row와 독립. 패널 type 식별용.
⑥ Evidence 발언대 버튼 컬러 복원
실제 게임 .pc-ev-detail__present-btn 매핑:
· is-a (박지연/A) = 파란 3px left border + 좌측 glow
· is-b (이준호/B) = 빨간 3px right border + 우측 glow
· 32×32 원형 portrait + gold border
v2의 plain 버튼 → v3 게임-정확 복원.
⑦ Witness subtitle 제거
"적절한 시점에 소환해야 핵심 증언을 들을 수 있습니다" 안내문 완전 제거.
title "증인 소환"만 헤더에 노출 — body의 witness card가 정보 충분.
⑧ Info-only 패널 [확인 Space]
모순 추궁처럼 액션 버튼 없는 패널에 일관된 dismiss row 추가. popup의 [확인 Space] 패턴을 structural에도 동일 적용.

4. v2 적용 영역 — 코드 변경 대상

⑤ 진짜 중앙 정렬 (B안 3-col grid) — pc.css의 Track A header rule을 display: grid; grid-template-columns: 32px 1fr 32px로 변환. icon은 col 1 (32px zone 안에서 자체 22×22 중앙), text wrapper는 col 2 (진짜 중앙), close는 col 3. icon 유무와 무관하게 title 중심선이 viewport 정중앙과 일치.
영향 면 — 모든 structural 패널 (dispute selector / witness summon / evidence / contrast).
⑥ Evidence character portrait 유지 — 코드는 이미 PCInteractionPanel.tsx의 evidence 변형에서 portrait 사용 중. 본 mockup v1에서 누락되어 있어서 v2에 복원만. 코드 변경 불필요.
⑦ 주요 쟁점 inline + 3-col grid — EvidenceDetailSection의 "주요 쟁점" 섹션: display: grid; grid-template-columns: 1fr auto 1fr로 label 좌측 / content 진짜 중앙 / 우측 균형 spacer. 세로 폭 ~30px 절약 + content 중심선 정확.
⑧ Info-only modal dismiss — contrast modal(pc-interaction-card--contrast)이 actions 없이 정보만 노출하는 경우 자동 [확인 Space] dismiss row 추가. PCInteractionPanel.tsx payload에 variant: 'info-only' 또는 actions 0건 + contrast=true 조건으로 분기.
코드 적용 우선순위: ⑤ (높음, CSS 한 줄) → ⑦ (중, EvidenceDetailSection 컴포넌트 1곳) → ⑧ (중, PCInteractionPanel 분기 1곳). ⑥은 기존 코드 keep.
