NPC 본인 발화 (변명·인정·회피) 영역 polish 시 [[feedback-natural-korean-precision-guide]] 19 차원 외 추가 점검 차원. 본 세션 (2026-05-25 spouse-01 evidence_present 69 entries polish 후 사용자 11 영역 patch) 학습.

**Why**: NPC가 본인 입장에서 발화하는 영역 (evidence_present / interrogation 등)은 재판관 격식 (judge_evidence_combo)과 다름. 사용자가 "내용은 숨기더라도 표현은 명확하게" 명시. GPT 결과의 추상 referent / 피동 직역체 / 강력 어휘 영역을 적극 발화로 변환 필요.

**How to apply**: NPC 발화 영역 polish 시 19 차원 + 본 5 차원 추가 점검.

## 추가 차원 (NPC 발화 전용)

### 1. 강력 어휘 완화 — 범죄·법적 단어 회피

NPC 본인이 자기 행동을 변명할 때 범죄 단어 ("혐의 / 사기 / 횡령")는 너무 강력. 일반 단어로:

- "외도나 횡령을 단정하진" → "외도나 다른 문제로 단정짓지" (혐의 → 문제)
- "사기였습니다" → "속았습니다" (피해자 입장)
- "사기 의심이 가는 대화" → "수상한 대화" (혐의 단어 회피)

### 2. 모호 referent → 명확 동사구

GPT가 자주 사용하는 "다른 쪽 일 / 다른 사정 / 관련된 얘기" 같은 모호 referent를 사용자 입장에서는 어색·답답. 명확한 동사구·명사구로:

- "다른 쪽 일에 손을 보태야 했습니다" → "제 도움이 필요한 일이 있었습니다"
- "가족 쪽 일을 제가 맡았습니다" → "제 도움이 필요한 일이 있었습니다"
- "다른 일을 챙기려는 뜻이 있었습니다" → "제 도움이 필요했던 상황이라 어쩔 수 없었습니다"
- "관련된 얘기를 숨긴 건" → "그 얘기를 숨긴 건"
- "다른 사정이라" → "사정이 있어"
- "제 일과 관련된" → "저와 관련된" ("제 일"이 모호)

### 3. 피동 직역체 → 적극 발화

NPC가 본인 의지·내면을 표현하는 영역에서 피동 / 객관 서술이 어색. 적극 발화·내면 동사로:

- "드러납니다" → "얽혀있어 말씀드리기 어렵습니다" (객관 → 본인 어려움)
- "있었습니다 (~뜻이 있었습니다)" → "어쩔 수 없었습니다 / 인정합니다" (추상 → 행위)
- "관련 있습니다" → "있었습니다" (피동 → 능동)
- "단정하진" → "단정짓지" (어색 어미 → 자연 동사형)

### 4. 직역체 구문 → 한국어 내면 발화

영어 직역 (purpose was X / it was that Y) 어순을 한국어 내면 발화체로:

- "그 목적은 ... 수습하는 것이었습니다" → "저는 그저 문제를 해결하고 수습하고 싶었던 것 뿐입니다" (목적 → 내면 욕구)
- "그 행동에는 ... 뜻이 있었습니다" → "제 도움이 필요했던 상황이라 ..." (행동→뜻 → 상황→어쩔 수 없음)
- "그건 다른 쪽 일과 이어져" → "그건 말씀드리기 어렵지만 다른 문제입니다" (방향성 → 직접 인정)

### 5. 자연 완충재 활용 — "말씀드리기 어렵지만 / 사정이 있어 / 어쩔 수 없었습니다"

NPC가 진실 누설 회피하면서도 명확하게 변명하려면 자연 완충재가 필요. GPT는 회피 영역을 모호 referent로만 처리 → 어색. 사용자 패턴:

- "말씀드리기 어렵지만" (회피 + 명확)
- "사정이 있어" (회피 + 자연)
- "어쩔 수 없었습니다" (변명 + 자기 인정)
- "분명 잘못입니다" (강조 + 자기 평가)
- "변명의 여지가 없습니다" (강력 인정)
- "다른 사람의 사정까지 얽혀있어 말씀드리기 어렵습니다" (회피 이유 명확화)

## NPC 발화 vs 재판관 발화 톤 차이

| 영역 | 재판관 (judge_evidence_combo) | NPC (evidence_present / interrogation) |
|------|----------------------------|-------------------------------------|
| 어미 | "말씀해 주십시오 / 들려주시겠습니까" | "~합니다 / ~네요 / ~겠습니다" |
| 의도 | 추궁 / 정중 청유 | 변명 / 인정 / 회피 / 미루기 |
| 톤 | 격식 + 직접 추궁 | 일상 격식체 + 내면 발화 |
| 추상 referent | 허용 (재판관 정리 영역) | 회피 (어색 / 답답) |
| 피동 | 허용 (객관 서술) | 회피 (NPC 본인 발화 어색) |

## Polish 시 자가 점검

NPC 발화 영역 polish 후:

- [ ] 강력 어휘 (혐의 / 사기 / 횡령) 사용 X — 일반 단어로 완화
- [ ] 모호 referent (다른 쪽 일 / 관련된 얘기) X — 명확 동사구
- [ ] 피동 / 객관 서술 X — 적극·내면 발화
- [ ] 영어 직역 구문 X — 한국어 내면 발화체
- [ ] 자연 완충재 (말씀드리기 어렵지만 / 사정이 있어 / 어쩔 수 없었습니다) 활용
- [ ] 재판관 격식 ("말씀해 주십시오") X — NPC 일상 격식
- [ ] 19 차원 ([[feedback-natural-korean-precision-guide]]) 동시 점검
