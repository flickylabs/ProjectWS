# GPT Pro 요청: v3 Fallback 교체 — 게임 이벤트 스크립트

> 3건(spouse-01, family-01, friend-01)의 v3FallbackGameLoopData placeholder를 사건별 맞춤 텍스트로 교체

---

## 첨부 파일 안내

이 세션에 함께 전달되는 파일들:

| 파일 | 내용 | 용도 |
|------|------|------|
| `01-case-context.json` | 3건 사건 데이터 (당사자/쟁점/증거/진실/맥락) | **필수 참고** — 사건 이해 |
| `02-current-placeholder.json` | 현재 fallback이 생성하는 기계적 텍스트 | **교체 대상** — 이걸 대체할 것 |
| `03-scripted-text-samples.json` | spouse-01 기존 ScriptedText 채널 샘플 | **톤/스타일 참고** — 이 톤을 따를 것 |
| `04-quality-rules.md` | 한국어 품질 규칙 + 금지 패턴 | **필수 준수** — 번역체/관찰문/호칭 |

**작업 순서**: 01로 사건을 이해 → 02의 placeholder를 확인 → 03의 톤을 참고 → 04의 규칙을 준수하여 → 아래 산출물 구조대로 작성

---

## 목적

현재 게임 이벤트(모순 발견, 끼어들기, 감정 폭발)가 쟁점명을 기계적으로 삽입한 placeholder를 사용합니다:
```
"'유서 작성과 판단 능력' 문제를 두고 결과 해석과 경위 해석이 갈라진다."
```
→ 사건 맥락에 맞는 자연스러운 한국어로 교체해야 합니다.

---

## 산출물 구조

각 사건별로 아래 3종 이벤트를 작성합니다.

### 1. contradictions (모순 이벤트) — 사건당 2건

양측 진술이 정면으로 충돌하는 순간. 플레이어가 "짚는다/넘긴다"를 선택합니다.

```json
{
  "id": "{caseId}-contradiction-1",
  "statementA": "A가 주장하는 핵심 한 문장 (구체적 사실 기반)",
  "statementB": "B가 맞서는 핵심 한 문장 (구체적 사실 기반)",
  "options": {
    "point_out": {
      "label": "짧은 행동 요약 (5~8자)",
      "effect": "플레이어가 짚었을 때 드러나는 결과 (1문장)"
    },
    "let_go": {
      "label": "짧은 행동 요약 (5~8자)",
      "effect": "넘겼을 때의 결과 (1문장)"
    }
  },
  "npcReaction": "시스템 메시지 — 관찰자 서술체, 1문장"
}
```

### 2. interjections (끼어들기) — 사건당 2건 (A 1건, B 1건)

한쪽이 참지 못하고 말을 자르는 순간.

```json
{
  "id": "{caseId}-interjection-a",
  "interruptor": "a",
  "interjectionLine": "A가 끼어드는 대사 (반말/감정적, 1~2문장)",
  "options": {
    "allow": {
      "label": "짧은 행동 요약",
      "effect": "허용했을 때 드러나는 것"
    },
    "block": {
      "label": "짧은 행동 요약",
      "effect": "차단했을 때 결과"
    }
  }
}
```

### 3. emotionalOutbursts (감정 폭발) — 사건당 2건 (A 1건, B 1건)

감정이 크게 흔들리는 순간. 압박할지 진정시킬지 선택.

```json
{
  "id": "{caseId}-outburst-a",
  "party": "a",
  "outburstLine": "A의 감정 폭발 대사 (1~2문장, 격앙/울먹임)",
  "options": {
    "press": {
      "label": "짧은 행동 요약",
      "effect": "압박 결과"
    },
    "calm": {
      "label": "짧은 행동 요약",
      "effect": "진정 결과"
    }
  }
}
```

## 사건별 맥락

### spouse-01 (박지연 vs 이준호 — 부부, 딴살림 의혹)

**핵심 진실**: 박지연은 남편의 딴살림을 확신하고 위임장 조작으로 공동 적금 2,000만원을 해지, 투자 사기로 전액 손실. 이준호는 외도가 아니라 친형의 조카(중2)를 돌보고 있었고, 비자금 3,000만원을 형에게 전달.

**충돌 축**:
- contradiction-1: "오피스텔 방문" — A는 딴살림 증거라 확신, B는 조카 돌봄이라 주장
- contradiction-2: "돈의 행방" — A는 B가 비자금을 숨겼다, B는 A가 적금을 먼저 해지했다

**감정 폭발 포인트**:
- A: 10년 결혼이 거짓이었다는 배신감 + 적금 해지 사실이 드러날 때의 수치심
- B: 형 가족을 지키려 한 것뿐인데 의심받는 억울함

**캐릭터**:
- 박지연(victim_cosplay): 피해자 위치를 먼저 잡고, 동기 질문에 수치심으로 범위를 넓힘
- 이준호(avoidant): 이유를 뒤로 미루고 모호어로 시간을 벌다가 한꺼번에 터짐

---

### family-01 (윤태성 vs 윤정후 — 형제, 유서 분쟁)

**핵심 진실**: 유서를 손댄 건 분명히 윤정후. 하지만 그 조작은 자기 몫을 줄인 조작이고, 20년간 형과 어머니를 몰래 떠받쳐 온 것도 윤정후.

**충돌 축**:
- contradiction-1: "유서 비율" — A는 치매 말기 어머니가 60:40을 판단할 수 없었다, B는 어머니 뜻이 있었다
- contradiction-2: "20년 송금" — 형이 평생 어머니가 도와준 줄 알았던 돈이 사실 동생 돈

**감정 폭발 포인트**:
- A(confrontational): "모시고 산 건 나인데 왜 40이냐" — 형의 분노와 자존심
- B(affect_flattening): 감정을 끝까지 억누르다가 "형을 지키려고 그랬다"는 순간에 무너짐

---

### friend-01 (송다은 vs 최수민 — 절친, 예비신랑 연락)

**핵심 진실**: 최수민은 예비신랑을 꼬시려 한 게 아니라 경고하려 했고, 오래전 송다은 아버지에게 당한 일을 말하지 못한 채 스스로 악역이 됨.

**충돌 축**:
- contradiction-1: "9일간 연락" — A는 집착이라 확신, B는 경고였다고 주장
- contradiction-2: "과거 손절" — A는 B가 또 선을 넘었다, B는 A 아버지 때문에 손절당한 것

**감정 폭발 포인트**:
- A(premature_summary): 결론부터 말하고 밀어붙이다가, 아버지 사실이 드러날 때 무너짐
- B(affect_flattening): 감정을 눌러 담다가 "네 아버지가 내 돈을 가져갔다"는 말을 할 때

## 품질 규칙

1. **쟁점명 직접 삽입 금지** — "'유서 작성과 판단 능력' 문제를 두고..." 이런 패턴 절대 사용 안 함
2. **번역체 금지** — "~된 것으로 생각됩니다", "부득이하게" 등 9패턴
3. **기계적 관찰문 금지** — "변화가 감지됩니다", "확인됩니다"
4. **호칭 규칙**:
   - statementA/B: 재판관 대상 합니다체 ("재판관님, ~입니다")
   - interjectionLine: 상대방 대상이면 반말 ("형, ~/자기, ~/수민아, ~")
   - outburstLine: 감정적이므로 해요체 허용
5. **npcReaction/effect**: 시스템 관찰자 서술체 ("진술이 달라지기 시작한다", "두 설명이 부딪힌다")
6. **구체성**: 사건의 실제 사실/인물/상황을 반영. 일반론 금지.
