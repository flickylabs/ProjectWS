3종 동시 재생 으로 어느 오브제가 가장 의미 전달이 좋은지 비교 검토. 비행 궤적 · 캐릭터에서 호를 그려 천칭(상단)으로 흡수 + 천칭 펄스 + 게이지 카운트업. 신뢰 하락 시는 반대 방향 (천칭 → 캐릭터 방향), 색상도 회색으로 dim. 지속 · 약 2.4초.

일반 상승 · 카드 외곽 골드 ring 1회 펄스(0.9s) + 새 dot이 scaleY 펄스로 채워짐. 빈번한 이벤트라 dim하게 — 작업 흐름 방해 X. 마지막 달성 · 인장 도장(scale 0 → 1.3 → 1.0, rotate -15° → 0°, 1.2s) + 도장 찍히는 순간 카드 plate flash (흰빛 0.2s) + 광선이 좌측 관찰 영역으로 발사 + 후광(halo) ring 확장. 지속 · subtle 0.9s / dramatic 3.4s.

구현 메모 · CSS animation + class toggle 패턴 (replay button → remove .is-playing → reflow → add .is-playing). 실제 적용 시 컴포넌트는 React effect 안에서 timer + state로 진입/종료 제어. 사운드 hint(Scene 3 사이렌 wail, Scene 4 도장 thump)는 Web Audio API 합성음으로 구현 가능. 컬러는 PC 표준 토큰 사용 (post-A1~A4 통일).
