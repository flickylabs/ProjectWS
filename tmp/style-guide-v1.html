1. 컬러 팔레트 — Primary / Alt 2단 체계

같은 계열의 색은 2개로 한정. 사용자가 매번 "어떤 골드?"를 고민하지 않도록 Primary(기본) / Alt(보조)로 명확히 분리.
기존 gold-bright · gold-dim은 폐기. 필요하면 alt를 opacity 조정으로 대체.

Gold — Primary / Alt

PRIMARY · MAIN
Gold Primary
#d4a24e · --gold-primary
언제 쓰나: idle 상태 골드 — 패널 border, 일반 텍스트 강조, archetype chip 외곽선, 비활성 인디케이터.
은유: "조용히 있는 황금".
ALT · HOVER · ACTIVE
Gold Alt
#e8c172 · --gold-alt
언제 쓰나: hover/active/focused — eyebrow 텍스트, active 라벨, glow 색상, 패널 헤더 아이콘 색.
은유: "빛을 받은 황금".
⚠ Primary와 Alt를 한 요소에 동시에 쓰지 말 것. 한 컴포넌트는 둘 중 하나만 선택. 보색은 항상 opacity 변형(.10~.50)으로 표현.
예: 패널 border = Primary .22, hover시 = 같은 Primary .40로 강화 (Alt로 바꾸지 마라).

2. 버튼 — Main(Secondary) / Ghost / Party

솔로몬 법정의 톤은 차분함. 골드 outline (Secondary)이 메인 CTA로 채택됨. 그라디언트 Primary는 폐기 (특수 1~2 케이스만 잔존).
모든 버튼 transition 140ms · hover시 translateY(-1px).

MAIN — 골드 outline (모든 결정 액션의 기본)

Use: 사건 입장 · 모달 결정 액션 · Phase pill · Space 진행 · 모순 찌르기 등 거의 모든 CTA.
bg gold .10 / border .45 / hover시 .65 + glow 18px. 그라디언트 X.

GHOST — 중립 (뒤로 · 취소 · 스킵)

색은 죽이고 hover시 골드 0.28로 살짝 깨움. Main과 함께 2버튼 다이얼로그에서 좌측에 배치.

PARTY CTA — 화자색 outline (당사자에게 제시 한정)

증거 제시 / 분리 심문에만. 화자색 outline은 즉각적인 대상 식별 신호.
⚠ 폐기된 버튼 변형
  • Primary (골드 그라디언트) — 게임 톤과 충돌. 모든 자리를 Main outline이 대체.
  • 예외: 판결 모달 최종 확정 버튼 정도만 잔존 가능 (한 게임에 1번).

13. 둥근 모서리 겹침 — Primary / Secondary

플레이 스크린샷에서 실제로 관찰되는 형태:
① 안쪽 카드가 바깥 카드 안에서 자기만의 둥근 모서리를 가짐 (frame-within-frame),
② 아바타·아이콘(원형)이 카드 좌측에 위치하면서 같은 색 측면 글로우가 카드 가장자리에 깔림.
이 두 가지가 Primary다. 나머지는 Secondary로 분리.

PRIMARY 1 · NESTED — 바깥 둥근 박스 안에 안쪽 둥근 카드

오피스텔 방문과 새벽 전화

바깥 패널 (radius 16) 안에 안쪽 카드 (radius 12). radius 차 4px 유지가 핵심 — 두 둥근 모서리가 평행 곡선으로 보여 frame-within-frame 효과.

구조: outer radius 16 · padding 10 · inner radius 12. radius 차는 항상 4px (또는 14/10).
사용처: brief 패널 안 항목, 모달 선택지, 발언노트, 증거 카드 본문. 가장 자주 쓰이는 표준.

PRIMARY 2 · PEEK + SIDE GLOW — 아바타가 카드 가장자리에 + 측면 글로우

박지연 (active)

아바타가 카드 좌측 가장자리에 위치하면서 같은 화자색의 글로우가 카드 좌측 edge에 깔린다. 원형 아바타 + 카드 둥근 모서리 + 측면 글로우 3요소가 만나는 패턴 (실제 캐릭터 카드/발언 카드/관찰 카드의 정답).

구조: 카드 좌측 안쪽에 원형 아바타·아이콘. 카드 좌측 edge에 같은 색 vertical glow (box-shadow inset 또는 ::before 12px 골드/화자색 fade).
사용처: 캐릭터 프로필, 발언 말풍선, 관찰 카드, 증거 카드. "왼쪽 덧칠"의 정답.
색 매핑: 박지연 = blue glow / 이준호 = red glow / 재판관·관찰 = gold glow.

14. 패널 위계 (3-Level Panel System)

플레이 화면은 항상 3단 위계로 구성. L1 panel → L2 section → L3 item card. 각 단계는 bg/border가 점점 약해짐.

16. 반투명 — Primary / Secondary

실제 사용되는 것 위주로 정리. Primary 2단이 95% 케이스, Secondary 2단은 특수 상황만. MEDIUM 폐기.

PRIMARY — 거의 모든 표면이 둘 중 하나

PRIMARY 1 · STANDARD .85
모든 일반 패널·카드·brief·모달
배경이 살짝 비치되 본문은 충분히 또렷.
PRIMARY 2 · LIGHT .42 + blur
플로팅 표면 — app bar, hotbar, 우측 패널, 정보 카드
backdrop-filter blur(8px) 동반.
STANDARD는 viewport에 "박혀 있는" 패널. LIGHT+blur는 viewport 위에 "떠 있는" 표면. 이 두 개로 95% 커버.

SECONDARY — 특수 상황만

SECONDARY 1 · HEAVY .96
결정적 다이얼로그만 (재판관의 판단, 모순 감지)
배경 거의 가림. 흐름 정지의 신호.
SECONDARY 2 · TINT .10
색이 영역의 의미일 때만
골드/화자색 강조 chip, active 영역.
SECONDARY는 정말 필요할 때만. 평소는 PRIMARY 두 개 중 하나로 끝.
⚠ 폐기: MEDIUM .70 — STANDARD으로 충분히 대체됨.

backdrop-filter — 단일 값 8px로 통일

FROST · blur(8px) · 단일 값
app bar / 우측 패널 / 정보 카드 / hotbar / 플로팅 카드 — 전부 동일하게 8px.
⚠ 폐기: blur(14px) — 결정적 다이얼로그 배경 dim에 쓰려 했으나 8px로도 충분, 더 흐려지면 어지러움. blur는 무조건 8px 한 가지만.

17. 네온 효과 — 사실상 폐기

실제 플레이 화면을 다시 분석한 결과 의도된 네온 효과는 사용되지 않음. 모든 강조는 12. GLOW로 충분.
단 하나의 예외만 남긴다 — WARNING NEON (모순 감지 등 amber 경고).

유일한 잔존 — WARNING (text-shadow only)

모순 감지
언제만 사용:
① 모순 감지 알림의 핵심 단어 ("모순 감지")
② 결정적 자백 순간 ("자백")
색: amber (#ffb347)만. 골드 아님.
스펙: text-shadow 0 0 10px amber .70, 0 0 22px .40
한 화면에: 0개 (기본) / 1개 (특수 이벤트 시)
⚠ 폐기된 네온 변형
  • SOFT NEON — active 라벨에 쓰려 했으나, 12. GLOW (text-shadow 없는 box-shadow)로 충분.
  • STRONG NEON — phase 표시는 그냥 골드 outline pill로.
  • SHARP NEON (stroke) — 판결 화면도 SHARP 안 씀. 큰 폰트 + GLOW로 처리.
  • 네온 박스 / 네온 라인 — 둘 다 폐기. 강조 필요 시 GLOW + 두께·color로.
결론: 솔로몬 법정의 시각 언어는 차분한 골드 + 절제된 GLOW다. 네온은 게임 톤과 충돌.

18. 선 두께 — 1px / 2px만

통합 결과: 1px (기본) + 2px (특수 둘레) 둘만 사용. 4px는 13. SOLID BAR가 폐기되면서 같이 폐기됨.

1px (PRIMARY · 기본)
모든 패널·카드·버튼·divider·hover/active 보더.
99% 케이스 — hover/active 강조도 1px 유지하고 색·alpha·glow로
2px (SECONDARY · 둘레)
원형 둘레만 — portrait ring, 아이콘 박스 강조 ring.
1px 둘레는 시각적으로 "안 보이는" 원형 한정
핵심 규칙: hover나 active로 더 강조하고 싶을 때도 두께는 1px 유지하고 색을 진하게(.22 → .40 → .60) 또는 glow를 추가한다. 두께를 2px로 올리면 위계가 깨진다.
⚠ 폐기: 4px (수직 액센트), 1.5px, 3px. 4px는 13.A SOLID BAR 폐기와 함께 폐기.

20. 적용 우선순위 (사건 선택 씬 리뉴얼 시)

  1. 전체 배경에 vignette + 미세 골드 radial glow 2겹 추가 (현재 평면 다크)
  2. brief 패널을 STANDARD .85 표준 패널로 — backdrop-filter blur(8px) 옵션
  3. brief 항목을 NESTED 13.B — outer 16 / inner 12, radius 차 4px
  4. 사건 입장하기 CTA를 Main(Secondary) — 골드 outline + hover SOFT glow (그라디언트 X)
  5. Stage pill active = 골드 .60 border + SOFT glow (PULSE는 0건, 사건 선택은 정적인 호흡)
  6. VS 영역에 화자색 archetype chip — 박지연 blue, 이준호 red
  7. 캐릭터 active = PEEK + GLOW 13.B — 아바타 가까이에 화자색 측면 글로우 (골드 X)
  8. 선 두께 전 영역 1px (1.5px / 3px / 4px 모두 폐기, portrait ring만 2px)
  9. eyebrow/title 모달 표준 (eyebrow 11~12px 800 0.22em / title 24~32px 800)
  10. 완료 기록만 토글 ON시 SOFT glow 12px
  11. 뒤로 버튼 Ghost 표준
  12. 네온 0건, STACK 0건, STRONG glow 0건 — 사건 선택은 차분한 호흡. 강조는 SOFT glow + 색·alpha만.
