2. 버튼

모든 버튼은 transition 140ms ease + hover시 translateY(-1px). Primary CTA만 골드 그라디언트, 나머지는 outline 패턴.

Primary — 골드 그라디언트 (메인 CTA, 결정 액션)

Use: 사건 입장 · 모순 찌르기 · 판결 · "다음 진술" 진행. 한 화면에 1개만.

Secondary — 골드 outline (기본 액션, 자주 쓰는 토글성 버튼)

Use: 모달 액션 · phase pill · Space 진행 표시. Primary 1개 + Secondary 0~3개 권장.

Ghost — 중립 액션 (취소 · 뒤로 · 부가)

Use: 뒤로/취소/스킵. 색은 죽이고 hover시 골드 0.28로 살짝 깨운다.

Party CTA — 화자 색 outline (당사자에게 제시)

Use: 증거 제시 모달 · 분리 심문. 화자 색 outline으로 즉시 구분.

3. 하이라이트 / Active 효과

플레이 화면의 모든 active state는 동일 패턴: 골드 border 0.5 + 골드 bg 0.10 + 외곽 glow shadow.

기본 (idle)
border 0.06 · bg 0.7
Active
border .50 · bg .10 · glow .18
Cleared
border .36 · bg .06
3가지 외 추가 상태 만들지 않는다. is-locked는 opacity 0.32만 적용.

12. 빛나는 효과 (Glow)

전 화면 동일 — Active/Hover에는 항상 골드 계열 빛이 약하게 깔린다. 6가지 변형으로 한정.

6가지 변형

SOFT0 0 18px gold .18
STRONG (CTA hover)다중 레이어 (0/24/48px)
INSET (active panel)inset 0 0 24px gold .10
PULSE (지속)2.4s 사이클 .16↔.42
RIM (gradient border)border-image gradient
HALO (radial bg)radial gradient inside
SOFT = 일반 active state (stage pill, brief item hover)
STRONG = Primary CTA hover, 결정적 모달
INSET = 패널 내부 강조 (active 캐릭터 프로필)
PULSE = 모순 알림 / 진행 가능 신호 — 절제해서 한 번에 1개만
RIM = 모달/카드 가장자리 강조 (전체 윤곽)
HALO = 인물 초상화 뒤 / 결정적 카드 (시즌 모드, MVP)

레이어 조합 — 결정적 카드 (예: 사건 입장하기 CTA)

기본 그림자(0 8 24) + 골드 외곽 글로우(0 0 32) + 1px 골드 stroke + 상단 inset 흰빛. 레이어 4단이 표준.

13. 왼쪽 덧칠 / 페인터리 (Left Accent / Painterly)

플레이 화면 좌측 패널들의 시각적 무게감 — "그림 같은 느낌"을 주는 핵심. 4가지 변형.

A. SOLID BAR — 4px 골드 수직 바 (현재 사건 선택 씬에 약하게 적용된 것)

증거 수집

골드 4px 수직 바 + 위·아래 14% 페이드. 활성 패널 좌측 식별자로 사용.

사용처: 사건 브리핑 패널, active 우측 패널, 선택된 캐릭터 프로필.

B. BRUSH WASH — 좌측 그라디언트 덧칠 (페인트가 번진 듯한 느낌)

재판관의 관찰

좌측 80px 영역에 골드 .16 → .06 → 0 그라디언트 + 좌측 가장자리 2px 골드 라인. 덧칠 + 경계선 조합으로 회화적 느낌.

사용처: 이게 사용자가 의도한 "왼쪽 편에 덧칠"의 정답. 패널 좌측이 그림자/잉크가 번진 듯 보임.

C. SCRIBBLE / FRACTAL NOISE — 거친 페인터리 결

발언노트 즐겨찾기

좌측 24px에 SVG fractalNoise 오버레이 (골드 톤). 거친 페인트 결이 보이는 가장 회화적인 변형.

사용처: 사건 선택 씬의 brief 패널 좌측, 핵심 모달 상단 등 강한 인상이 필요한 곳에 한정.

D. TAB INDICATOR — 활성 탭 하단 골드 라인 + glow

기본 탭
박지연
이준호
사용처: 우측 패널 박지연/이준호 탭, 재판관 데스크 탭. 2px 골드 + 양 끝 페이드 + glow 8px.

14. 패널 위계 (3-Level Panel System)

플레이 화면은 항상 3단 위계로 구성. L1 panel → L2 section → L3 item card. 각 단계는 bg/border가 점점 약해짐.

누설 — 0%

L1 (panel) = 골드 border .22 + 큰 그림자 + inset highlight + 헤더(아이콘 + 제목 + 카운트)
L2 (section) = 흰 border .06 + 반투명 배경 — 같은 L1 안의 카테고리
L3 (item) = 흰 border .05 + 흰 bg .03 — 가장 안쪽 단위 (목록 항목)

헤더 패턴: 좌측 28×28 골드 아이콘 박스 + 제목 (uppercase 0.14em) + 우측 카운트 chip. 모든 L1에 통일.

테두리 색은 그 영역의 기능을 즉시 알린다. 자의적으로 섞지 말 것.

PARTY B

16. 적용 우선순위 (사건 선택 씬 리뉴얼 시)

  1. 전체 배경에 vignette + 미세 골드 radial glow 2겹 추가 (현재 평면 다크)
  2. brief 패널을 모달 표준(radius 18, golden border .28, big shadow + inset)으로 격상 + RIM 글로우 적용
  3. brief 패널 좌측에 BRUSH WASH(13.B 패턴) — 80px 골드 그라디언트 덧칠 + 2px 라인
  4. brief 항목을 L3 item 표준으로 (흰 .05 → 골드 .04 bg + .16 border, hover시 SOFT glow)
  5. 사건 입장하기 CTA를 STRONG glow 4단 레이어로 강화 (그림자 + 외곽 글로우 + stroke + inset)
  6. Stage pill active = SOFT glow + 6×6 dot + pulse(2.4s) 한 번만
  7. VS 영역에 화자 색 chip 추가 — 박지연(피해자 서사·대립형) blue, 이준호(회피형) red
  8. 캐릭터 카드 active시 화자색 .60 + 화자색 glow .18 (골드 X)
  9. eyebrow/title 위계 모달 표준 (eyebrow 11px 800 0.22em / title 24px 800)
  10. 패널 헤더에 28×28 골드 아이콘 박스 + uppercase 제목 + 카운트 chip 도입 (현재 카운트 chip 없음)
  11. 뒤로 버튼 Ghost 표준
  12. 완료 기록만 토글 ON시 골드 glow 12px (현재 평범한 색 변화만)
