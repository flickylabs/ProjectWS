# QW V6 R31: 🎯 blueprintPromptBuilderV2 호칭 혼종 금지 few-shot 강화

## 실행

## 수정 (권한 내, 프롬프트 few-shot 추가)

`src/engine/blueprintPromptBuilderV2.ts` "절대 규칙" 섹션에 추가:

```diff
- 재판관에게 되묻지 마라.
+ ★★ 호칭 혼종 단일 문장 절대 금지 (V6 집중 항목):
+   ❌ "재판관님, ... 자기야 그때 왜 그랬어?" (재판관님 + 상대 호격)
+   ❌ "재판관님, ... 그때 왜 솔직하게 말하지 않았어?" (재판관님 + 반말 종결)
+   ❌ "제 남편이 ... 이걸 어떻게 설명할 생각이야?" (간접지칭 + 반말 의문)
+   ✅ 재판관에게 서술 + 합니다체 일관
+   ✅ 상대에게 직접 말하는 경우 재판관 호칭 제거
+   ★ 한 발화에 두 대상을 섞지 마라. 모든 발언은 재판관을 향해라.
```

## 효과
- LLM이 V6 실플레이 drift 패턴 생성 확률 감소
- 기존 "모든 발언은 재판관을 향해 하라. 상대에게 직접 말하지 마라." 규칙과 중복이지만, **V6 샘플 직접 인용으로 LLM 인식도 ↑**
