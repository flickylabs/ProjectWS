## 5. Recommended Option

Recommendation: Option C, dual anchor with exact targeted-region validation.

Reason:
- It preserves `baseline-pre-policy-v1` for the other ~14.9k ScriptedText variants.
- It avoids a broad rebaseline that could accidentally absorb unrelated ScriptedText drift.
- It is safer than a simple whitelist because the approved A-1 entries can be checked against concrete v2 text/behaviorHint hashes, not merely variant IDs.
- It keeps the existing hard-fail posture for all unapproved B/C ScriptedText edits.

Pragmatic fallback if CT-Main needs the shortest path: Option A is acceptable only if CT-Main creates a v2 baseline commit/tag whose diff is proven to contain exactly the approved A-1 ScriptedText corrections, then updates/authorizes the checker baseline behavior accordingly. Option B should be avoided unless it is hash-bound and temporary.
