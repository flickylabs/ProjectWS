## TC-B: Phase B 체념 시스템 보강 (10분, 핵심)

**준비**: spouse-01 → Phase 3 → 캐릭터B 격앙 유도.

| # | 동작 | 기대 |
|---|---|---|
| B-1 | 캐릭터B 체념 진입 (emotion ≥ 85) | 시스템 메시지 1회 출력. 우측 patch label "체념" |
| B-2 | 체념 진입 직후 turn = T라 가정 | turn T+1, T+2 모두 B 질문 시도 시 차단됨. **turn T+3부터 가능** (정확히 2턴 차단) |
| B-3 | 체념 만료 시점(turn T+3) | 시스템 메시지 "[B 이름]이(가) 호흡을 가라앉히고 다시 답할 수 있는 상태가 되었습니다." 자동 출력 |
| B-4 | 만료 후 B 질문 시도 | 정상 응답. **즉시 다시 체념에 빠지지 않음** (emotion 75로 자동 조정됨) |
| B-5 | 체념 중 캐릭터B에 증거 제시 시도 | "🔒 [B 이름]이 체념 상태입니다. N턴 후 증거를 제시할 수 있습니다." 메시지 + **증거 제시 카운팅 안 됨** |
| B-6 | 체념 중 캐릭터A에 질문 | 정상 진행. (A는 영향 없음) |
| B-7 | 우회 안내 메시지 확인 | B 차단 메시지에 "[A 이름]에게 질문(증거 제시)하거나 다른 행동을 취해주세요" 안내 포함 |

**검증 핵심**: 정확히 2턴 차단 + 만료 후 emotion 자동 조정 + 증거 제시도 차단 + 우회 안내.

## TC 우선순위 (시간 부족 시)

1. **TC-B** (체념 시스템) — 사용자가 가장 명확히 보고한 결함
2. **TC-E** (emergence 모달) — 시각적 변화 큼
3. **TC-F** (호칭) — 사용자 인지 빠름
4. **TC-A** (텍스트 통일) — 빠른 확인
5. **TC-D** (수첩 가시성) — 인프라만 — 빠른 확인
6. **TC-G** (Script sample) — 마지막 검증

NG 시 발화/시점/조건 알려주시면 즉시 추가 픽스.
