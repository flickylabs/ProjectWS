## TC-11. ScriptedText 모드 핫바 락 (Agent 3 완료)

**위치**: 사건 진행 중 (LLM Off 모드 = ScriptedText 매칭 사건)

**변경**: `src/hooks/useActionDispatch.ts` +30줄 (헬퍼/상수) +4줄 (호출 2곳)

### 매커니즘
- ScriptedText 매칭으로 NPC dialogue가 즉시 추가된 직후 `setLLMLoading(true)` 호출
- 텍스트 길이 × 14ms + 220ms 버퍼 (min 350ms / max 4000ms 캡)으로 `setTimeout` 자동 해제
- 새 호출 시 기존 타이머 `clearTimeout`

### 체크
- [ ] **ScriptedText 사건(spouse-01 등)에서 핫바 액션 클릭 → NPC 응답 직후** 핫바 6슬롯 + 단축키(1~6, Q/W/E) 모두 차단됨
- [ ] **타이핑 종료(약 1.6~3초 후)** 핫바 자동 활성화
- [ ] 다시 클릭 가능
- [ ] **LLM 폴백 분기**(ScriptedText 미매칭 사건) 락 동작 변화 없음 (이전과 동일)
- [ ] CSS `hotbar-slots--locked` 시각 효과 (회색 톤) 적용 확인

### 회귀 점검 (잠재 의심점)
1. **LLM 응답이 ScriptedText 락 타이머보다 빠르면** `setLLMLoading(false)` 두 번 set 가능 — 무해 (false 두 번 = 그대로 false)
2. **사건 종료 시 타이머가 살아있다면** 다음 사건 초반 잠깐 락 가능 — max 4초 캡으로 체감 영향 미미
