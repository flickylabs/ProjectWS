# Task Spec — 자백 스크립트 작성 형식

## 자백 단일 entry 구조

각 자백은 3단계로 구성. 각 단계는 자연스럽게 이어지되 독립적 발화로 사용 가능 (시스템에서 단계별 dispatch).

```jsonc
{
  "speaker": "a" | "b",          // 자백자
  "disputeId": "d-1" | ...,      // 핵심 쟁점
  "preConfession": "string",     // 자백 직전 1문장 — hesitation·침묵 깨기
  "confessionMain": "string",    // 핵심 자백 본문 — 1~3문장
  "postConfession": "string",    // 자백 후 1문장 — 책임 인정·silence·shame
  "behaviorHint": "string",       // 옵션. 행동 묘사 (1줄)
  "tags": ["channel:confession", "stance:confess", "emotion:resigned" ...]
}
```

## 단계별 톤 가이드

### preConfession (자백 직전)
- 짧은 호흡 / 침묵 깨기
- 망설임 표현 ("…", "재판관님,")
- 화자 캐릭터 톤 유지 (B는 침묵, A는 흔들림)

**예시 (B 외도 의심받는 자, family B 보호자, friend B 자책)**:
- "…재판관님,"
- "더 숨기지 않겠습니다."
- "…말씀드리겠습니다."

**예시 (A 외도 의심자, family A 분노 장남, friend A 성급 단정)**:
- "재판관님, 솔직하게 말씀드리겠습니다."
- "한 가지만 인정하겠습니다."
- "…저도 잘못한 부분이 있습니다."

### confessionMain (핵심 자백)
- **구체 사실** + **금액·이름·시점 노출**
- 1~3문장
- 자연스러운 한국어 (시스템 말투·번역체 금지)

**예시 (B의 형 지원 자백 = spouse-01 자백 #3)**:
> "제 아내 몰래 모아둔 돈에서 이천만 원을 형에게 건넸습니다. 개인회생 중이라 통장으로는 받을 수 없어서 현금으로 직접 전했습니다."

**예시 (A의 위임장 조작 자백 = spouse-01 자백 #5)**:
> "공동 적금 해지 서류의 서명은 제가 흉내낸 것입니다. 두려움이 컸고, 그날 한 번이면 끝날 줄 알았습니다."

### postConfession (자백 후)
- 책임 인정 멘트 또는 silence·shame
- 1문장
- 화자 캐릭터에 맞는 종결 톤

**예시**:
- "이 부분은 제가 잘못한 게 맞습니다."
- "…죄송합니다."
- "더 일찍 말씀드렸어야 했습니다."
- "이 점에 대해서는 제가 책임지겠습니다."

## 금지 사항

1. **시스템 말투** — "~을 수 있겠습니다", "~답니다", "~인 측면이 있었습니다"
2. **번역체 9패턴** — "혼란과 불안으로 가득 차", "부득이하게", "불찰", "인지하고 있습니다" 등
3. **재판관에게 답 요구** — "재판관님, ~ 알려주십시오"
4. **자기 지칭 "자기"** — "자기를 보호 → 스스로를 지키"
5. **특정 X 패턴** — "특정 금액 → 그 금액"
6. **반말** — 재판관 대상 발화는 모두 합니다체

## 검증 체크리스트 (작성 후 자체 검증)

- [ ] 모든 12개 자백 entry 작성
- [ ] 각 entry에 preConfession/confessionMain/postConfession 모두 채움
- [ ] 금액·이름·시점이 03-context.md와 일치
- [ ] 캐릭터별 naturalTone 유지
- [ ] 금지 사항 위반 없음
- [ ] 재판관 호칭 합니다체 일관

## 후속 작업

GPT Pro 산출물 받으면:
1. CT(Claude Code)에서 한국어 보정 (어색한 부분만 교정)
2. ScriptedText 또는 별도 confessionData 파일로 통합
3. Phase C 자백 트리거 인프라에서 매칭 (lieState=S5 + 누설 임계 + 자백 발동 1회 제한)
4. 재판관의 수첩 (Phase D)에 자백 entry 등록
