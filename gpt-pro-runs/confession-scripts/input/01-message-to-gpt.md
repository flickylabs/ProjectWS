# GPT Pro 의뢰 — 활성 3사건 자백 스크립트 작성

## 프로젝트
**솔로몬 법정 (Solomon Court)** — 재판관(플레이어)이 두 당사자를 심문하여 진실을 밝히는 추리 게임. 활성 사건 3건(spouse-01·family-01·friend-01)에 **자백 시점 전용 스크립트**가 부재. 자백 발동 시 NPC가 즉흥 LLM이 아닌 사전 작성된 자연스러운 자백 발화를 하도록 작성 의뢰.

## 핵심 문제 (현재 상태)

기존 코드 흐름:
1. 캐릭터의 lieState가 S5에 도달하거나 누설 미터가 임계 도달 → "자백" 트리거
2. 시스템 메시지 "결정적 진술이 확보되었습니다"만 출력
3. **NPC 직접 자백 발화 없음** (즉흥 LLM이 짧게 답할 뿐, 전용 스크립트 부재)
4. 결과: 사용자에게 "자백 순간"의 무게가 전달되지 않음

본 의뢰 목적: **자백 시점 NPC 발화를 사전 작성**해서, 자백 트리거 시 정해진 스크립트로 무게 있는 발화를 노출.

## 입력 자료

| 파일 | 내용 |
|---|---|
| `02-task-spec.md` | 자백 entry 구조 + 출력 형식 |
| `03-context.md` | 3사건 캐릭터 입장 + 자백 시점 정의 + 진실 공개 곡선 |
| `source/confession-points.json` | 작성 대상 자백 12개 (사건별 트리거·쟁점·화자 정의) |

## 작성 대상 (12개 자백 포인트)

| 사건 | 자백 # | 화자 | 쟁점 | 자백 핵심 |
|---|---|---|---|---|
| spouse-01 | 1 | B | d-1 (오피스텔 방문) | "형 집에 갔다" 인정 |
| spouse-01 | 2 | B | d-2 (형 문자 스레드) | 형의 개인회생 사실 인정 |
| spouse-01 | 3 | B | d-3 (계좌 출금) | 2,000만원 = 형 지원 인정 |
| spouse-01 | 4 | A | d-4 (투자 사기) | 3,000만원 손실 = 자기 책임 인정 |
| spouse-01 | 5 | A | h-d3·h-d4 (위임장) | 위임장 조작 = 자기 위조 인정 |
| family-01 | 6 | B | d-1·d-2 (60:40 유서) | 어머니 의사 변경 개입 인정 |
| family-01 | 7 | B | d-3 (장기 송금) | 형 보호 의도 인정 |
| family-01 | 8 | A | d-2 (어머니 돌봄) | 분노 안의 두려움·출생 비밀 인지 자백 |
| friend-01 | 9 | B | d-3 (과거 카톡) | A 아버지 사기 피해 노출 |

## 핵심 가이드라인

1. **인격 보존** — 03-context.md의 캐릭터 naturalTone 유지. 자백이라고 갑자기 다른 사람이 되지 말 것.
   - B(외도 의심받는 자): 회피·침묵 → 자백 시도 침묵·짧은 문장. 격하지 않음
   - A(외도 의심자): 분노·추궁 → 자기 자백 시 갑자기 약해지지 않고 책임 인정 + 약간의 자기 변명·두려움 표출
   - family A(분노 장남): 큰 목소리 → 자기 자백 시 잠시 침묵 후 작게
   - family B(보호자/조작자): 평평한 톤 → 자백 시도 동일. 감정 폭발 X
   - friend A(성급 단정): 단정 톤 → 자백 시 후회·자책
   - friend B(보호자→낙인): 자책 평평 → 자백 시 가까스로 입을 떼는 톤

2. **자백 흐름 3단계 구조** — 각 자백 entry에 다음 3개 필드:
   - `preConfession`: 자백 직전 1문장 (hesitation, 침묵 깨기)
   - `confessionMain`: 핵심 자백 본문 (1~3문장. 구체 사실·금액·이름 포함)
   - `postConfession`: 자백 후 1문장 (silence, shame, 책임 인정 멘트)

3. **금액·이름·시점 정확** — 03-context.md의 사건 설정 그대로:
   - spouse-01: 2,000만원(B 형 지원), 3,000만원(A 투자방 손실)
   - family-01: 60:40·90:10 유서 비율, 20년 송금
   - friend-01: 9일 17건 연락, A 아버지 반복 사기

4. **재판관 호칭** — "재판관님" + 합니다체. 자백이라도 재판관에게는 존대.

5. **상대에게 직접 호칭** — A·B 서로에게 직접 말하는 발화는 callTerms.toPartner 활용 (예: "자기야"). 단 이 자백 entry에서는 대부분 재판관 대상 (toJudge).

6. **TruthThrottle 무시** — 자백 시점은 S5이므로 모든 진실 공개 OK. 구체적 이름·금액·시점 모두 노출.

## 분량

12개 자백 entry × 3필드(preConfession/confessionMain/postConfession) = 36개 발화. 각 발화 길이는 1~3문장.

## 후속

GPT Pro 산출물 → CT(Claude Code)에서 한국어 추가 보정 → ScriptedText 통합 또는 별도 자백 데이터 파일로 import → Phase C 인프라(자백 트리거)에서 매칭하여 NPC 발화로 노출.
