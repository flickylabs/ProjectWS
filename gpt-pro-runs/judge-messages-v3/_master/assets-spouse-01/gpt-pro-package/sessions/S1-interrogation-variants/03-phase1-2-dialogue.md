# spouse-01 — Phase 1/2 대사 톤 참고

이 문서는 GPT가 spouse-01의 캐릭터 voice를 정확히 재현하기 위한 톤 레퍼런스다.
보정 톤 8원칙(02-tone-guide.md) 적용 후 활용한다.

## Phase 1 — 초기 진술

### 박지연 (A) voice
| 라인 | 톤 패턴 |
|---|---|
| "재판관님, 제 남편은 매일 퇴근하면 집으로 바로 돌아오지 않습니다. 처음엔 야근이겠거니 했습니다. 그런데 한 달, 두 달, 석 달… 똑같은 패턴이 반복되니까 저도 가만히 있을 수가 없었습니다." | victim_frame: 참아온 시간 강조, 또렷한 정리 |
| "블랙박스를 확인해 보고, 매일 같은 오피스텔에 두세 시간씩 방문하는 것을 알게 되었습니다." | 증거 기반 정리, "추측이 아니라 확인" 뉘앙스 |
| "자기야, 뭐가 오해인데? 매일같이 거기를 다녀와놓고 그저 오해라고? 거기서 뭘 하는 건데?" | toPartner="자기", angry 직전 |
| "오해라고? 그게 끝이야? 나한테 할 말이 아직도 그것뿐이야?" | 분노 + 서운함, 목소리 떨림 |
| "재판관님, 제 남편은 항상 저런 식입니다. 사정이 있다, 복잡하다, 나중에 말한다. 시댁 문제 때도 그랬습니다." | 패턴 공격, 시댁 자연 비약 |

### 이준호 (B) voice
| 라인 | 톤 패턴 |
|---|---|
| "재판관님, 그건 오해입니다." | 짧게 끊고 입 다묾 (answer_delay) |
| "… 그곳에 간 건 맞습니다. 근데 제 아내가 생각하는 일은 아닙니다." | partial_scope: 큰 사실 인정, 핵심 자름 |
| "… 사정이 있어. 근데 지금은 말하기가 어려워." | toPartner="자기" 생략 (위축) |
| "이게 뭐하는 거야… 여기서 이러지 말자." | 회피 + 창피함 |
| "… 가족입니다. 그 이상은… 지금은 말씀드리기 어렵습니다." | hard 압박에 한 단계 인정 (cornered) |
| "… 고맙습니다, 재판관님. 사정이 있는 건 맞습니다. 자칫하면 문제가 더 커질 수 있어서… 그래서 이럴 수 밖에 없습니다." | empathy 접근에 진심 살짝 (rapport_warm) |

## Phase 2 — 반박 진술

### 박지연 (A) voice 추가
| 라인 | 톤 패턴 |
|---|---|
| "재판관님, 제가 블랙박스만 본 게 아닙니다. 제 남편 차 뒷좌석에서 영수증 묶음을 찾았습니다. 다섯 장이요." | 차분 + 칼날 (한 장씩 세듯) |
| "편의점 컵라면, 올리브영에서 산 머리끈이랑 틴트, 헤어롤… 제가 안 쓰는 물건들입니다. 제 남편이 왜 올리브영에서 틴트를 사겠습니까." | '틴트'에서 목소리 떨림, 서운함>분노 |
| "자기가 산 거라고? 그럼 누구 주려고 산 건데?" | 즉시 직접 추궁 (자기 호명) |
| "10년을 같이 살았는데 내가 모르는 '아는 사람'이 있어? 머리끈이랑 틴트를 사다 줄 정도로 가까운 사람을 나는 왜 몰라?" | "10년" 강조 배신감 |
| "재판관님, 이게 셋이 겹치면 딴살림 아닙니까." | 정황 정리 + 확신 호소 |

### 이준호 (B) voice 추가
| 라인 | 톤 패턴 |
|---|---|
| "그건… 제가 산 겁니다." | 잠깐 멈칫 + 인정 + 다음 말 삼킴 |

| "… 지금 말하면 더 복잡해져. 집안 사정이야." | 또 같은 회피 패턴, 말끝 흐림 |
| "그때랑 지금은 다르다니까." | 작은 목소리지만 단호, 더 파지 말라는 뉘앙스 |
| "재판관님… 제 아내 마음은 이해합니다. 의심할 만하다는 것도 압니다. 하지만 제가 숨기는 건 제 아내가 생각하는 그런 일이 아닙니다. 그것만은 분명합니다." | 처음으로 길게, 진심 묻어남, 핵심은 여전히 감춤 |

## 톤 재활용 가이드

### 박지연 npc_variants에 활용
- **base S0**: "재판관님, ~ 사실입니다." (정리된 어투)
- **cornered**: "재판관님, ~ 또 같은 패턴 아닙니까." (감정 누르기)
- **counter_attack**: "자기가 ~ 한 거 아니야?" (직접 공격, 자기 호명)
- **emotional_outburst**: "10년을 ~ 한 게 다 뭔데!" (목소리 갈라짐)
- **justification_long**: "재판관님, 제가 ~ 한 이유는 ~" (피해자 정당화 길게)

### 이준호 npc_variants에 활용
- **base S0**: "재판관님, 그건 오해입니다." (짧게 끊기)
- **base S1**: "그건… 사실입니다. 다만 ~" (partial_scope)
- **cornered**: "재판관님, 말씀드리고 싶지만 ~" (한 박자 늦게)
- **silenced**: "…" (한 단어, 시선 회피)
- **deflecting**: "그건 그렇고, ~" (motive_jump)
- **rapport_warm (S4 가까이)**: "재판관님… 사실은 ~" (진심 살짝)

## 핵심 호칭 패턴

### 양측이 직접 발화 시
- A → B: "자기" / "이준호!" (angry)
- B → A: "자기" / "박지연!" (angry)

### 양측이 재판관에게 상대 언급 시
- A → 재판관: "제 남편이 ~"
- B → 재판관: "제 아내가 ~"

### 재판관이 양측 호명 시
- "박지연 씨, ~"
- "이준호 씨, ~"
- ⚠️ "부인" 단어 절대 X. "아내분"/"남편분"은 OK (보정 톤 1원칙)
