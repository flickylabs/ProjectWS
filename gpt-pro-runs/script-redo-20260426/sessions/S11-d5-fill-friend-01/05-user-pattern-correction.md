# 보정 작업의 진짜 의미 (메인 잘못 패턴 #6)

## 규칙
ScriptedText 보정 = **글자수 가이드 + 표면 어휘 교체로 끝내지 마라.** 9차원 맥락(캐릭터 archetype × lieState × emotion × contradict_token × tone × 시점 등)을 정확히 매핑한 뒤, **각 단계의 인지 상태를 살린 표현**을 선택해야 한다.

**Why**: 2026-04-26 spouse-01 ScriptedText judge_contradiction 18 entries 1차 보정에서 메인이 글자수 70자 가이드 미세 초과 3건만 단순 단축으로 처리. 사용자가 직접 보정해서 보여준 예시는 표면이 아니라 의미/맥락 차원이었다. 사용자 명시: "글자수 약간의 편차는 허용할 수 있어. 다만, 오히려 내용들이 문제네. 표현에 있어 훨씬 꼼꼼하게 의미를 살려서 작성해야 돼."

**How to apply**: 보정 작업 시 다음 차원 정확 매핑 후 표현 선택.

### 점검 차원 (9차원 + α)
1. 모순의 종류 — 사실 변화? 입장 변화? 인지 단계 변화?
2. NPC 캐릭터 archetype — 박지연 victim_cosplay → 강한 단정의 무게 / 이준호 avoidant → 모호어의 무게
3. lieState 단계 — S1 모순 vs S3 모순은 다른 톤
4. 추궁 강도 — soft지만 의미는 첨예 / hard라도 단순 압박이 아니라 핵심 요구
5. NPC 마지막 발언 맥락 — 직접 인용 X but 발언의 본질을 정확히 짚는 표현
6. 박지연/이준호 인지 변화 단계 — "확실 → 정황 해석 → 인정" / "오해 → 사정 → 자백"

### 사용자 보정 모범 (2026-04-26)

**Patch 1**: 박지연 d-1 모순 추궁 (soft)
- 메인 보정: "쪽이었는데" / "쪽입니다" — 단순 어휘 교체
- **사용자 보정: "주장이었는데" / "의견입니다"** — 박지연의 인지 단계 단계적 약화 (강한 단정 → 한 발 물러선 해석) 정확 반영
- 핵심: "쪽" 같은 모호한 단어 회피, 인지 상태 단계 표현

**Patch 2**: 박지연 d-1 단정 추궁 (hard)
- 메인 보정: "분명히 " 제거 — 단순 단축
- **사용자 보정**: "그 책임도 → 그 이유도" / "무엇을 알고 무엇을 밀어붙였습니까 → 왜 그렇게 확신하고 밀어붙였습니까"
- 핵심: **정보 추궁(무엇)이 아니라 동기/심리 추궁(왜 그렇게 확신)** — 더 깊은 차원

**Patch 3**: 박지연 d-2 출금 인지 추궁 (hard)
- 메인 보정: "출금 사실을 → 출금을" — 단순 단축
- **사용자 보정**: "흐리면 → 밝히지 않으면" (추상 → 직접 행동 지적) / "바로 세울 수 없습니다 → 내세울 수 없습니다" (재판관이 쟁점화 자체를 거부하는 톤) / "본 방식과 본 뒤의 행동 → 관련내용" (어색한 표현 → 자연스러운 일반화)

**Patch 4 (한국어 자연체 — 명사형 → 동사형)** 2026-04-26 추가
- 메인 1차 보정: "가족 돌봄으로 입장을 옮기셨습니다" / "가족 지원이었다고 말씀하십니다" — 명사형 어색
- **사용자 정정**: "가족을 돌본 것이라고 입장을 옮기셨습니다" / "가족을 도운 것이었다고 말씀하십니다" — **동사형 자연체**
- 핵심: "X 돌봄" "X 지원" 류 명사형 표현은 한국어 재판관 발화에 부자연. **"X을 ~한 것"으로 동사형 풀어쓰기**가 자연
- 톤 가이드 7원칙(자연체 어미 일부 허용)과 직결

### 보정 작업 절차 (재발 방지)
1. 해당 entry의 9차원 메타 모두 확인 (party / disputeId / lieState / questionType / tone / 발동 맥락)

## 메인 잘못 패턴 #7: 사용자 단순 확인 질문에 옵션 제시 X (2026-04-26)

**규칙**: 사용자 질문이 "지금 ~만 한 거야?", "이게 맞나?" 류 **단순 확인**이면 짧은 답만. 작업 옵션 (A/B/C/D 류)을 추가로 제시하지 마라.

**Why**: spouse-01 ScriptedText 보정 작업 중 사용자가 "지금 spouse-01만 진행한 거야? family-01도 한 거야?"라고 단순 확인. 메인이 "spouse-01만"이라 답하면서 family/friend 진행 옵션 4개를 추가 제시 → 사용자가 작업 범위 흐트러진다고 느낌.

**How to apply**:
